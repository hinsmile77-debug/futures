# 신동 주체 리뉴얼 구현계획 — 미륵 휴면(더 이상 사용하지 않음) 전제 (MW0602 · 2026-10-24)

- 전제(사용자 지시 2026-10-24): **미륵을 더 이상 사용하지 않는다.** 신동을 프로그램의 주체로 현 프로그램(`main.py` 단일 프로세스)을 리뉴얼한다.
- 선행 조사(같은 날): [미륵 장점 도입 검토](신동_V4_미륵장점_도입검토_MW0602-20261024.md) · [완전 독립 득실](신동_완전독립_별도엔진_이득손실_조사_MW0602-20261024.md) · [미사용 vs 섀도 득실](신동주인_리뉴얼_미륵미사용vs섀도_득실조사_MW0602-20261024.md).
- 이 문서는 **계획**이다. 코드는 아직 바꾸지 않았다. 줄 번호는 2026-10-24 HEAD 기준(이후 바뀌므로 함수명으로 찾을 것).

---

## 0. 한 줄 요약

**미륵을 「지우는」 것이 아니라 「스위치로 재우는」 리뉴얼이다.** `MIREUK_ENGINE = "off"` 하나로 예측·학습·미륵 진입·미륵 장후 체인을 건너뛰고, 그 안에 섞여 있던 **신동이 쓰는 부품 12개**(§1)는 새 「경량 분봉 패스」가 그대로 돌린다. 신동 규칙(`SD-2026-10-26-v4`)·집행 장치·계좌 안전장치는 **손대지 않는다.**

비유: 큰 공장(미륵)의 생산 라인을 멈추되, 그 라인에 붙어 있던 **전기 계량기·화재 경보·출입문 잠금장치**는 떼어서 신동의 작업장 벽으로 옮겨 다는 공사다. 라인을 철거하지 않고 전원만 내리므로, 필요하면 다시 켤 수 있다.

## 2. 원칙 (리뉴얼 내내 지킬 불변식)

1. **신동 규격 무변경** — `strategy/shindong/spec.py` 값·`families.py` 규칙을 건드리지 않는다. 바뀌면 v5 다.
2. **삭제 금지 · 휴면** — 미륵 코드·모델·DB 를 지우지 않는다. `MIREUK_ENGINE="full"` 로 되돌리면 오늘과 같아야 한다(기본값 `full` 로 머지 → 검증 → 전환일에 `off`).
3. **원천 수집은 끄지 않는다** — 1분봉·7222·외국인 선물·맥점·연결선물 정규 수집(`Mireuk_RegularCollect_1552`).
4. **주문 주체는 하나** — 미륵 off 에서 `SYSTEM_AUTO` 출처 주문은 **코드에서** 막는다(설정값이 아니라 주문 함수 진입부).
5. **계측 4원칙** — 끈 것은 「꺼짐」으로 로그에 남긴다(미측정 ≠ 0). 미륵 패널은 0 이 아니라 「휴면」을 표시한다.
6. **절대원칙 §1(15:10)·§4(COM 콜백 내 호출 금지)** 그대로. 새 QTimer 를 만들지 않는다(617차 슬롯 래칫) — 경량 패스는 기존 분봉 콜백 자리에서 돈다.

### Phase 2 — 경량 분봉 패스 (규모 中 · 핵심)

`main._on_candle_closed` 에서 `run_minute_pipeline(candle)` (7001) 를 부르는 자리를 분기한다:

```text
if self._mireuk_engine == "off":
    self._light_minute_pass(candle)
else:
    self.run_minute_pipeline(candle)        # 오늘과 동일
```
