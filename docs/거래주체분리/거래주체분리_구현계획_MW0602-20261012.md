### D4 해석 — 2레그는 「같은 지점에서 함께 청산」이다
FLOWC MAIN 의 두 레그는 `families._run_position()` 에서 **같은 청산가·같은 시각**으로 닫힌다
(`t1 == t2 == 익절가`, 레그별로 손익만 따로 계산). 따라서 실집행은 **2계약 일괄 진입·일괄 청산**이며
부분청산 기능을 새로 만들 필요가 없다.

### D6 해석 — DB 는 규격 요율 유지, 모든 소비처는 CREON
`shindong.db` 의 `leg*_net` 은 사전등록 규격(`spec.COMMISSION_RATE` = CYBOS)으로 계산된다. 이 값을
바꾸면 과거 행과 섞이고 검증 시계가 흔들린다(`spec.py` 머리말). 그래서
- **저장값은 그대로**, 거래주체 계층(잔고 카드·거래 현황·섀도 비교)은 `display.leg_net_at_rate(…, creon_rate())`
  로 **CREON 환산값만** 쓴다(590차 손익추이 패널과 같은 방식).
- 신동이 **실거래**로 나간 건은 브로커 실체결 → `trades.net_pnl_krw` 가 이 PC 감지 요율(CREON 0.0019%)로
  계산된다(495차 채널 파생).

## 3. 설계

### 3-1. 거래주체 상태 — `strategy/runtime/trade_principal.py`(신설)
- 값: `MIREUK | SHINDONG | PETER`. 파일 `data/trade_principal.json` — 날짜가 바뀌어도 유지(D3).
- 전환 로그: `data/trade_principal_log.jsonl`(append) + 시스템 로그 `[Principal]`.
- 전환 조건: 포지션 FLAT **그리고** 대기주문 없음(D2). 아니면 거부 + 사유.
- 출처 매핑: `SYSTEM_AUTO→MIREUK` · `SHINDONG→SHINDONG` · `PETER2→PETER`.
  `OPERATOR_MANUAL`·`BROKER_SYNC_RECOVERY` 등 운영 출처는 **항상 통과**(주체와 무관).

### 3-2. 실주문 관문 — `_ts_execute_entry` 맨 앞 1곳
- 출처의 주체 ≠ 선택 주체 → 주문하지 않고 `[PrincipalBlock]` + 섀도 기록 후 반환.
- **청산 경로는 건드리지 않는다**(하드스톱·15:10·CB·EmergencyExit) — 들고 있는 포지션은 반드시 닫는다.
- 수동 진입은 `entry_source="OPERATOR_MANUAL"` 을 명시해 넘긴다(지금은 SYSTEM_AUTO 로 들어간 뒤 덮어써
  관문에 막힌다).

### 3-3. 주체별
- **피터**: 실효 모드 = 설정 `live` **그리고** 선택 주체 PETER 일 때만 `live`, 아니면 `shadow`(기존 섀도 분기).
- **미륵 섀도(D5)**: 관문이 막은 `SYSTEM_AUTO` 진입을 `data/principal/<날짜>/mireuk_shadow.jsonl` 에 기록
  (방향·가격·수량·ATR·등급·호라이즌·손절배수). 장후 `mireuk_shadow_eval` 이 1분봉으로 **단순화 가상 손익**
  (하드스톱 + 호라이즌 TP1 전량 + 15:10, CREON 요율)을 산출. ⚠ 실제 청산 사다리(TP1~3·계단·트레일)와 다르다.
- **신동 실행기**: `_run_shindong` 직후 같은 분.
  - 새 MAIN `OPEN` 거래(라이브 탐지, 진입봉이 최근 2분 이내, 미집행) → 선택 주체가 SHINDONG 이면
    **2계약** `entry_source="SHINDONG"` 진입, 외부 손절 = `stop_now`(재난 손절/트레일), 목표 = `t1`(익절 12pt).
  - 매분 `stop_now` 이 유리하게 움직이면 외부 손절을 조인다(트레일 승계).
  - 재생에서 그 거래가 `CLOSED` 가 되면(TR/SL/TP/TIME) 실포지션도 시장가 청산(미러).
  - `RETRACTED`(원천 재수신으로 신호 소멸)는 **청산 사유가 아니다** — 마지막 손절·목표로 계속 관리, 로그만.
  - 15:05(규격 시간청산)에 미청산이면 시장가 청산. 15:10 강제청산은 그대로 뒤를 받친다.
  - 집행 키는 `data/principal/<날짜>/shindong_exec.json` 에 남겨 재기동 중복 진입을 막는다.
- **외부 손절·목표 일반화**: `EXTERNAL_ENTRY_SOURCES = (PETER2, SHINDONG)`. 켈리·앙상블 학습 격리도 같은 집합.
  CB② 는 계좌 안전장치라 센다(피터2 와 같은 결정).

## 5. 위험·영향

- **실전 전환 기준 ①**: 미륵이 아닌 주체가 선택된 날은 미륵 실거래 표본이 없고 `broker_net_krw` 에 다른 주체
  손익이 섞인다 → ① 판정은 주체별로, 그날은 창에서 표시·제외해야 한다(주간회의 안건).
- **CB②·15:10**: 계좌 단위로 모든 주체에 적용된다.
- **신동 실집행 괴리**: 규격 진입가 = 진입봉 종가, 실집행 = 그 직후 시장가 → 슬리피지·지연만큼 다르다.
  트레일·청산은 1분봉 완성 뒤 판정(재생)과 틱 판정(엔진 손절)이 섞인다.
- **피터**: 오프셋·수집 지연은 615차 후속2 로 별도 진행 중.
