## 3. 아직 검증하지 못한 것 (라이브 첫날 확인)

1. **신동 실주문 경로** — 신동을 켠 날 첫 신호에서 `[ShindongLive] 진입 … 2계약` → 체결 →
   `[ShindongLive] 손절 … (재생 stop_now)` / `신동익절` / `신동미러:…` / `신동시간청산` 순서가 나오는지.
2. **잔고 표시** — 주체 실적이 첫 줄, 계좌 값이 둘째 줄로 나오는지. 수익율 분모는 오늘 예탁현금 기준선
   (`_broker_dep_base_today`)이며 없으면 계좌 수익율이 그대로 보인다.
3. **전환** — FLAT 에서 전환 → `[Principal] 거래주체 전환` 로그, 보유 중이면 버튼이 잠기는지.
4. **미륵 섀도** — 미륵이 아닌 주체 날 `[PrincipalBlock] 미륵 진입 → 섀도` 와 장후 `[MireukShadow]`.
