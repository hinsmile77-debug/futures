## 0. 한 줄 결론

**당일 고점·저점은 「어느 가격이 저항인가」로는 못 맞히고, 「시가에서 얼마나 갈 것인가」로는 맞힌다.**
그래서 두 모델을 만들되 **거리 모델을 주력**으로, **구조 모델은 참고용 후보**로 산출한다.
26주 워크포워드 검증에서 거리 모델은 MAE 14.2pt·80% 구간 커버리지 78%였고, 구조 모델은 **무작위 레벨과
구분되지 않았다**(극값 안착 49.6% vs 무작위 47.1%). 두 모델을 함께 내되 **구조 모델에 신뢰 문구를 붙이지 않는다.**

| | 거리 모델 | 구조 모델 |
|---|---|---|
| 예측 대상 | 고점·저점의 **가격 + 50%/80% 구간** | 상방 3개 / 하방 3개 **후보 레벨** |
| 검증 | MAE 14.2pt(08:50) / 11.0pt(09:30), 80% 구간 78% / 74% | 무작위와 구분 불가(모든 지표) |
| 용도 | 목표가·기대 진폭·리스크 폭 | 참고 후보(합류 근거 표기) |
| 판단 연결 | **하지 않는다**(관측·기록만) | **하지 않는다** |

## 1. 개념 — 왜 이렇게 갈렸는가

### 1-1. 출발점

2026-09-04 08:50에 외부 트레이더가 낸 KOSPI200 선물 저항선 1049 / 1057 / 1063이 그날 그대로 마디로 작용했다
(09:00~12:59 1049 상단 봉쇄, 14:19 **1063.85 일중 고점** 반전). 그 세 수를 역산하니 피봇·카마릴라·피보나치·
ATR 배수·이동평균 어느 공식으로도 안 나오고, **전일 이전 세션의 구조적 가격**(매물대·갭 가장자리·전일 고저·
VWAP·옵션 OI 행사가)에서만 셋 다 나왔다. 그래서 구조 모델을 먼저 만들었다.

### 1-2. 검증이 뒤집은 것

26주(144~249세션) 워크포워드로 재니 **구조 레벨은 무작위와 구분되지 않았다.**

| 지표 | 구조 레벨 | 무작위(ATR 정규화 거리 셔플) | 판정 |
|---|---|---|---|
| 일중 극값 ±0.5% 안착 | 49.6% | 47.1% | 차이없음 |
| 레벨 ±0.098ATR 체류 분 | 71.5분 | 71.3분 | 차이없음 |
| 첫 터치 후 되돌림 우선(±1.0%) | **44.0%** | 49.2% | **열세** (무작위보행 귀무값 50%) |
| 정거장률(체류 ≥ 무작위 75분위) | 28.6% | 26.9% | 차이없음 |

> **터치율은 지표가 아니다.** 일중 가격 경로는 연속이라 레벨이 그날 범위 안이면 반드시 터치된다.
> 터치율 80%는 「레벨이 맞았다」가 아니라 「레벨이 범위 안이었다」이고, 무작위도 78%다. **쓰지 말 것.**

반면 **거리에는 정보가 있었다.** 시가 ± k·ATR 투영은 자기 대조군을 2배 이겼고(40% vs 26%), 극값까지의
거리를 0.30 ATR 오차로 예측했다. 결정적 실험: 라운드 10pt 격자(구조 정보 0)가 구조 4원천보다 극값을 더 자주
담았고(63% vs 49.6%), 그 격자를 3pt 옆으로 밀어도 62%로 같았다 — **중요한 것은 「어디에」가 아니라
「얼마나 촘촘하고 얼마나 멀리까지」였다.**

### 1-3. 그래서 설계

- **거리 모델**: 오늘 얼마나 움직일지를 최근 변동성으로 예측하고, 그 거리를 시가에 더한다. 점추정 + 구간.
- **구조 모델**: 그 거리 근처에 무엇이 있는지를 **참고로만** 보여준다. 예측력을 주장하지 않는다.
- 두 모델을 같은 두 시점(08:50 / 09:30)에 내고, 장후에 **둘 다 채점**한다.

## 2. 거리 모델 — 개념과 수식

### 2-1. 정의

| 기호 | 뜻 |
|---|---|
| O | 당일 첫 봉(08:45) 시가 |
| H, L | 당일 고가·저가 (= 상→하 되돌림 고점, 하→상 되돌림 저점) |
| ATR14 | **전일까지** 14세션 True Range 평균 |
| u, d | (H − O)/ATR14, (O − L)/ATR14 — 예측 대상 |

### 2-2. 1단계 M1 (08:50) — 훈련창 중앙값

```
med_u = median(u_i),  med_d = median(d_i)      # 직전 60세션
고점 = O + med_u × ATR14
저점 = O − med_d × ATR14
```

구간은 훈련 잔차 `r = u_i − med_u`의 분위로 만든다(정규분포 가정 없음).

```
고점 50% 구간 = O + (med_u + q25(r_u))×ATR  ~  O + (med_u + q75(r_u))×ATR
고점 80% 구간 = O + (med_u + q10(r_u))×ATR  ~  O + (med_u + q90(r_u))×ATR
저점은 부호를 뒤집어 같은 방식 (하한/상한이 바뀌므로 min/max로 정렬할 것)
```

2026-09-03 마감 기준 실측: **med_u = 0.27, med_d = 0.41** (하방이 큰 것은 6~8월 하락장 때문. 매일 갱신된다).

### 2-3. 2단계 P1 (09:30) — 경로 회귀

09:30까지의 그날 경로를 넣어 다시 낸다. **미륵 피처(매크로·수급·CVD 등)는 넣지 않는다**(§2-5).

```
설명변수 x = [1, gap, r1, u_T, d_T, ret_T]
  gap   = (O − 전일종가)/ATR
  r1    = (전일고 − 전일저)/ATR
  u_T   = (09:30까지 고가 − O)/ATR
  d_T   = (O − 09:30까지 저가)/ATR
  ret_T = (09:30 종가 − O)/ATR

u_hat = x · β_u   (β는 최소절대편차 = 중앙값 회귀)
고점 = O + max(u_hat, u_T) × ATR        # ← 경로 하한: 이미 난 고가보다 낮게 예측하지 않는다
저점 = O − max(d_hat, d_T) × ATR
```

잔차도 **하한 적용 후**로 계산해야 구간이 맞는다: `r_u = u_i − max(x_i·β_u, u_T,i)`.

**LAD(최소절대편차) 구현** — 반복 가중 최소제곱(IRLS) 30회. 꼬리가 두꺼운 이 시장에서 OLS보다 안정적이다.

```python
def lad_fit(X, y, iters=30):
    beta = np.linalg.lstsq(X, y, rcond=None)[0]
    for _ in range(iters):
        w = 1.0 / np.maximum(np.abs(y - X @ beta), 1e-3)
        Xw = X * w[:, None]
        beta = np.linalg.lstsq(Xw.T @ X, Xw.T @ y, rcond=None)[0]
    return beta
```

## 3. 구조 모델 — 개념과 수식

### 3-1. 원천 4종 + 옵션 1종

전일까지 **6세션**의 1분봉으로 후보 가격을 모은다.

**(a) 매물대 봉우리** — 거래량이 아니라 **가격이 머문 시간**으로 잰다.

```
① 각 봉이 지나간 0.5pt 구간마다 +1분   (저가~고가 사이 전 구간)
② 평활: sm[b] = dwell[b−0.5] + dwell[b] + dwell[b+0.5]
③ 봉우리 판정: sm[b] ≥ 60분  그리고  sm[b] == max(sm[x] for |x−b| ≤ 2.0pt)
```

거래량을 안 쓰는 이유: 1분봉 거래량은 개장·마감에 몰려 히스토그램이 그쪽으로 쏠린다. 사람이 차트에서
"선반"으로 읽는 것은 **머문 시간**이다(09/03의 76분 선반, 08/31의 49분 선반).

**(b) 갭 변** — 연속 두 세션의 고저 범위가 겹치지 않으면 그 빈 구간의 양 끝.

```
A(앞날) 고가 < B(다음날) 저가  →  갭 하변 = A고가,  갭 상변 = B저가
A(앞날) 저가 > B(다음날) 고가  →  갭 상변 = A저가,  갭 하변 = B고가
```

시가 갭이 있어도 장중에 겹치면 갭이 아니다. **주의**: 갭업 다음날 갭다운으로 열린 "섬" 세션은 한 가격이
두 갭의 변으로 잡혀 합류가 부풀려진다 — 중복 제거 필요(마흐디 미구현 항목).

**(c) 전일 고·저 / 전일 세션 VWAP / 4세션 VWAP** — VWAP은 Σ(종가×거래량)/Σ거래량. "4세션"은 직전 4거래일.

**(d) 옵션 OI 상위 행사가** — 전일 마감 체인의 행사가별 (콜+풋, 전 만기) OI 합 상위 3.
미륵에는 옵션 체인 스냅샷이 없으므로 **Phase 2 이후 선택 사항**(§6-4). 검증에서 이 원천을 넣으면 오히려
극값 안착이 44.3% → 41.8%로 **내려갔다**(ATM±2 창의 행사가가 "가까운 3개"의 자리를 차지하기 때문).

### 3-2. 병합과 선택

```
① 후보 가격을 정수로 반올림
② 1.5pt 안의 후보들을 한 레벨로 합침 → 근거 목록의 길이가 "합류"
③ 기준가 위로 가까운 3개 = 상방 1·2·3차, 아래로 3개 = 하방
   (기준가 ±1pt 안은 어느 쪽도 아님)
```

09:30 재산출에서는 **오프닝 레인지 고·저**(08:45~09:30)를 후보에 더하고 기준가를 09:30 종가로 바꾼다.

### 3-3. 합류(合流)의 뜻과 한계

합류 = 서로 다른 원천이 같은 자리를 가리킨 개수. 09/04 상방 1차 1048은 「매물대 1048.0(359분/3세션)」과
「4세션 VWAP 1048.8」이 0.8pt 차이로 겹쳐 합류 2였다.

**합류가 높을수록 잘 맞는지는 확인되지 않았다.** 층화 검정을 사전 등록했으나 레벨 전체가 무작위와 구분되지
않아 검정까지 가지 못했다. 합류는 **근거 표기 방식**이지 예측력 점수가 아니다.

| 창 | 극값 안착 ±0.5% | 무작위 | 되돌림 우선 ±1.0% | 정거장률 T75 |
|---|---|---|---|---|
| 2026-01~09 (144세션) | 49.6% | 47.1% | 44.0% (귀무 50%) | 28.6% vs 26.9% |
| 2026-07~09 (45세션) | 44.3% | 43.0% | 46.4% | 27.0% vs 26.6% |

09:30 재산출도 마찬가지다. 「09:30 이후 극값」을 표적으로 하면 53.8% vs 무작위 50.9% — 절대치는 오르지만
대조군도 같이 올라 **초과분은 +2.9%p로 차이없음**이다(현재가가 시가보다 남은 구간 극값에 가깝기 때문).

조사한 다른 원천 14종(플로어 피봇·카마릴라·거래량 POC/VAH/VAL·VWAP ±σ·이동평균 5/20/60·라운드·전주 고저·
20세션 고저·전일 스윙·선반 가장자리·감마 월) **어느 것도 개선하지 못했다.**

## 4. 산출 시점 규격 — 08:50 / 09:30

| | 08:50 | 09:30 (재산출) |
|---|---|---|
| 기준가 | 당일 08:45 시가 | 09:30 종가(현재가) |
| 거리 모델 | M1 (훈련창 중앙값) | P1 (경로 회귀 + 경로 하한) |
| 구조 후보 | 전일까지 6세션 | + 오프닝 레인지 고·저 |
| 필요 데이터 | 08:45 봉 1개 | 08:45~09:30 봉 45개 |
| 산출 실패 조건 | 훈련 세션 < 30 → **거리 모델 미산출**(지어내지 않는다) | 09:30 이전 봉 < 5개 → 미산출 |

**굳히기(freeze)**: 한 번 산출한 단계는 다시 계산하지 않는다. 09:30 산출을 09:40에 실행해도 컷은 같지만,
**처음 계산한 값을 DB에 굳혀** 장후 채점이 화면·로그와 같은 수를 보게 한다.

**왜 09:30인가**: 09:05는 개선이 작고(MAE 13.2), 10:00은 더 좋지만(9.8) 하루의 1/5가 지나 "예측"의 의미가
줄어든다. 09:30이 개선폭(14.2→11.0)과 시의성의 균형점이다.

## 5. R̂ 스케일링 — 구간 폭의 변동성 보정 (채택)

### 5-1. 문제

전체 잔차 하나로 구간을 만들면 시장 상태가 섞인다. 조용한 날은 **과신**(80% 구간이 실제 64~72%),
시끄러운 날은 **과소신**(83%)이 된다.

### 5-2. 방법

당일 실현 범위 `R = (H−L)/O`를 log 회귀로 예측(R̂)하고, 구간 잔차 분위에 **R̂ / 훈련중앙R** 배수를 곱한다.

```
08:50 회귀 x = [1, log(ATR14/O), log(ATR5/ATR14), log(전일범위/ATR14), gap, |gap|, 전일종가위치]
09:30 회귀 x = 위 7개 + [log(u_T + d_T), |ret_T|]
scale = clip(exp(x·β) / median_R, 하한 0.85, 상한 2.0)
구간 = 잔차분위 × scale
```

### 5-3. 하한 선택 근거 (144세션 실측)

| 하한 | 08:50 커버리지 / 폭 | 09:30 커버리지 / 폭 | 09:30 실현분위 조/중/시 |
|---|---|---|---|
| 스케일 없음 | 78% / 4.68% | 74% / 3.09% | 93 / 79 / **59** |
| 0 (하한 없음) | 79% / 4.78% | 77% / 3.05% | 85 / 74 / 75 |
| **0.85 (채택)** | **83% / 4.82%** | **81% / 3.07%** | 93 / 80 / 75 |
| 1.0 (넓히기만) | 85% / 5.21% | 83% / 3.37% | 96 / 84 / 76 |

**하한 0.85 채택**: 폭이 거의 그대로(+3% / −1%)인데 커버리지가 명목 80%에 닿고, 시끄러운 날 과소신 59→75%,
조용한 날 과신 64→71%로 좁혀진다. 하한 1.0은 폭이 9~11% 넓어져 "넓혀서 맞춘 것"이다.

**중요**: 스케일 전 구간(raw)도 **함께 저장**한다. 장후 채점이 두 구간을 나란히 세어야 채택의 손익이
누적으로 검증된다.

### 5-4. 하지 말 것 — 부분집합 방식

"예측 분위에 해당하는 훈련일의 잔차만 쓰기"는 **해롭다**(커버리지 6%p 하락). 분위당 훈련일이 20일로 줄어
분위값이 요동치고, 오분류된 날에 좁은 구간을 씌운다. 스케일링만 쓴다.
