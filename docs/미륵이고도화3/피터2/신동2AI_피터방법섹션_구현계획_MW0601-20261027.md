## 4. 순서와 일정

```
Phase 0 사전등록 ─┐
Phase 1 신선도 ───┤ (독립 · 바로 착수 가능 · 다음 장전 전에 배포 가능)
Phase 2 피터 계측 ┘
        ↓
Phase 3 P층 레벨 → Phase 4 상자·백필(장후) → Phase 5 학습 연결 → Phase 6 운영 반영
```

- **1차 배포**(Phase 0–2): 계측만 늘리고 판단은 바꾸지 않는다. 장중 경로를 건드리므로 첫날 장중 점검 대상이다(일일 점검 흐름표 12:25).
- **2차 배포**(Phase 3–4): 섀도로 표시하고 채점만 한다. 백필 판정이 나오기 전에는 해설 근거로 쓰지 않는다.
- **3차 배포**(Phase 5–6): 레슨·지표 후보 등록과 SKILL 운영 반영. 승격은 기존 규칙(적용 3회·적중 우세 / verify PASS + 사용자 확인)을 따른다.
