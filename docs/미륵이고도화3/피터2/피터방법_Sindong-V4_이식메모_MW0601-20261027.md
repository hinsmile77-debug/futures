## 3. MW0602 가 할 일

1. **백필(장외)** — 결과를 보고 문턱을 바꾸지 말 것(458차 D6).
   - `conda run --no-capture-output -n py310_64 python scripts/peter_method_backfill.py` → `피터방법_백필검증_MW0602-<날짜>.md`
   - `conda run --no-capture-output -n py310_64 python scripts/machine_speed_backfill.py` → `기계속도_백필검증_MW0602-<날짜>.md`
     (I9 verify 가 `indicators_MW0602.json` 에 I9 를 자동 등록한다. 표본 창은 사전등록대로 08-10 – 10-26 · 10-27 제외)
2. **지표 ID** — `indicators_MW0602.json` 은 I1–I5 사용 중(플러그인 i1–i3). 이식한 I6–I9 와 겹치지 않는 것을 확인했다(2026-10-27). 이후 MW0602 가 새 I-n 을 만들 때 I6–I9 를 피할 것.
3. **레슨** — `lessons_MW0602.json` 다음 번호로 두 개 등록(MW0601 L25·L26 에 해당):
   봉 신선도(축 계측) · 피터 상자·P맥점은 참고 레벨(축 확률). ⚠ `lesson add` 인자에 `—`·`−` 를 쓰면 conda 가 `?` 로 깨뜨린다.
4. **피터 실시간 수집이 꺼져 있다(639차)** — 이 PC 에서는:
   - 장중 snapshot 「피터 HH:MM」 줄·피터 관점 이벤트·I6 이 **미측정**으로 뜬다(「관점 없음」이 아니다). follower VIEW/NOFACT 도 생기지 않는다(무해).
   - 15:55 `pmethod` 는 16:30 `peter_pull` 전이라 피터 관점 채점이 비어 있다 → pull 뒤 `python scripts/shindong2_live.py pmethod --date <그날>` 을 한 번 더 돌리면 같은 날 줄을 교체한다.
   - P층·상자·봉 신선도·기계 속도는 피터 수집과 무관하게 동작한다(`raw_program_trade` 는 MW0602 에도 있다 — 확인).
5. **테스트** — 이식 작업트리에서 관련 36파일: 이식으로 새로 깨진 것 0(test_640 은 위 ID 수정으로 해결). 같은 묶음에서 원본 Sindong-V4 에도 이미 실패하던 12건(test_457 peter_paste · test_610 ×4 · test_640 test_5·6 · test_677 · test_690 ×4)은 작업트리에 `data/` 가 없는 환경 탓이 섞였을 수 있다 — MW0602 본 작업트리에서 한 번 확인해 주세요.
