## 4. MW0602 환경 준비

1. **Chrome 확장**: 미륵이 PC의 Chrome(X에 로그인된 프로필)에서 `chrome://extensions` → 개발자 모드 → 압축해제 로드 → `<futures>\tools\peter2_live\extension`.

   - 수신기 확인: `python tools/peter2_live/receiver.py --check` → `"posts"`가 늘어야 한다.

| 함정 | 증상 | 대응 |
|---|---|---|
| Windows `SO_REUSEADDR` | 수신기 두 개가 같은 포트에 동시에 뜬다 | `SO_EXCLUSIVEADDRUSE`(이미 반영됨) |
| 백그라운드 탭 타이머 | Chrome이 숨은 탭 타이머를 분당 1회로 묶는다 | 확장 서비스워커 알람이 새로고침을 쥔다(반영됨) |
| heredoc 이스케이프 | `\\t` → 탭 문자, `\\` 줄 이어붙임 | 패치 스크립트는 파일로 쓰고 실행할 것 |
| 결산 트윗 | 「972 또는 974 매도. 손절가 980 = 6-8P 손실」이 진입으로 읽힌다 | `_RECAP` 가드(반영됨). 새 문형은 테스트에 추가 |
| 진입 앞 손절 보고 | 「1047 손절. / 1049 돌파시 매수」에서 앞 손절을 버린다 | 문장 순서로 구분(반영됨) |
| `ui_prefs.json` 의존 테스트 | 손익 패널 테스트가 사용자 화면 설정에 따라 실패한다 | 환경 문제다. 수정 전 코드와 같은 설정으로 대조해 가를 것 |
