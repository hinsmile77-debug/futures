### 3-1. 진입 판정(대기 지시 → 진입)

지시가 오면 바로 사지 않고 **대기(ARMED)** 로 둔다. 2초마다 미니 현재가 `p`를 지시가(미니 환산) 범위 `[lo, hi]`에 대 본다.

| 지시 유형 | 진입 조건 | 예 |
|---|---|---|
| 상향 돌파 매수 | `lo − 0.2 ≤ p ≤ hi + 1.0` | 「1105 돌파시 매수」 |
| 하방 돌파 매도 | `lo − 1.0 ≤ p ≤ hi + 0.2` | 「1096 하방 돌파시 매도」 |
| 지정 매수(눌림·범위·그냥) | `p ≤ hi + 1.0` | 「1050까지 내려오면 매수」「1035-36에서 매수」 |
| 지정 매도 | `p ≥ lo − 1.0` | 「1102 오면 매도」 |
| 그가 「체결」을 알렸다 | 위 조건에 더해, `|p − 지시가| ≤ 1.0`이면 진입 | 「1096 매도 체결.」 |

- **추격 금지**: 1.0pt 넘게 불리하면 들어가지 않고 기다린다.
- **해제 조건**: 10분 경과, 진입 전에 손절가 도달, 그가 취소·청산함, 미륵이 보유 중, 14:50 이후.

### 3-2. 손절·청산

| 그의 트윗 | 피터2 행동 |
|---|---|
| 진입 트윗의 손절가 | 진입 시 외부 손절. 없으면 ±4pt(`stop_src=default`). 진입가에서 8pt 넘게 멀면 캡. |
| 「손절가 N로 변경」 | 외부 손절 갱신. **불리한 쪽 이동도 따른다**(추종의 정의). 캡 8pt는 유지. |
| 「청산가 N」 | 외부 목표. 2초 폴링에서 도달하면 시장가로 청산. |
| 「N 이탈하면 청산」 | 손절을 N으로 끌어올린다. 단, 지금 바로 걸리지 않고 더 조이는 경우에만. |
| 「N 손절」「N 청산체결」 | **미러 청산**(시장가). 그가 나갔으면 우리도 나간다. |
| 보유 중 반대 방향 진입 지시 | 미러 청산 후 새 지시 대기 |

틱 손절은 기존 틱 하드스톱이 그대로 처리한다(`stop_price = ext_stop`).
15:10 강제청산·15:18 안전망·CB⑤·킬스위치는 피터2 포지션에도 그대로 적용된다.
