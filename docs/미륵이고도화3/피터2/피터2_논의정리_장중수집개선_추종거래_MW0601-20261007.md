## 1. 출발점 — 「장중 피터 트윗 수집」은 실제로 돌고 있었나

### 1-1. 설계상 흐름(기존 `peter-daily` 스킬)

- **장중**: Claude가 Chrome에서 X 검색(`from:PeterLeejoa since_time/until_time`)을 열어 트윗을 긁는다. 결과는 `tools/peter_capture.py`로 `data/peter_feed/_raw/<날짜>.jsonl`에 **받아 적기만** 한다. 해석하지 않고 DB도 건드리지 않는다.

  3. 월간 문서를 낸다.
  4. `peter-feed` 브랜치로 push → MW0602가 pull한다.
- **장중에도 받아 적는 이유**: 그는 트윗을 **지운다**. 2026-08에 08-18 장중 전체와 08-11 10:17 이전 트윗이 사라졌고, 두 날 모두 손실이 컸다.

## 5. 피터 추종 거래 — 해석·판단·집행

### 5-1. 해석(`strategy/peter2/parse.py`)

트윗을 문장 단위로 사실(fact)로 바꾼다. 진입은 **좁게**, 청산은 **넓게** 읽는다. 진입을 잘못 읽으면 주문이 나가지만, 청산은 위험을 줄이는 쪽이기 때문이다.

| 사실 | 문형 예 |
|---|---|
| 진입 | 「N 돌파시 매수」「N 하방 돌파시 매도」「N까지 내려오면 매수」「1035-36에서 매수」「1045나 46에서 매수」「1079 지금 매도」 |
| 체결 | 「N 매도 체결.」「1010체결됨」「1085-7에서 매수 체결」 |
| 손절가 | 「손절가 1111로 변경」「손절가 다시 변경 1113」「손절가 1116 입니다」 |
| 청산가 | 「청산가 N」「N 청산가로 변경」「N 청산으로 변경」「청산은 N에서」「그냥 N에 청산하자」 |
| 조건 청산 | 「만약 995 이탈하면 청산해」「밀리면 985에 수익실현」 → 손절 끌어올림 |
| 청산 완료 | 「N 손절.」「N 청산체결」「N 청산완료」「N 수익 청산」 |
| 취소 | 「매수금지」「매수하면 안됨」 |

**진입으로 읽지 않는 것**(전 기간 393줄로 검증):
- 결산(「= 6p 손실」)
- 인용(「'1110 갈거니까…'」)
- 보고서(「[피터리 - 8월 선물매매 내역]」)
- 계획·가정(「예정」「생각」「가능」「대기」「관망」)
- 보유분(「매수분」)
- 회고(「매수를 외친건」)
- 다른 상품(코스닥·삼전 등)

### 5-2. 판단(`strategy/peter2/follower.py`)

지시가 오면 바로 사지 않고 **대기(ARMED)** 로 둔다. 2초마다 미니 현재가를 지시가(+offset)에 대 본다.

| 지시 | 진입 조건 |
|---|---|
| 상향 돌파 매수 | `lo − 0.2 ≤ p ≤ hi + 1.0` |
| 하방 돌파 매도 | `lo − 1.0 ≤ p ≤ hi + 0.2` |
| 지정 매수 / 매도 | `p ≤ hi + 1.0` / `p ≥ lo − 1.0` |
| 그가 「체결」을 알림 | 위 조건에 더해 `|p − 지시가| ≤ 1.0`이면 진입 |

- **추격 금지**: 1.0pt 넘게 불리하면 들어가지 않는다.
- **해제 조건**: 10분 경과, 진입 전 손절가 도달, 취소·청산 트윗, 미륵이 보유 중(D1), 14:50 이후, 일 최대 진입 6회.
- **손절·청산**: 진입 트윗의 손절가로 연다. 손절가가 없으면 ±4pt, 진입가에서 8pt 넘게 멀면 캡. 「손절가 변경」은 **불리한 쪽 이동도 따른다**(추종의 정의). 「청산가」는 도달 시 청산한다. 「N 손절/청산체결」은 **미러 청산**이다.
- 그의 포지션을 따로 추적해 **실시간 `_tr` 거래줄**을 만든다.
- 재기동되면 그날 트윗을 재생해 복원한다. 이미 집행한 지시 id를 기억해 중복 진입을 막는다.

### 5-3. 집행(main.py · PositionTracker)

- QTimer 2초 → 게이트(모드·수집기 하트비트·엔진 FLAT·CB·킬스위치·14:50·15:10) → `_execute_entry(entry_source=PETER2)` 1계약.
- `PositionTracker.ext_stop/ext_target`은 **PETER2 포지션일 때만** ATR 손절·TP1–3·손절계단·트레일링을 덮는다. 비-PETER2 포지션에 남은 값은 폐기한다.
- 15:10 강제청산·15:18 안전망·CB⑤·킬스위치는 그대로 적용된다.
- `_post_exit`: **CB에는 계수**(D2). **켈리·앙상블 학습에는 제외**한다(미륵이 판단이 아닌 거래가 미륵이 학습을 움직이면 안 된다). 청산 후 쿨다운도 면제한다(그는 손절 직후 재진입한다).
- 출처 분류 **`external`** 을 신설했다. PETER2는 system이 아니므로 전환기준 ①과 ProfitGuard 「자동」에서 빠진다.
