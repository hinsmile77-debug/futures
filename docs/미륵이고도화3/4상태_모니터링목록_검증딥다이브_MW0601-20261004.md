# 4상태 실시간 모니터링 목록 — 미륵이 데이터 검증 딥다이브

> MW0601 · 2026-10-04 · 읽기전용(장외) 분석 · 코드·설정 변경 없음
> 입력: 사용자 제시 「장세 상태 4종 + 상태별 진입·청산 가이드」
> 기간: 2026-09-21 – 10-02 (8거래일, 행사가별 OI 열은 09-28 – 10-02 5거래일)

## 0. 결론

1. **상태표의 「먼스리(본월물)」 열은 지금 미륵이 데이터로 측정할 수 없다.** 네 상태 모두 「외곽 콜매수·풋매도」「콜매도 벽」「양매도」처럼 행사가별 **투자자·매수매도 방향**을 요구하는데, 미륵이가 가진 것은 행사가별 OI 합계(참여자·방향 구분 없음)와 상품 단위 투자자 순매수뿐이다. 행사가별 투자자 자료는 HTS [9842] 수동 내보내기 하루 1장이 전부다.
2. **8거래일(OI는 5거래일)은 상태 목록을 확정할 표본이 아니다.** 게다가 이 기간은 **하락 편향**(8일 합계 −29.8pt, 하락일 5일 중 −22·−25pt 급락일 2일)이라 매도 쪽 규칙이 저절로 좋아 보인다. 아래 결론은 「확정」이 아니라 **「방향 관찰 + 사전등록 대상 선별」**이다.
3. **4상태 중 그대로 쓸 수 있는 것은 없다.**
   - **S3 「하방 경직·숏스퀴즈」는 정의와 반대 방향이다.** 「지지 터치 후 유지」는 반등이 아니라 **하락 지속 경고**였다(30분 뒤 평균 −2.0pt, 양수 28%, 날짜 평균 제거 후에도 8일 중 7일 음수). 위클리 콜 V자 반전을 붙여도 아무것도 바뀌지 않는다(p=0.81).
   - **S4 「가두리」는 흐름 조건을 붙이면 거의 비고(2,928분 중 17분), 박스 핑퐁 가이드는 10전 0승 −35pt다.**
   - **S1 「상방 드라이브」의 흐름 조건(위클리 콜 가파름)은 10/1 하루(+28pt)의 산물이다.** 그날을 빼면 p=0.28.
   - **S2 「하방 드라이브」의 흐름 조건(위클리 풋 가파름)은 정보가 없다**(p=0.19–0.28). 오히려 외인 선물 급매도는 하락 **둔화** 쪽이었다(보수 검정에서는 소멸).
4. **흐름 신호 중 방향이 가장 일관된 것은 「근월 위클리 외인 풋 순매수 10분 증가 → 30분 뒤 하락」**이다(가격 상승 중 8일 중 7일 음수, 날짜 내 순열 p 0.001–0.03). 그러나 비중첩 표본으로 솎으면 유의성이 사라진다(p 0.32). **사전등록 후보**이지 규칙이 아니다.
5. **가이드 시뮬**: 흐름 조건을 붙인 가이드는 8일간 **1–4건**만 발동해 평가 불가. 가격 전용 중 「맥점 하향 이탈 매도」가 +46pt로 가장 좋아 보이지만 같은 보유시간의 무작위 매도 위약도 +14pt이고 p=0.066이라 **추세 편향을 넘는 근거가 없다.** 「풋 유입 즉시 청산」은 롱 가이드를 +12 → −0.1로 망가뜨렸다(절반의 분이 풋 증가라 너무 자주 끊긴다).
6. **지금 데이터로 지지되는 것은 「하지 말 것」 둘이다**: ① 박스 핑퐁 매매 금지 ② 지지 터치 유지 자리에서 변곡 매수 금지(30분 안에 지지가 깨질 확률 40% vs +3pt 반등 20%).
7. 개정 상태 목록(§5)과 가이드(§6)는 **근거 등급**을 달아 제시하고, §8에 20거래일 사전등록 재검정 기준을 고정한다. §7의 수집 개선(행사가×주체) 없이는 상태표의 절반이 영원히 미측정으로 남는다.
