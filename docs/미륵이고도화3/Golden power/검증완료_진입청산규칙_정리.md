# 【 숏 규칙 】 압축돌파 · 하락추세 한정 · 60분

## 진입 시점

| 항목 | 조건 |
|---|---|
| **① 진입대기(압축)** | GB ≤ 0.5 **AND** GS ≤ 0.5 **AND** \|GB − GS\| ≤ 0.5 |
| **압축 유효기간** | 압축 발생 후 **10봉 이내** |
| **② 트리거** | `gp_bear_20` (GS) 가 **0.5 상향돌파** **AND** GB ≤ 0.10 |
| **③ 국면 필터** | **MA20 < MA60 (필수)** |
| **진입 타이밍** | 즉시 — 다음 봉 |
| **시간창** | 09:20 ~ 14:50 |
| **횟수 제한** | **당일 최초 1회만** |

**❗ 국면 필터는 선택이 아닙니다.** MA20>MA60 구간만 떼면 **−186.7pt, t=−2.71 (유의한 손실)**. 필터를 빼는 순간 전략이 마이너스로 뒤집힙니다.

## 청산 시점

| 조건 | 값 |
|---|---|
| **주 청산** | **GS ≥ 1.2** 도달 |
| **시간 손절** | 진입 후 60분 |
| **강제 청산** | 15:05 |
| 반대선(GB) 손절 | **사용하지 않음** (1.5 손절은 너무 멀어 손실만 키웠음) |

**GS 1.5 → 1.2 로 낮춘 이유**: 1.5는 GS 분포의 **91백분위**라 도달 자체가 어려워 청산의 47%가 시간만료로 끝났습니다. 1.2는 약 82백분위로 실제로 작동합니다.

## 숏 규칙의 강점

| 검증 | 결과 | 판정 |
|---|---|---|
| 알파 α | +0.452, **t = 2.56** | ✅ 유의 |
| 베타 β | **−0.037, t = −2.81** | ✅ **시장과 반대 — 진짜 독립 수익원** |
| 무작위 대조 (800회) | +75.1 vs −72.5±48.8 → **3.02σ**, 백분위 100% | ✅ 강함 |
| 4분할 안정성 | +3.9 / +25.7 / +4.4 / +41.1 (전부 +) | ✅ 시장 +244 구간에서도 방어 |
| 파라미터 격자 24조합 | 22개 양수 (−10.7 ~ +100.0) | ✅ 고원 위에 있음 |
| 월별 | 14개월 중 11개월 + | ✅ |
| 집중도 | 최대 단일거래 총액의 11%, 상위3 제외해도 +54.6 | ✅ |

**롱과 정반대 성격입니다.** 노출 8.5%로 짧게 치고 빠지며, β가 음수라 롱 편향 포트폴리오에 분산 효과가 있습니다.

## ⚠ 숏 규칙의 한계

| 기준 | 필요 t | 실측 |
|---|---|---|
| 단일 검정 5% | 1.96 | 2.02 ✅ |
| **Bonferroni 5% (탐색 70개)** | **3.38** | 2.02 ❌ |
| 귀무가설 하 기대 최대 t = √(2·ln70) | 2.91 | 2.02 ❌ |

**t=2.02는 70개를 탐색했을 때 우연히 나올 수 있는 최대값(2.91)에도 못 미칩니다.** 무작위 대조 3.02σ(p≈0.0011)를 70으로 보정하면 0.077 — 10% 수준에서만 살아남습니다.
