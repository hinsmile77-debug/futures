## 6. 수익률 향상방안

원칙: **매매 정책 무변경 · 기록 전용 · 사전등록 → 전향 판정 → 승격.** 이번 발견은 전부 데이터를 본 뒤 만든 것이므로
(SOP §11 K-1) 그 자체로는 근거가 아니다. 하드차단은 금지한다(529차 `hard_block_forbidden`, 317차 FalseBlock).

### A. 채택 후보 — 진입 품질 관측 컬럼 2종 + 사전등록 1건 확장

**A-1. GP 모멘텀 정렬 플래그** — `gp_break_entry_watch`(GP 실증 §7) 채널에 **보조 처리군 정의를 지금 고정**해 붙인다.

```
컬럼     gp_mom_align_20   결정분에서 진입 방향의 GP20 선이 ≥0.5 이고 3봉 상향이면 1
소급     정렬 83건 −18,849 / 비정렬 38건 +36,930 (SYSTEM_AUTO, 단일요율)
용도     주 처리군(gp_break_hi/lo=1)과 교차표만 낸다. 판정·승격은 주 처리군 기준 그대로.
```
채널을 하나 더 만들지 않는 이유: 같은 현상(직전 움직임 방향으로 들어가면 진다)의 컷이 이미 사전등록돼 있고,
검정 수를 늘리면 Bonferroni 분모만 커진다. 주 처리군이 판정에 이르면 이 컬럼으로 「극값 종가 컷 vs 기울기 컷」 중
어느 것이 더 날카로운지 **그때** 고른다.

**A-2. 레벨 상태 컬럼** — 534차가 08:50/09:30에 굳힌 레벨을 매분 상태로 바꿔 `ensemble_decisions`에 기록한다.

```
컬럼     lvl_state_struct  ∈ {+1 상향돌파, −1 하향돌파, +2 저점되돌림, −2 고점되돌림, 0}   (구조모델 1차 레벨)
         lvl_state_dist    동일 (거리모델 점추정)
         lvl_stage         0850 / 0930 / none
계산     종가 vs 레벨 + 당일 고/저가의 레벨 터치 여부 — 이미 메모리에 있는 값 4개 비교, DB 접근 없음
채널     level_state_entry_watch   (사전등록, 아래 고정)
  질문   구조모델 되돌림 상태에 **역행**한 진입이 손익을 깎는가
  처리군 lvl_state_struct = ±2 이고 진입 방향이 되돌림 방향과 반대            ← 컷 고정
  대조군 그 외
  소급   정렬 96건 +10,253 / 역행 13건 −63,473  (p=0.23 / 0.69 — 미달)
  판정   일자단위 부호검정 α=0.05 + 최악 3일 제거 부호 유지
  min_samples 40 (역행군, 소급 13 → 약 2~3개월) · min_days 25
  승격   ["checklist_demote", "size_half"] · 하드차단 금지
  비용   단일 실측요율
```
거리모델은 실체결에서 부호가 반대라 처리군에 넣지 않고 **관측만** 한다.

### B. 관측 피처 1종 — 외인 단기 흐름 Δ (26주 WFA L1 후보)

`foreign_flow_d10` = 외인 선물 순매수 **계약수 원값**의 10분 차분(로그압축 전, 3분 갱신 반영). 451차 후속3이 이미

  학습 X는 97개 동결이라 지금 모델에 넣을 수 없다(GP 실증 §6-1). 억지로 넣지 않는다.
