## 0. 왜 기존 검정이 답을 못 주었는가

기존 검증은 총손익 하나로 채점했습니다. 그런데 총손익은

```
총손익 = 신호 품질 × 청산 효율 × 시장 드리프트
```

세 항의 곱입니다. 곱을 하나의 숫자로 보면 어느 항이 기여했는지 분해가 안 됩니다.

> 요리사를 평가하는데 **재료 품질**과 **조리법**을 합쳐서 "맛있다/없다"로만 채점하는 셈입니다.
> 재료가 좋은데 조리를 망친 건지, 재료가 나쁜데 조리로 살린 건지 구분이 안 됩니다.

`손익 432.5 = 베타 255.4 + 알파 177.1` 분해가 오해를 부른 이유도 같습니다. 이 회귀는 우변에 **실현된** 시장 수익률을 놓기 때문에, 신호가 오르는 구간을 골라낸 실력이 전부 베타 항으로 흡수됩니다. **타이밍 능력을 측정하는 게 아니라 정의상 제거하는 회귀**입니다.

참고로 미래를 완벽히 아는 롱 온리 타이머(`PnL = max(R_m, 0)`)를 시장수익률에 회귀하면 β = 0.50, R² ≈ 73%가 나옵니다. **완전예지 전략도 "손익의 73%가 시장"으로 찍힙니다.** 따라서 59%라는 숫자만으로는 유능과 무능을 구분조차 못 합니다.

## 1. 선결 과제 — "90분 최적"의 재판정

문서의 보유시간 표는 아직 확정된 사실이 아닙니다.

전체 211일, 총손익 432.5pt, t = 2.91 → 일평균 SE = 2.050 / 2.91 = **0.705pt**
총손익 SE = 0.705 × 211 ≈ **149pt**

| 보유 | 총손익 | 90분과의 차이 | 149pt 대비 |
|---|---|---|---|
| 60분 | +352.2 | −80.3 | 0.54σ |
| **90분** | **+432.5** | — | — |
| 120분 | +328.2 | −104.3 | 0.70σ |
| 180분 | +354.1 | −78.4 | 0.53σ |

40~180분이 전부 1σ 안에 뭉쳐 있고, 432 → 328 → 354로 **비단조**입니다. 진짜 구조가 있으면 봉우리를 넘어 단조 감소해야 하는데 120분에서 꺼졌다가 180분에서 다시 오릅니다. 노이즈의 지문입니다.

> 안개 속에서 능선을 보는데 봉우리가 세 개로 보입니다.
> 안개(SE 149pt)가 봉우리 높이 차이(80pt)보다 짙어서 어느 게 정상인지 구분이 안 됩니다.

**단, 이건 독립 표본 기준 SE입니다.** 같은 진입에 청산만 바꾼 비교이므로 **쌍대검정**을 써야 하며, 잔차 상관이 높아 SE가 크게 줄어듭니다.

```python
# 587개 진입 고정. 청산 시점만 바꿔 일별 손익 시계열 생성 후 쌍대 비교
d = daily_pnl[90] - daily_pnl[180]          # 211개
t = d.mean() / (d.std(ddof=1) / np.sqrt(len(d)))
print(f"90분 − 180분: {d.sum():+.1f}pt, t={t:.2f}")
```

- **|t| ≥ 2** → 90분 확정. 검정 B의 E1 기준선으로 사용
- **|t| < 2** → 90분을 최적으로 확정하지 말 것. 결론은 "40~180분 구간 어디든 무방"이며 이는 **강건성의 증거**(고원 위)

## 2. 검정 A — GP 신호 품질 (청산 무관)

### A-0. 드리프트 논쟁을 구조적으로 제거하는 설계

대조군을 **같은 날짜·같은 진입 횟수·같은 시간대 분포**로 무작위 배치합니다. 그러면 대조군도 똑같이 드리프트를 먹습니다.

> 조류가 세다고 다투는 대신 **같은 조류에 배 두 척을 띄웁니다.**
> 하나는 신호대로, 하나는 아무 때나. 둘 다 조류를 똑같이 받으니 남는 차이는 조류가 아닙니다.

이 설계에서는 β가 얼마든 무관합니다. **차이만 보므로 드리프트가 산술적으로 상쇄됩니다.**

```python
import numpy as np, pandas as pd

H = 180  # 전방 관측 창(분)

def forward_matrix(bars_by_date, entries, side):
    """entries: [(date, i0)] → (N, H) 전방수익 행렬. side=+1 롱, -1 숏"""
    out = np.full((len(entries), H), np.nan)
    for k, (d, i0) in enumerate(entries):
        c = bars_by_date[d]['close'].values
        px0 = c[i0 + 1]                       # 다음 봉 진입 (지연 0분 규칙 반영)
        n = min(H, len(c) - i0 - 2)
        out[k, :n] = side * (c[i0+2 : i0+2+n] - px0)
    return out

def matched_control(bars_by_date, entries, side, rng, n_rep=1000):
    """날짜별 진입 횟수·시간대 분포를 보존한 무작위 대조군"""
    per_date = pd.Series([d for d, _ in entries]).value_counts()
    hours    = np.array([i0 for _, i0 in entries])       # 시간대 풀
    reps = []
    for _ in range(n_rep):
        fake = []
        for d, cnt in per_date.items():
            L = len(bars_by_date[d])
            cand = hours[(hours > 0) & (hours < L - H - 2)]
            if len(cand) < cnt:
                continue
            fake += [(d, int(x)) for x in rng.choice(cand, cnt, replace=False)]
        reps.append(np.nanmean(forward_matrix(bars_by_date, fake, side), axis=0))
    return np.array(reps)                                 # (n_rep, H)
```

**보존해야 할 세 가지**: 날짜(그날의 변동성·드리프트), 진입 횟수(노출량), 시간대 분포(장중 패턴). 하나라도 안 맞추면 그 차이가 실력으로 위장됩니다.

### A-1. 우위 곡선 Δ(t)

```python
real  = np.nanmean(forward_matrix(bars, long_entries, +1), axis=0)   # (H,)
null  = matched_control(bars, long_entries, +1, rng)                 # (1000, H)

delta = real - null.mean(axis=0)
z     = delta / null.std(axis=0)
```

**총손익이 아니라 곡선의 모양을 읽습니다.**

| Δ(t) 모양 | 해석 | 청산 함의 |
|---|---|---|
| 초반 급상승 후 평평 | 신호가 **순간 정보**를 담음 | 짧게 끊어야 함 |
| 완만히 계속 상승 | 신호가 **국면 정보**를 담음 | 길게 들어도 됨 |
| 상승 후 하락 반전 | **평균회귀**가 뒤따름 | 봉우리에서 나와야 함 |
| 처음부터 평평 (z<1) | **신호에 정보 없음** | 청산 최적화 무의미 |

문서의 지연 표(0분 +432 → 20분 +157)는 신호 시각 자체의 정보를 보여줍니다. Δ(t)는 이를 분 단위 해상도로 다시 그리는 작업입니다. **"신호 유효기간 ≈ 10분, 움직임 지속기간 ≈ 90분"이라는 두 시계 가설이 여기서 검증됩니다.**

### A-2. Edge Ratio — 청산과 완전히 무관한 품질 지표

**검정 A의 주력 지표.** 어떤 청산을 쓰든 값이 변하지 않습니다.

```python
def edge_ratio(fwd, atr0, t):
    mfe =  np.nanmax(fwd[:, :t], axis=1) / atr0    # 유리 편위, ATR 정규화
    mae = -np.nanmin(fwd[:, :t], axis=1) / atr0    # 불리 편위
    return np.nanmean(mfe) / np.nanmean(mae)

for t in [15, 30, 60, 90, 180]:
    er_real = edge_ratio(fwd_real, atr0, t)
    er_null = np.array([edge_ratio(f, atr0, t) for f in null_paths])
    z = (er_real - er_null.mean()) / er_null.std()
    print(f"{t:3d}분  ER={er_real:.3f}  대조 {er_null.mean():.3f}±{er_null.std():.3f}  z={z:+.2f}")
```

> 신호를 받고 진입한 뒤 **얼마나 유리하게 갔다 오는가 ÷ 얼마나 불리하게 갔다 오는가**입니다.
> 등산로가 오르막이 많은지 내리막이 많은지를 재는 것이라, 어디서 하산할지(청산)와 무관합니다.

대조군 ER은 거의 정확히 1.0이 나옵니다. `ER_real > 1`이고 z ≥ 2면 신호가 진짜이며, **초과분이 청산으로 뽑아낼 원재료의 크기**입니다.

ATR 정규화를 넣는 이유는 고변동 세션이 표본을 지배하는 것을 막기 위함입니다. `atr0`은 진입 시점 기준 ATR14(1분봉 기준 또는 일봉 ATR를 분배분).

### A-3. 경로 분포 측정 (검정 B의 입력값 생산)

같은 행렬에서 청산 파라미터의 원천이 되는 통계를 뽑습니다.

| 기호 | 정의 | B에서의 역할 |
|---|---|---|
| `MFE(t)` | 0~t 최대 유리 편위 | **TP 설정 근거** |
| `MAE(t)` | 0~t 최대 불리 편위 | **SL 설정 근거** |
| `t*` | MFE(H) 발생 시각 | 진짜 최적 보유시간 분포 |
| `Giveback` | MFE(H) − R(H) | **트레일링 가치** |
| `R_drift(t)` | `R(t) − β × 시장수익(t)` | 드리프트 제거 순수 신호 |

```python
mfe = np.fmax.accumulate(fwd_real, axis=1)
mae = np.fmin.accumulate(fwd_real, axis=1)
t_star = np.nanargmax(fwd_real, axis=1) + 1

print("t* 분위 :", np.percentile(t_star, [25, 50, 75, 90]))
print("MFE(90) :", np.nanpercentile(mfe[:, 89], [50, 75, 90]))
print("MAE(90) :", np.nanpercentile(mae[:, 89], [10, 20, 50]))
print("반납 중앙:", np.nanmedian(mfe[:, -1] - fwd_real[:, -1]))
```

**반납액(giveback) 중앙값이 정보량이 가장 큽니다.** 롱 거래당 평균이 +0.737pt인데 MFE(90) 중앙값이 +3.0pt라면, 매번 평균 2.3pt를 되돌려주고 있다는 뜻이며 트레일링 하나로 성과가 크게 달라집니다.

`R_drift`는 롱 전용 보조 지표입니다. 노출 62% · β 0.463 조건에서는 보유시간을 늘리면 드리프트가 기계적으로 쌓이므로, 드리프트 미제거 상태로 "몇 분이 최적인가"를 물으면 답이 항상 "길게"로 편향됩니다.

### A-4. 판정 기준 (사전등록 — 실행 전 확정)

| 기준 | 문턱 | 미달 시 |
|---|---|---|
| Δ(t) 최대 z | ≥ 2.0 | 신호 기각 |
| Edge Ratio | ≥ 1.15 **且** z ≥ 2.0 | 신호 기각 |
| **하락구간 부분표본 Δ** | > 0 유지 | 롱: 상승장 전용으로 격하 |

**세 번째 항이 롱의 진짜 시험입니다.** MA20 < MA60 구간 또는 시장 일간수익 음(−)인 날만 잘라 A-1을 재실행합니다. 문서의 부수 발견 **"롱 GB 돌파는 하락추세에서 2배 좋다(120분 +347 vs +178)"** 가 여기서 검증됩니다.

- 살아나면 → 롱은 드리프트 편승이 아니라 **반등 신호**. 상승장 편향 우려가 상당 부분 해소
- 무너지면 → 롱은 상승장 전용. 국면 필터 도입 또는 포지션 축소 검토

**숏은 149거래뿐이라 Δ(t)의 z가 잘 안 나옵니다.** ER은 거래당 통계라 표본 효율이 높으므로 **숏은 ER 중심으로 판정**합니다.

## 3. 검정 B — 청산 기하 (진입 고정)

**검정 A 통과 후에만 진행.** 진입 롱 587 / 숏 149를 고정하고 청산만 교체합니다.

### B-1. 후보를 5개로 제한

문서 상태에서 격자탐색은 금물입니다. 현재 탐색 70개 기준 Bonferroni 문턱이 3.38인데, 후보를 100개 추가하면 문턱이 3.63으로 올라가 **롱(2.91)·숏(2.02) 둘 다 확실히 탈락**합니다.

| | 청산 기하 | 파라미터 결정 방식 |
|---|---|---|
| **E1** | 시간청산 T분 | **현행 고정** (롱 90분 / 숏 GS≥1.2+60분) — 기준선 |
| **E2** | 시간 + 고정 TP | TP = MFE(T) **중앙값** |
| **E3** | 시간 + 고정 SL | SL = MAE 분포 **하위 20% 경계** |
| **E4** | 트레일링 (봉우리 − w) | w = 되돌림 **회복률 변곡점** |
| **E5** | E2 + E3 브래킷 | 위 두 값 그대로 |

**파라미터를 손익 최대화로 고르지 않습니다. 전부 A-3에서 이미 측정한 경로 분포에서 읽어옵니다.**

> 그리드서치는 "열쇠를 100개 만들어 다 꽂아보고 열리는 걸 고르는" 방식입니다.
> 경로 분포는 **자물쇠를 뜯어 내부 구조를 보고 열쇠를 깎는** 방식입니다.
> 전자로 우연히 맞은 열쇠는 실전에서 다시 못 씁니다.

트레일링 폭 `w`도 손익이 아니라 물리적 변곡점에서 읽습니다.

```python
# 봉우리 이후 w만큼 되돌렸을 때, 다시 신고점을 갱신하는 비율
for w in [0.5, 0.8, 1.2, 1.6, 2.0, 2.5]:
    rate = recovery_rate_after_pullback(fwd_real, w)
    print(f"w={w:.1f}pt  되돌림 후 회복률 {rate:.1%}")
```

회복률이 급격히 꺾이는 지점이 `w`입니다. 손익 최대화 값이 아니라 **가격 구조상의 변곡점**이므로 표본 밖에서 버팁니다.

### B-2. 쌍대검정으로 비교

```python
def paired(a, b, name):                       # a, b: 일별 손익 (211,)
    d = a - b
    t = d.mean() / (d.std(ddof=1) / np.sqrt(len(d)))
    print(f"{name}: {d.sum():+7.1f}pt  t={t:+.2f}")

for tag, pnl in [('E2', pnl_e2), ('E3', pnl_e3), ('E4', pnl_e4), ('E5', pnl_e5)]:
    paired(pnl, pnl_e1, f"{tag} vs E1")
```

**E1을 이기려면 |t| ≥ 2 필요.** 못 넘으면 **현행 유지가 정답**입니다. 이건 실패가 아니라 "이미 고원 위에 있다"는 결론이며, 표본 밖에서 안 무너지는 상태입니다.

### B-3. 채점은 총손익이 아니라 칼마 비율

```python
def score(daily):
    eq  = daily.cumsum()
    mdd = (np.maximum.accumulate(eq) - eq).max()
    return daily.sum() / mdd
```

손익이 1.3배 늘어도 MDD가 1.6배면 후퇴입니다. 청산 기하 변경은 손익과 MDD를 **동시에** 바꾸므로 반드시 비율로 판정합니다.

### B-4. 워크포워드 필수

TP·SL·w를 **학습 126일 경로 분포에서만** 산출하고 검증 85일에 그대로 적용합니다. 211일 전체로 뽑은 값을 전체에 적용하면 당연히 좋게 나오며, 그건 측정이 아니라 기억입니다.

### B-5. 숏에 대한 특례

숏은 149거래 · t = 2.02 · Bonferroni 문턱 3.38 미달 상태입니다. 여기서 청산 탐색을 더 하면 **탐색 카운트만 늘고 문턱만 올라갑니다.** 현행 GS≥1.2는 이미 1.5→1.2 조정을 거친 값이라 표본이 더 견딜 여력이 없습니다.

> **숏은 검정 A(측정)만 수행하고 규칙은 동결한 채 섀도우 60거래일로 넘길 것.**
> MFE/MAE는 기록하되, 그 기록으로 규칙을 바꾸는 것은 섀도우 데이터 축적 이후.

## 4. 최대 수익률 제시 방법

### 4-1. 두 개의 천장

```
천장 A (완전예지) = Σ MFE_i(T) − N × 0.15      ← 도달 불가, 원재료 총량
천장 B (실현가능) = 워크포워드 최고 기하의 검증 85일 성과
추출률           = 실제 총손익 / 천장 A
```

**추출률이 핵심 숫자입니다.**

| 추출률 | 해석 |
|---|---|
| < 20% | 청산 개선 여지 큼. B를 반드시 진행 |
| 20 ~ 40% | 통상 범위. 개선 가능하나 폭은 제한적 |
| > 40% | 이미 잘 짜내는 중. 현행 유지가 유력 |

### 4-2. 규모 추정 (실측으로 대체할 것)

아래는 자릿수 확인용 개략치입니다.

- 코스피200 선물 1,050 기준 일간 ATR ≈ 15pt
- 90분 = 세션의 약 1/4 → 구간 진폭 ≈ 15 × √0.25 ≈ 7.5pt
- 롱 진입 편향 감안 평균 MFE(90) ≈ **+3.0 ~ 3.5pt**

| | 총손익 | 현재 대비 |
|---|---|---|
| 현재 (90분 시간청산) | +432.5pt | 1.00× |
| 천장 A (완전예지) | 약 +1,700 ~ 2,000pt | 4.0× |
| **천장 B (실현가능)** | 약 **+550 ~ 800pt** | **1.3 ~ 1.8×** |

거래당 평균 +0.737pt / MFE +3.0pt → **추출률 약 25%**로 추정됩니다.

### 4-3. 수익률의 분모

문서는 pt와 원화 총액만 있어 수익률 계산이 불가능합니다. 분모 정의가 필요합니다.

| 분모 | 값 | 현재 롱 211일 |
|---|---|---|
| 명목가 (1,050 × 25만) | 2억 6,250만원 | 41% |
| 증거금 (약 15%) | 3,940만원 | 274% |
| **위험자본 (MDD 83.4pt × 3)** | **6,255만원** | **173%** |

**세 번째만 실전에서 의미가 있습니다.** MDD의 3배를 깔아야 연속 손실 구간에서 강제청산을 면합니다. 청산 기하를 바꾸면 MDD도 바뀌므로 최종 보고는 아래 형식으로 통일합니다.

> **최적 기하 = E?, 검증 85일 총손익 ??pt, MDD ??pt, 위험자본 대비 ??%, 추출률 ??%**

## 6. 사전 등록 사항 (착수 전 확정)

1. 판정 문턱(§A-4, §B-2)은 **결과를 보기 전에** 확정하며 사후 변경하지 않는다.
2. 검정 B 후보는 **E1~E5 다섯 개로 고정**한다. 실행 중 후보를 추가하지 않는다.
3. TP·SL·w는 **학습 126일 데이터만으로** 산출한다.
4. 검정 A가 실패한 방향은 검정 B를 **진행하지 않는다.**
5. 숏은 검정 A까지만 수행하고 규칙을 동결한다.
6. 최종 채점은 총손익이 아니라 **칼마 비율**로 한다.
7. 본 검정의 탐색 5회를 누적 카운트에 반영한다 (70 → 75).
