## 1. 무엇을 묻는가

**"진입 방향으로 25봉 극값 종가를 찍은 분에, 그 방향으로 들어가는 진입"이 손익을 깎는가.**

25봉 신고 종가에 매수한다는 것은 최근 25분 중 가장 비싼 종가에 사는 것이다.
소급 실측에서 이 군이 통산 손실의 전부를 설명했다(§5-2).

## 2. 왜 새 축인가 — 기존 두 장치가 못 잡는다

| 장치 | 축 | 소급 실측에서의 분리력 |
|---|---|---|
| `10_chase` (343차) | 직전 **10분 종가 한 점** 대비 연장폭 ≥2.0/1.5 ATR | 발동 28건이 **+518원/건(무해)** — 이미 감점 중 |
| `leg_exhaustion_entry_watch` (529차) | **60봉** 고저 대비 run≥5.0 & dist≤1.0 ATR | 529차만 발동 15건 **−6,931원/건**, 자체 부호검정 **p=1.00** |
| **본 채널** | **25봉 종가 극값**(이산 돌파 플래그) | 처리군 47건 **−56,217원/건**, 부호검정 **p=0.019** |

⇒ 축이 다르다. GP만 잡는 6건이 **−103,296원/건**으로 기존 필터가 통째로 놓친다.

## 3. 고정 명세 (🔴 사후 변경 금지)

```python
"gp_break_entry_watch": {
    "enabled": True,
    "entry_source": "SYSTEM_AUTO",
    "feature_wired_date": None,        # 배선일. 이후 분은 DB 키, 이전은 replay_proxy
    "data_start": "2026-07-14",        # 사이징 체제 변경(431차) 이후 구간만
    "period": 25,                      # GP 룩백. GP_PERIOD 와 일치해야 한다

    # ── 처리군 정의 (컷 고정) ──────────────────────────────────
    #   LONG  이면 gp_break_hi_25 == 1
    #   SHORT 이면 gp_break_lo_25 == 1
    #   결정분 = entry_ts − 1분 (529차 관례), 포지션은 entry_ts 병합(계측 4원칙 ①)

    # ── 사전등록 합격선 ────────────────────────────────────────
    "min_samples": 70,                 # 처리군 포지션 수 (소급 47 → 약 15거래일 추가 필요)
    "min_days": 30,                    # 처리군 발생 거래일 (소급 19)
    "alpha": 0.05,                     # 일자단위 부호검정(양측) — 313차 ①
    "drop_worst_days": 3,              # 최악 3일 제거 후에도 처리군 열세 유지 요구 — 313차 ③

    # ── 비용 ───────────────────────────────────────────────────
    # 🔴 COST_MODEL_COMMISSION_RATE(핀값 0.0015%) 금지. 실측 요율만 쓴다.
    "commission_source": "broker_channel_specs",   # BROKER_CHANNEL_SPECS[detect()]

    # ── 거울상 보존 (529차 require_early_group_better 와 같은 취지) ──
    "require_chase_axis_better": True,

    # ── 승격 형태 (판정 전에 확정) ─────────────────────────────
    "promotion_order": ["checklist_demote", "size_half"],
    "hard_block_forbidden": True,
    "size_half_mult": 0.5,
}
```

### 3-1. `min_samples`를 소급값보다 높게 잡은 이유

소급 처리군은 47건인데 문턱을 70으로 뒀다. 소급으로 이미 충족되는 문턱을 쓰면
**데이터를 보고 문턱을 맞춘 것**이 된다(458차 D6 계열). 적립 속도 실측
2.47건/거래일(47건/19일) 기준 **약 10~15 거래일 추가**면 도달한다 —
`spread_extreme_watch`(ETA 7개월)와 달리 현실적인 시계다.

### 3-2. `require_chase_axis_better`

529차의 `require_early_group_better`와 같은 취지의 안전장치다.
§5-3(b) 실측에서 **`10_chase`만 발동한 28건은 +518원/건으로 사실상 무해한데 이미
감점받고 있다**(317차 FalseBlock 계열). GP 축을 넣는 조치가 그 오탐을 함께
줄이거나 최소한 늘리지 않을 것을 통과 조건에 넣는다.

### 3-3. 하드차단을 금지하는 이유

처리군도 **48.9%는 이긴다**. 317차가 Hurst 하드차단으로 진짜 추세 분봉의 72.3%를
오판한 전례가 그대로 적용된다. 승격은 소프트(체크리스트 감점 → 사이즈 ½) 순서로만.

## 4. 판정 절차

1. 표본이 `min_samples`(70) **且** `min_days`(30)에 도달할 때까지 **판정하지 않는다**.
   미달이면 리포트에 "판정 미달"로 기록하고 이월한다(§11 K-3·K-4 — "기각"과 구분).
2. 도달 시 **1회** 판정: 처리군 vs 대조군 일자단위 부호검정(양측 α=0.05).
3. 최악 3일 제거 후에도 처리군 열세가 유지되는지 확인.
4. `require_chase_axis_better` 확인.
5. 전부 통과 시에만 **주간회의 상정**. PASS여도 자동 적용은 아니다.

## 5. 이 채널이 답하지 않는 것

- **왜** 지는가(기전). §5-4의 평균회귀 설명은 가설이며 이 채널은 검정하지 않는다.
- 다른 룩백(`period` ≠ 25)이 더 나은가. **탐색 금지** — 여러 값을 돌려 이긴 것을
  고르면 사전등록이 무너진다. 25는 사이보스 기본값이라는 **외생적 근거**로 고정한다.
- 대조군(돌파 없음, +12,328원/건)을 **늘리는** 조치. 가점은 진입을 늘리는 방향이라
  `faststop_discovery`(2026-08-03 사용자 결정) 및 절대원칙 §2 계열 원칙과 충돌한다.
