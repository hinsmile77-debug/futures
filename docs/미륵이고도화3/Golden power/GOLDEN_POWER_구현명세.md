## 1. 산식

```
Golden Buy(n)  = ( 종가 − n봉_최저종가 ) / 종가 × 200
Golden Sell(n) = ( n봉_최고종가 − 종가 ) / 종가 × 200
```

기본 파라미터 `n = 25`. 사이보스 설정창의 자유 파라미터는 `기간` 하나뿐이며 위 식과 정확히 일치한다.

### 단위 해석

`1.0 = 이격 0.5%`. 값 0.42는 25봉 최저종가 대비 0.21% 위에 있다는 뜻이다.

### 반드시 지킬 것

- **고가/저가가 아니라 종가**를 쓴다. 09/04 11:31봉 고가 1048.50을 넣으면 어긋나고, 최고종가 1047.94를 써야 맞는다.
- 상한이 없다. 스토캐스틱과 달리 레인지로 나누지 않으므로 1.0을 초과한다 (09/07 13:17 실측 약 1.15).
- 하한은 0이며 정확히 0에 닿는다. `Golden Buy = 0`은 당봉 종가가 n봉 신저 종가, `Golden Sell = 0`은 n봉 신고 종가라는 뜻이다.

## 2. 검증 근거

역산 절차: 지표값에서 분모 `D`와 분자의 극값을 역산한 뒤, 그 극값이 실제 종가의 롤링 최대/최소와 일치하는지 대조.

### 2.1 분모 D

| 거래일 | 표본 | D (최소제곱) | 잔차 RMS | D ÷ 평균종가 |
|---|---|---|---|---|
| 09/04 | 21봉 (Hi 고정 구간) | 5.207 | 0.0176 | **0.4976%** |
| 09/07 | 16봉 (Lo 고정 구간) | 5.457 | 0.0152 | **0.5017%** |

잔차 RMS는 지표값 소수점 둘째 자리 반올림 노이즈(±0.005 × D ≈ ±0.027, 균등분포 RMS ≈ 0.015)와 정확히 같은 크기다. 모형 오차가 아니라 표시 정밀도의 한계다.

두 날짜 모두 종가의 0.5%. 추정 표준오차가 ±0.03 수준이라 0.4976%와 0.5017%는 통계적으로 구분되지 않는다.

**기각된 대안:** 기준가(전일종가) 기준. 09/07 기준가는 1,051.5(종가 1,097.04, +4.33% 역산)이므로 0.5%면 5.258이어야 하나 실측 D는 5.457. 약 6σ 밖이다. 분모는 **당봉 종가**다.

**09/07 (상승 국면) — 최고종가 추적**

역산 Hi가 11:29·11:31·11:32에서 종가 러닝맥스를 정확히 따라 1088.34 → 1088.59 → 1088.78로 갱신되고, 각 봉의 `Golden Sell`이 정확히 0.00을 찍는다. 이후 24봉 내내 1088.74~1088.81 범위에 머문다.

**09/04 (하락 국면) — 대칭 확인**

## 3. 구현

### 3.1 기본형

```python
import pandas as pd


def golden_power(close: pd.Series, period: int = 25) -> pd.DataFrame:
    """대신 사이보스 GOLDEN POWER 재현.

    1.0 = 이격 0.5%. 상한 없음, 하한 0.

    Args:
        close: 종가 시계열 (시간 오름차순)
        period: 룩백 기간. 사이보스 기본값 25

    Returns:
        golden_buy, golden_sell 두 컬럼. 첫 period-1 봉은 NaN.
    """
    lo = close.rolling(period, min_periods=period).min()
    hi = close.rolling(period, min_periods=period).max()
    return pd.DataFrame({
        "golden_buy": (close - lo) / close * 200.0,
        "golden_sell": (hi - close) / close * 200.0,
    })
```

### 3.2 파생 피처

원본 두 선보다 아래 조합이 다루기 쉽다.

```python
def golden_power_features(close: pd.Series, period: int = 25) -> pd.DataFrame:
    gp = golden_power(close, period)
    gb, gs = gp["golden_buy"], gp["golden_sell"]
    denom = (gb + gs).replace(0.0, pd.NA)
    return pd.DataFrame({
        "gp_buy": gb,
        "gp_sell": gs,
        # 방향축: 양수면 저점 쪽보다 고점 쪽에 가까움
        "gp_dir": gb - gs,
        # 변동성축: n봉 종가 레인지를 0.5% 단위로 표현
        "gp_range": gb + gs,
        # 위치축: 0~1 정규화. 스토캐스틱 %K와 동형
        "gp_pos": (gb / denom).astype(float),
    })
```

- `gp_dir` — 방향. 실측에서 RSI와 강한 단조 관계를 보이나 이는 부산물이다. 둘 다 종가의 상대적 위치를 재기 때문이며 인과가 아니다.
- `gp_range` — **n봉 종가 레인지 그 자체**. 계단 함수로 움직이며 저변동성 국면에서 눌린다. 레짐 필터 후보.
- `gp_pos` — `gp_range`로 나눠 정규화하면 스토캐스틱 %K와 같아진다. 즉 `gp_dir`, `gp_range`가 담은 정보를 `gp_pos` 하나로 대체하면 변동성 정보가 소실된다.

### 3.3 성격

**스토캐스틱의 분모를 상수로 갈아끼운 지표**다.

스토캐스틱은 레인지로 나누므로 횡보장에서도 100을 찍는다. 자를 눈금 없이 늘였다 줄였다 하는 셈이라 "얼마나 큰 움직임인가"가 지워진다. GOLDEN POWER는 고정된 자(종가의 0.5%)로 재기 때문에 횡보장에서는 두 선이 같이 납작하게 눌리고, 추세가 나오면 같이 부풀며 1을 넘어간다.

위치와 에너지를 한 쌍으로 담는 구조다. 미륵이처럼 이미 위치 계열 지표(RSI, 스토캐스틱)를 여럿 쓰는 파이프라인에서는 `gp_range` 쪽이 신규 정보량이 크다.

## 4. 미륵이 통합 시 확인할 것

### 4.1 룩어헤드

없다. `t` 시점 값은 `t-24 ~ t` 종가만 사용한다. 다만 **당봉 종가 확정 후에만 유효**하므로, 장중 미완성 봉에 적용하면 봉이 진행되며 값이 변한다. 실전 예측 경로에서 미완성 봉을 쓰는지 확인이 필요하다.

### 4.2 워밍업

`period` 봉이 필요하다. 1분봉 25봉이면 개장 후 25분. 09:00~09:25 구간은 NaN이므로 결측 처리 정책을 정해야 한다. 전일 봉을 창에 포함시킬지 여부는 오버나이트 갭 때문에 결과가 크게 갈린다. **일중 리셋 권장** (미륵이의 당일청산 절대원칙과도 정합).

### 4.3 피처 등록 경로

`batch_retrainer.py`의 `_save_feature_names()` 비대칭 저장 이슈(97 features 사고) 전례가 있으므로, 신규 피처 추가 시 다음을 함께 확인한다.

- `horizon_feature_sets.json` — 호라이즌별 피처셋. Phase 1 재학습에만 적용되고 Phase 2 EOD에는 슬라이싱이 들어가지 않는 문제가 기록돼 있다. 신규 피처가 Phase 2에서 어떻게 취급되는지 먼저 확인할 것.
- SHAP 동적 피처 선택 — `gp_buy`/`gp_sell`을 그대로 넣으면 `gp_dir`, `gp_range`와 선형종속이다. **네 개 다 넣지 말고 둘만 고를 것.** 권장은 `gp_dir` + `gp_range`.

### 4.4 사전등록 검증

VALIDATION_CAMPAIGN 체계상 데이터 확인 전에 `min_samples`와 합격선을 고정해야 한다. 신규 채널로 등록하려면 다음을 먼저 정한다.

- 대상 호라이즌 (1m 상관 거의 0, 30m에서 유효 피처 최대라는 기존 분석 참고 → 15m/30m 우선)
- `min_samples` — 기존 채널들의 실측 도달속도가 9~16주였음을 감안
- 합격선 — 기존 피처셋 대비 net EV 개선폭

### 4.5 값 검증

구현 후 HTS 값과 대조하려면 사이보스 차트 데이터 저장으로 `시각, 종가, Golden Buy(25), Golden Sell(25)`를 뽑아 위 함수 출력과 비교한다. 소수점 둘째 자리까지 일치해야 한다.

## 5. 남은 불확실성

- 분모 계수는 실측 0.4976% / 0.5017%로 **0.5%가 거의 확실**하지만, 두 날짜 모두 가격대가 1044~1089로 좁아 가격 수준에 대한 민감도를 넓게 검증하지 못했다. 가격대가 크게 다른 종목(예: 저가 종목)에서 한 번 더 대조하면 완전히 닫힌다.
- 분모가 당봉 종가인지 창 내 평균종가인지는 이 표본(종가 스프레드 0.22~0.34%)으로 구분되지 않는다. 실용상 차이는 무시할 수준이다.
- 사이보스 도움말에서 공식 산식이 확인되면 위 내용과 대조할 것. 웹·커뮤니티에는 이 지표의 공개 문서가 존재하지 않는다.
