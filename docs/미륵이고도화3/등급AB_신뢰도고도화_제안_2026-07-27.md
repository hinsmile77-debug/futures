## 1. 설계 철학 — "반드시 개선"의 정직한 정의

시장 엣지 자체는 어떤 설계로도 보장할 수 없다(보장한다고 주장하는 안은 그 자체로 의심해야
한다). 따라서 본 제안은 "반드시 개선"을 다음처럼 **검증 가능한 시스템 속성**으로 정의하고,
각 항목이 그 속성을 결정론적으로 달성하도록 구성한다:

| # | 보장되는 개선 | 어떻게 보장되는가 |
|---|---|---|
| G1 | 등급이 **도달 가능**해진다 — 엣지가 생기면 A/B가 수학적으로 나올 수 있다 | 척도를 절대확률 → 통계적 lift로 교체(순수 수학, §2-1) |
| G2 | 등급이 **정직**해진다 — 엣지가 없으면 지금처럼 안 나온다(과신 부활 없음) | Wilson 하한 + 표본수 하한이 구조적으로 강제(§2-1) |
| G3 | 등급의 **역전이 소멸**한다 — A≥B≥C≥X 단조성이 정의상 성립 | 등급 판정량 자체가 실측 적중률의 신뢰구간이므로(§2-1) |
| G4 | 설계된 정보 소스가 **실제로 흐른다** (또는 명시적으로 퇴역한다) | 죽은 피처 3계열 원인 규명 후 복구 or 제거 — 어느 쪽이든 현재의 "0 기여 + 차원 낭비"보다 개선(§2-2) |
| G5 | 시스템이 **실제 구조와 일치**한다 — 죽은 30m 기준 CB, 죽은 1m/30m 연산 제거 | 실측 가중치 0 확정에 근거한 정리(§2-3) |
| G6 | 모든 변경이 **롤백 가능 + 섀도 선행** | 전 항목 플래그 게이트 + 섀도 로그 → 실측 후 승격(§4) |

트랙 구분:
- **트랙 A (결정론적 — 실패 불가능)**: §2 전체. 척도·배선·정리. 코드와 수학만으로 완결.
- **트랙 B (측정 기반 — 검증 후 승격)**: §3. 포켓·레이블 재설계. 섀도 기간 실측이 승격 조건.

## 2. 트랙 A — 결정론적 개선 (반드시 달성)

### 2-1. [A-1] 등급 척도 재설계: 절대확률 → 검증된 엣지(EdgeScore)

**핵심 아이디어**: 등급을 "모델이 주장하는 확률"이 아니라 **"최근 실측이 통계적으로 입증한
엣지"**로 정의한다. 자기 주장(confidence)이 아니라 실적(rolling hit-rate)의 신뢰구간이
등급을 만든다 — HCGuard(A→B 강등 가드)가 이미 이 방향의 원형이며, 이를 등급 체계 전체로
일반화하는 것이다.

**EdgeLedger (신규 모듈 `learning/edge_ledger.py`)**:

- 셀 단위: (entry_horizon 그룹, 시간대 zone[AM/MID/PM], regime) — 초기 셀 수를 3×3×3
  이하로 제한해 셀당 표본을 확보(과분할 금지, 372차 소표본 교훈).
- 셀마다 rolling deque(기본 300건)로 (방향성 신호의 부호적중, 손익 근사 realized_move)를
  축적. **부호적중 기준 = UP/DN 2-class**(기저율 0.5) — 거래 손익과 직접 대응되는 척도라
  3-class 정확도의 "FLAT 적중" 노이즈가 제거된다(§0-1 실측도 이 척도가 유일하게 0.5
  근방에서 의미 있는 변동을 보임).
- 등급 판정:

```
p̂    = 셀의 rolling 부호적중률
L    = Wilson 95% 하한(p̂, n)
EV   = 셀의 rolling 평균 (realized_move × direction) − 왕복비용(pt)

A: L ≥ 0.55  AND EV > 0  AND n ≥ 150     # "하한조차 55%+" — 입증된 강한 엣지
B: L ≥ 0.52  AND EV > 0  AND n ≥ 100     # 입증된 약한 엣지
C: p̂ ≥ 0.50 AND n ≥ 60                  # 엣지 미입증, 손실 증거도 없음
X: 그 외 (p̂ < 0.50 이거나 표본 부족)
```

- 기존 confidence·min_conf 게이트(regime_ok)는 **진입 허용/차단 필터로 유지**(안전장치
  약화 없음). 등급은 그 위에서 "얼마나 믿을 만한가"만 담당하도록 역할 분리.
- HCGuard는 그대로 유지하되 판정 입력을 EdgeScore 셀과 공유(중복 버퍼 제거).

**왜 이것이 "드라마틱"한가**: 등급의 의미론이 "모델의 자기신고"에서 "감사(audit)된 실적"으로
뒤집힌다. G1~G3이 수학적으로 보장되고, 부수 효과로 A/B 등급이 그 자체로 **셀 단위 엣지
모니터**가 된다 — 어느 시간대·레짐에서 엣지가 살아나는지가 대시보드에서 실시간으로 보인다.

**검증(사전)**: 과거 DB 재생으로 05-08~07-27 전 기간 EdgeScore를 소급 계산 —
(a) 05-19 이전 과신 구간에서 A/B가 남발되지 않는지(G2), (b) §0-4 오후 포켓 구간에서
B가 간헐 점등하는지(G1), (c) 등급별 실측 적중 단조성(G3)을 리포트로 확인 후 섀도 배선.

### 2-2. [A-2] 죽은 피처 3계열 복구 (또는 명시적 퇴역)

§0-3(a)의 3계열에 대해 계열별로:

1. **원인 규명** (읽기 전용): 수집 로그·raw 소스 DB에서 원천 데이터 존재 여부 확인 →
   "수집 단절"인지 "변환 로직이 항상 0을 내는 버그"인지 "설계상 조건이 라이브에서 절대
   참이 안 되는 로직 결함"인지 분류.
   - 수급 계열: `collection/` 프로그램매매 TR 경로 — TR 미호출/파싱 실패/필드 매핑 의심.
   - 소진 계열: `features/technical/cvd.py` — exhaustion 판정 임계가 라이브 스케일에서
     도달 불가능할 가능성.
   - 매크로 계열: nasdaq 소스 단절 여부(`macro_vix`는 정상 흐름이므로 수집기 전체 문제는
     아님 — nasdaq 항목만의 문제).
2. **복구 가능** → 수정 후 zero-rate 모니터를 EOD 리포트에 추가(재발 방지 계측).
3. **복구 불가/무가치 판정** → feature_names에서 제거해 차원 정리(GBM 노이즈 차원 감소 +
   "있는 줄 알았던 정보가 사실 없음"이라는 인식 오류 해소).
4. **재발방지 일반화**: EOD 리포트에 "전 피처 zero-rate/상수 감시" 섹션 신설 — zero-rate
   > 95%가 N일 지속되면 경보. 이번처럼 2개월+ 방치되는 일 자체를 계측으로 차단.

### 2-3. [A-3] 죽은 호라이즌 정리 + CB③ 다중 호라이즌 재설계

1. 1m·30m 가중치 상시 0의 메커니즘 확인(decorrelation/adaptive weighting 어느 단계에서
   배제되는지 — `model/ensemble_decision.py` 가중 로직 추적).
2. 확인 결과가 "구조적 상시 배제"이면: 1m·30m을 앙상블 입력에서 공식 퇴역(예측·채점은
   레이블 연구용으로 유지 여부만 별도 판단), 딥다이브 제안 2와 정합되게 **CB③을 "활성
   호라이즌 공통 부호정확도 기준"으로 재설계** — 예: "활성 4개 호라이즌 롤링 부호정확도
   전부 < 0.48 → 당일 정지". EdgeLedger 셀 데이터를 그대로 재사용하므로 추가 인프라 불요.
3. 실전 전환 기준 ⑥(CLAUDE.md)의 "30m 재도입 vs CB③ 재설계" 항목이 이것으로 해소됨 —
   CLAUDE.md 갱신 포함.

## 3. 트랙 B — 측정 기반 개선 (섀도 검증 후 승격)

### 3-1. [B-1] 조건부 엣지 포켓의 섀도 검증

§0-4의 오후 중장기 포켓은 유망하지만 일자단위 t=1.41로 미확정. EdgeLedger가 섀도로 돌면
셀별 Wilson 하한이 자동으로 이 검증을 수행한다 — **별도 작업이 거의 불필요**(A-1의 부산물).
- 승격 조건(사전 등록, 372차 방법론 준수): 섀도 20거래일 후 해당 셀(PM×중장기)의
  일자단위 부호적중 평균이 t≥2.0 또는 Wilson 하한≥0.52 → 그 셀의 B등급 점등을 라이브
  진입 사이징에 반영(첫 단계는 사이징 가중만, 진입 게이트 무변경).
- 기각 조건: 20거래일 후에도 하한<0.50 → 포켓 가설 폐기 기록.

### 3-2. [B-2] 레이블·타겟 구조 연구 (별도 세션, 최후순위 아님 — 최대 기대값이나 위험도 최대)

- 현행: FLAT 34% 균형 재단 → 최대 엔트로피 3-class를 자기부과(§0-2).
- 연구 방향: (a) 2-class 부호 예측 + 진입가치 메타모델 분리(기존 `meta_labels`·
  `meta_entry_quality_prob` 인프라 재사용), (b) triple-barrier(손절/익절/시간) 레이블로
  "거래 결과"를 직접 예측, (c) `quantile_expected_pt`(이미 저장 중)를 EV 축으로 승격.
- **주의**: 모델·레이블 전면 교체는 실패 위험이 큰 트랙이므로, 트랙 A 완료 + B-1 결론
  이후 착수. 반드시 walk-forward 재생으로 현행 대비 부호정확도·EV 우위를 확인한 뒤에만
  라이브 승격. 트랙 A와 독립이므로 실패해도 트랙 A의 개선(G1~G6)은 잔존한다.

## 4. 구현 계획

### Phase 0 — 사전 검증 (1세션, 코드 변경 없음)
1. 죽은 피처 3계열 원인 규명(§2-2의 1) — 읽기 전용 조사.

   파라미터(윈도우 300, 컷 0.55/0.52)를 조정 후 재검증 — 확인 전 라이브 배선 금지.**

1. `learning/edge_ledger.py` 신규 + `model/ensemble_decision.py` 등급 경로에 섀도 병기
   (`GRADE_EDGE_MODE = "shadow"` 플래그 — 기존 등급 그대로 산출·기록하고, EdgeScore 등급을
   `detail` JSON과 대시보드에 병행 표시만).
2. 죽은 피처 수정 or 퇴역(Phase 0 결과에 따라) + EOD zero-rate 감시 섹션.

  단조성(G3), (iii) B-1 포켓 셀 하한 추이, (iv) 재설계 CB③ 가상 발동 빈도.
