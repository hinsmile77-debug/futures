## 0. 결론

1. **두 객체 모두 공식 명세에 「고객등급 제한 객체」로 적혀 있다.** 「등급과 무관한 통신량 제한」이라는 주장은 이 객체에 대해서는 명세와 맞지 않는다. 10/2 장후 프로브의 차단 문구도 일반 통신량 문구(「많은 시세 데이터를…」)가 아니라 **객체명을 지목한 문구**(「…**CCpSvr9842** 시세데이터를 받는 데는 제한이 있습니다」)였다.
   → **1단계는 코드가 아니라 판별이다**: 장중 1회 프로브(한도 잔량 기록 포함)로 「등급 차단」과 「통신량 차단」을 가르고, 등급 차단이면 대신증권(1588-4488)에 해제 조건을 확인한다.
2. **명세상 월물 입력이 「최근월/차근월」뿐이라 위클리가 빠질 가능성이 크다.** 개인 거래가 몰리는 위클리(10/2 실측 개인 옵션 거래의 64%)를 못 받으면, 이 수집으로 얻는 것은 **먼스리 행사가 × 12주체**다. 위클리 커버리지는 1단계 프로브에서 같이 확인한다.
3. 차단이 풀리면 구현은 가볍다. **1분에 콜·풋 2회 호출**(연속조회 없음, 12주체 배열 한 번에)이라 15초당 60건 한도의 약 1%를 쓴다. 기존 7222 수집기와 같은 틀(QTimer 경로 · COM 캐시 · 한도 대기)에 붙인다.
4. 붙여 주신 예시 코드는 그대로 쓰면 안 된다. `time.sleep` 루프는 미륵이 Qt 메인 스레드를 막고, 필드 인덱스는 명세와 다르며(예시의 「행사가=1, 개인=2」는 명세상 「1=보유계약 배열, 2=평균단가 배열」), `Continue` 처리는 이 객체에 해당하지 않는다(§2).

## 3. 데이터의 뜻 — 무엇을 받게 되는가

- **「당일」 모드의 보유계약 = 그 주체의 당일 순포지션(계약)**으로 읽힌다. 분마다 찍어 차분하면 **행사가 × 주체 × 분 순매수**가 된다. 다만 화면 제목이 「투자 주체별 종목 비교(**추정**)」라 거래소 확정치가 아닌 **증권사 추정치**일 수 있다 → §4-P3 대사가 필요하다.
- **먼스리(최근월·차근월)만**일 가능성이 크다. 그러면 이 수집은 「먼스리 열」을 살리고, 위클리 열은 지금처럼 상품 단위(7222)로 남는다.
- 기존 HTS 내보내기와 단위가 다를 수 있다(내보내기 금액은 십만원 추정). API 필드 3 보유금액의 단위도 P1에서 화면과 대조해 확정한다.

**스키마 초안** (`data/db/option_flow.db`)

```sql
CREATE TABLE option_strike_investor (
    trade_date TEXT NOT NULL, snap_hm TEXT NOT NULL,      -- 'HH:MM' (호출 분)
    cp TEXT NOT NULL,            -- 'C' | 'P' | 'F'
    month TEXT NOT NULL,         -- '1' 최근월 | '2' 차근월
    code TEXT NOT NULL, strike REAL,
    investor INTEGER NOT NULL,   -- 0–11 (명세 인덱스 그대로)
    hold_qty INTEGER, avg_px REAL, hold_amt REAL, realized REAL,
    collected_at TEXT NOT NULL,
    PRIMARY KEY (trade_date, snap_hm, cp, month, code, investor)
);
CREATE TABLE option_strike_investor_status (
    trade_date TEXT, snap_hm TEXT, cp TEXT, month TEXT,
    ok INTEGER, rows INTEGER, k_min REAL, k_max REAL, limit_remain INTEGER,
    elapsed_ms REAL, msg TEXT, PRIMARY KEY (trade_date, snap_hm, cp, month)
);
```

용량: ATM ±20 × 2(콜·풋) × 12주체 ≈ 1,000행/분 → 하루 약 41만 행. 4주체만 남기면 14만 행. **12주체로 시작해 2주 뒤 줄일지 결정.**

## 7. 확인이 필요한 것

1. **위클리 지원 여부** — 명세상 월물 구분이 최근월/차근월뿐이다. 위클리가 안 되면 개인 주무대는 여전히 상품 단위만 있다.
2. **「추정」의 뜻** — 증권사 추정치라면 거래소 확정치와 어긋날 수 있다. P3 대사가 그 폭을 잰다.
3. **등급 조건** — 해제에 필요한 등급(자산·거래 실적)과 모의투자 계좌 적용 여부.
4. 프로브와 수집은 **MW0601 기준**이다. MW0602(CREON 로그인)는 같은 객체라도 등급 판정이 다를 수 있어 따로 프로브해야 한다.

## 부록. P0 프로브 스크립트 초안 (실행 전 검토용)

```python
# scripts/probe_cpsvr9842.py — 장중 1회, 읽기전용, DB 쓰기 없음
from utils.dll_bootstrap import ensure_conda_dll_path; ensure_conda_dll_path()
import time, datetime, win32com.client as wc

def log(msg):
    line = "%s [CybosProbe][RAW] %s" % (datetime.datetime.now().strftime("%H:%M:%S"), msg)
    print(line)
    with open("logs/%s_PROBE.log" % datetime.date.today().strftime("%Y%m%d"), "a", encoding="utf-8") as f:
        f.write(line + "\n")

cy = wc.Dispatch("CpUtil.CpCybos")
log("connect=%s remain(1)=%s remain_ms=%s" % (cy.IsConnect, cy.GetLimitRemainCount(1), cy.LimitRequestRemainTime))
obj = wc.Dispatch("CpSysDib.CpSvr9842")
for attempt in (1, 2):
    obj.SetInputValue(0, ord("2")); obj.SetInputValue(1, ord("1")); obj.SetInputValue(2, ord("1"))
    obj.BlockRequest()
    st, msg = obj.GetDibStatus(), str(obj.GetDibMsg1() or "").strip()
    log("CpSvr9842 call#%d status=%s msg=%s remain(1)=%s" % (attempt, st, msg, cy.GetLimitRemainCount(1)))
    if st == 0:
        n = obj.GetHeaderValue(0); log("rows=%s" % n)
        for i in range(min(n, 3)):
            log("row%d code=%s qty=%s avg=%s amt=%s pnl=%s" % (i, obj.GetDataValue(0, i),
                list(obj.GetDataValue(1, i)), list(obj.GetDataValue(2, i)),
                list(obj.GetDataValue(3, i)), list(obj.GetDataValue(4, i))))
        log("codes=%s" % [obj.GetDataValue(0, i) for i in range(n)])   # 위클리 코드 포함 여부
        break
    time.sleep(15)
```
