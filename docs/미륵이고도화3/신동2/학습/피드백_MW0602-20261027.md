- **바꿀 것 하나**: **L27**(선물 외인 2거래일+ 연속 순매수면 익일 매도 금지, 현물 매도 동반 시 「선물 선행 divergence」로 읽음). 내일 live 익일계획에 적용, legacy 는 종전(현물·콜풋 가중) 유지해 효과를 분리 측정.

#### 레슨런
- 신설(후보): **L27**[방향] 선물 외인 2일+ 연속 순매수 → 익일 매도 금지(딥다이브 산출). **L28**[진입] 당일 2번째 이후 재진입은 맥점 지지 재터치 확인 전 보류.
