## 결론

1. **방향 적중률 자체는 어떤 필터로도 크게 오르지 않는다.**
   - 앞을 보는 기준(그 시각 → 30분 뒤 · → 15:05)으로 재면 모든 후보가 **30분 적중 51–57%, 마감 적중 53–60%** 안에 있다.
   - 현행 F2는 55.7% / 58.3%다.
   - ⚠ 앞 답변의 「F2 = 실제 방향 82%」는 그날 전체 방향(09:00 → 15:05)과 비교한 값이다. 결과를 미리 아는 쪽으로 부풀려져 있어 재인용하지 말 것.
2. **필터의 가치는 적중률이 아니라 「R3 진입 순간에 어느 쪽을 걸러 내는가」에서 나온다.** 손익 차이는 크다(아래 §3).
3. **견고성 기준**(V2·MAIN 두 바탕 × 전반·후반 4칸 모두 플러스)을 통과한 것 중 **현행 F2(변화량 0 기준)가 여전히 가장 견고하다.** 최소 칸 +266.3만, V2 바탕 효율 0.29다.
4. **추세 지표를 쓴 대안 중 유일하게 가치 있는 것은 「F2(±50) ∧ 가격 EMA20−EMA60 일치」다**(불일치·중립이면 필터 없이 통과).
   - 합계는 현행보다 작다.
   - 대신 **최악일과 MDD가 줄고**, MAIN 바탕 효율은 **0.33으로 최고**다.
5. **가격 단독 추세 필터는 실패한다.** EMA20 위/아래는 22일 −488만(V2 바탕)이다. R3는 맥점에서의 되돌림 매매라, 가격 추세만 따르면 「눌림에서 사는」 신호를 반대로 걸러 낸다.

## 4. 해석

| 질문 | 답 |
|---|---|
| 0 기준 대신 중립 구간을 두면? | ±50·±100은 사실상 같다(±100 block +806 vs 현행 +797). **±200은 나빠진다**(필요한 신호까지 막는다). 0 → 매수 기본값의 편향은 손익상 문제가 아니었다 |
| 수급 추세(최근 30·60분 · EMA)를 쓰면? | 짧은 창은 소음에 흔들린다. 「09:00 이후 누적」이 그날 개인 포지션의 실제 쏠림을 더 잘 잡는다 |
| 가격 추세를 쓰면? | 단독은 실패한다 — R3는 맥점 되돌림이라 가격 추세와 성격이 반대다. **수급과 일치할 때만**(조합) 쓰면 나쁜 날을 줄인다 |
| 왜 적중률은 그대로인데 손익은 크게 다른가? | 필터는 R3 터치 순간에만 작동하고, 한 신호를 막으면 그 시간에 다른 신호가 들어온다(한 번에 한 포지션). 매분 평균 적중률이 아니라 **박스권에서 반대 방향 R3를 얼마나 막느냐**가 손익을 정한다 |
