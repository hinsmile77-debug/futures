- **사용자 결정**: MW0602는 현 체계를 유지하고, MW0601이 MW0602를 보완한다.
- **구현**: MW0601 신동 규격 v3(`SD-2026-10-21-v3`)
  - MAIN = v2 + R3 트레일 4/4(구 TR44 승격 · 새 값 0)

  - TR44 종료
  - 채점은 10-21에 재시작한다.
- **주 근거**: 632차 사전등록 판정(순손익 우위 **그리고** 최악일 개선)에서 TR44가 「채택 후보」였다.

- **MW0602 보완 판정 사전등록**: 20거래일 뒤 판정한다.
  - 조건: (HYBR60+MW0601 MAIN)/2의 최악일 > HYBR60 **그리고** 평균/표준편차 ≥ HYBR60
  - v2 창에 소급하면 TR44는 「부분」이다 — 기준을 TR44에 맞추지 않았다.
- **연동 정리**

  - 신동2 AI 대 MAIN 사전등록은 `SD2AI-MW0601-2026-10-21-v2`로 재등록했다(개시 전 · 표본 0).

## 6. 실주문 상태 (2026-10-20 확인)

- **현재 실주문 주체는 피터(피터2)다.**
  - `data/trade_principal.json` = `PETER`(2026-10-12 설정)
  - 기동 로그: `[Peter2] 모드=live (거래주체=피터)`
- **신동은 가상이다.** 10-14부터 `shindong_vexec.json` 가상 장부만 쌓였고, 실집행 기록 `shindong_exec.json`은 한 번도 생기지 않았다.
- **대시보드 [신동] 클릭 → 즉시 전환된다**(재기동 불필요).
  - 조건: FLAT · 대기주문 없음. 장전이면 충족된다.
  - R2 신호(09:01–09:10)를 받으려면 **09:01 전에** 전환할 것(신호 추적 한도 2분).
  - 전환 뒤 피터2는 섀도로 내려가며, 진입 주문 관문이 이중 실주문을 막는다.
- ⚠ **MW0601 신동 실집행기(685차 `live_legs`)의 첫 실전 가동이 된다.**
  - 실계좌는 1계약이라 1차 목표에서 전량 청산된다.
  - 1차 전 +4pt 뒤 되밀리면 트레일 손절이 매분 갱신된다.
