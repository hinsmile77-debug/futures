## 3. 왜 같은 TR44가 MW0601에서는 이기고 MW0602에서는 지나

| | 신동2 MAIN (MW0601) | 신동 MAIN (MW0602) |
|---|---|---|
| 기존 청산 | 맥점 목표(멀다) · 1차 뒤 본전 · **트레일 없음** | **트레일 6/4** · 익절 12pt · 재난 손절 |
| TR44가 하는 일 | 없던 이익 보호를 **새로 만든다** | 있던 트레일을 **더 촘촘하게** 만든다 |
| 결과 | 「+4pt 갔다 원 손절」 손실 → 이익 | 12pt 익절까지 갈 거래를 4pt 되돌림에 잘라낸다 |

비유하면 이렇다. 안전벨트가 없던 차(MW0601)에 벨트를 달면 사고 손실이 크게 준다. 이미 벨트가 있는 차(MW0602)의 벨트를 더 조이면 승차감(수익)만 나빠진다.
