## 4. 반사실 해석

1. **현행 재생 → 인과 MAIN(결함 제거)**: 22일 +764.0 → +120.4만. 「전」의 진짜 기준선은 인과 MAIN이다. 현행 재생 수치는 실집행으로 낼 수 없는 소급 선택이 섞여 있다.
2. **인과 MAIN → ① F2**: +120.4 → **+796.7만(+676.3)**, MDD −333 → −266만.
   - 개선은 거의 **후반 박스권(10-08–10-26)**에서 나온다(−188.3 → +492.6). 전반은 같다(+308.7 vs +304.2).
   - 약점: 거래가 적어(109건) 하루 손실이 클 때가 있다(09-29 −256.7).
3. **인과 MAIN → ② F2X**: +120.4 → **+637.9만(+517.5)**, MDD −333 → **−191만**.
   - **최악일·MDD·효율·이긴 날 모두 1위**다(−190.6 · 0.33 · 14/22). 전반에도 이긴다(+434.3 — 유일하게 기준선보다 높다).
   - 대신 후반은 ①보다 약하다(+203.6 vs +492.6). 트레일이 흐름 방향 추세 거래를 끊기 때문이다(10-15 +9.6 vs ① +194.0).
4. **수량 1.5%와의 결합은 후보마다 다르다.**
   - **①**은 1.5%에서도 손익이 유지되고(+764.2) v3 4일 최고(+179.3 · MDD −8.6)다. 다만 전반 손익이 크게 줄고(+304.2 → +74.9) 최악일이 커진다(−230.4).
   - **②**는 1.5%에서 손익이 반감된다(+637.9 → +343.9). 손절이 좁은 R3에 수량이 몰리는데, ②는 트레일이 이미 좁게 끊어 그 몫을 키우지 못한다.
