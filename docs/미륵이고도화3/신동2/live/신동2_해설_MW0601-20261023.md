## 다음 단계
- I4·I5 는 **미구현**이다 — 플러그인 코드는 Edit/Write 가 막힌 이 통로에서 쓸 수 없다. 다음 **대화 세션**에서 구현 후 verify(사전등록 문턱) → PASS 면 사용자 확인 뒤 장착.
- I3 부호 뒤집기(역추종)도 같은 세션에서 처리.
- 장착 지표 없음 — 20거래일 폐기 판정 대상 없음.
