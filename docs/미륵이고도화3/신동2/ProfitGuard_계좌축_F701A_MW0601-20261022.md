## 2. ProfitGuard 4층 — 무엇을 지키나

CB 가 「잃을 때 멈추는」 장치라면 ProfitGuard 는 **「벌었을 때 멈추는」** 장치다. 매 진입 전
L1 → L2 → L3 → L4 순서로 검사한다.

| 층 | 이름 | 보는 것 | 걸리면 |
|---|---|---|---|
| L1 | 피크 트레일링 | 최고점에서 얼마나 되돌렸나 | 당일 종료(래치) |
| L2 | 수익구간 티어 | 얼마나 벌었나 | 당일 종료(래치) |
| L3 | 오후 리스크 압축 | 언제(13시 이후) · 몇 번 | 그 진입만 거절 |
| L4 | 수익 CB | 벌어 둔 상태에서 몇 연패 | 당일 종료(래치) |

## 3. 결정 — 계좌 축

**계좌 전체 = 거래주체 3종(SYSTEM_AUTO · SHINDONG · PETER2)의 실거래 실현 net 합.**

- 수동 진입(`OPERATOR_MANUAL`)·복구(`GHOST_PENDING_MISS` 등)·유령·출처 미기록은 **여전히 제외**한다.
  2026-09-08 외부 수동매매로 L2 가 래치된 사고(546차)의 재발 방지는 그대로 유지된다.
- 선택되지 않은 주체(가상 장부)는 돈이 걸리지 않으므로 합산 대상이 아니다.
- 주체를 바꿔도(FLAT 이면 장중 전환 가능) **래치는 계좌에 남는다** — 전환으로 우회할 수 없다.
- 미륵이 가상 주체일 때 계좌 래치는 미륵의 **가상** 진입을 막지 않는다(섀도 평가 표본 보호,
  `PROFIT_GUARD_BLOCK_VIRTUAL_PRINCIPAL=False`). 막지 않은 사실은 `[ProfitGuard][Virtual]` 로 1회 남긴다.

### 테스트가 잡은 결함

L2 가 래치되는 순간 남기는 스냅샷 로그가 `size_mult` 를 `:.2f` 로 포맷해, 등급이 없는 주체(None)
