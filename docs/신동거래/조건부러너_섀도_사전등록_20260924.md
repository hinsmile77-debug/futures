## 0. 무엇을 검증하나

반사실에서 신동 청산을 미륵이에 통째로 입히면 이익이 **추세일 3일**에 몰렸고, 그 밖의 날은
손해였다. TP1 뒤 잔량만 신동 최종목표까지 들고 가는 러너도 조건 없이는 무효였다
(현행 구간 +13만 원, P(≤0) = 0.49).

남은 가설은 하나다 — **추세일을 미리 가려내는 신호가 신동 R1(08:59 개인 위클리 콜−풋 금액)인가.**
흐름 원천이 9/21–9/23 세 날뿐이라 지금은 답할 수 없다. 이 섀도가 표본을 쌓는다.

## 1. 규칙(고정값)

| 항목 | 값 |
|---|---|
| 대상 | 미륵이 **`SYSTEM_AUTO`** 포지션(레그를 진입 시각·방향으로 묶음). 보유 중 포지션은 건너뛴다 |
| 조건 ① | 진입 방향 == 그날 신동 R1 방향(`bias`, 08:59 확정 — 진입 전에 알 수 있다) |
| 조건 ② | 실제로 **TP1 레그가 체결**됐다 |
| 러너 | TP1 레그는 **실제 체결 그대로.** TP1 시각 **이후** 나간 비-TP1 레그만 교체 — TP1 다음 분부터 **본전 스톱** + **신동 최종목표**(`engine.targets` 의 T2, 진입 분 기준) 지정가 + **15:05 시간 청산** |
| 같은 봉 본전·목표 | 본전(보수적, 신동 규격과 같다) |
| 슬리피지 | 본전·시간 청산 1틱(0.02pt), 지정가 목표 0 |
| TP1 이전에 나간 레그 | 실제 그대로 |
| 조건 불충족 | 실제와 같다(차이 0). 사유를 `skip_reason` 에 남긴다 |
| 흐름 미수집 | `cond_met = NULL` — **「불충족」이 아니라 미측정**(계측 4원칙 ②) |
| 실제 손익 | 기록된 `gross_pnl_krw` 에서 **CREON 요율로 수수료만 다시 뺀다**(실체결·실슬리피지 유지) |

`r2`(개장 확정)는 **기록만** 하고 조건에 쓰지 않는다. 조건을 여럿 두고 나중에 고르면
반사실에서 경계한 다중비교가 다시 생긴다.

## 3. 판정(사전등록)

| 항목 | 값 |
|---|---|
| 판정 시점 | 채점 시작 후 **흐름 측정일 20일**이 찬 날 장후 |
| 판정 창 | 그 20일(미륵이 진입이 없던 날도 포함 — 그날 차이 0) |
| 최소 표본 | 러너가 실제로 적용된 포지션 **10건** 미만이면 **INSUFFICIENT**(판정 불가 — 통과가 아니다) |
| ① | 누적 차이(섀도 − 실제) **> 0** |
| ② | 차이 기준 **상위 3일을 뺀** 누적 차이 **≥ 0** |
| ③ | 최악일 악화(실제 최악일 − 섀도 최악일) **≤ max(|실제 최악일| × 0.5, 10만 원)** |
| PASS | ①②③ 모두 |

- ②가 이번 사전등록의 핵심이다. 반사실에서 신동 청산은 ①을 쉽게 넘었지만 ②에서 무너졌다.
- **PASS 여도 자동 적용하지 않는다.** 미륵이 청산 경로 변경은 주간회의 안건이며,
  채택한다면 새 버전으로 실거래 전 섀도를 한 번 더 돈다.
- FAIL 이면 섀도를 끈다(기록은 지우지 않는다).
- ⚠ 결과를 본 뒤 기준을 완화하지 않는다(458차 D6).

### 3-2. 진입 필터 B (`SDF-2026-09-24-v1`, 2026-09-24 추가 — 채점 시작 전)

| 항목 | 값 |
|---|---|
| 규칙 | 미륵이 진입 분에 신동 MAIN 이 **같은 방향으로 보유 중**일 때만 진입(「방향 + 유지 상태」). 청산은 **실제 미륵이 그대로** |
| 보유 판정 | 신동 진입 분 **<** 미륵이 진입 분 ≤ 신동 최종 청산 분(진입봉 종가 전은 모른다 — 미래 참조 금지) |
| 제외 포지션 | 「진입 안 함」 = 0원 |
| 흐름 없는 날 | `filt_b_pass = NULL` — 실제 그대로 두고 표본에서 뺀다(미측정 ≠ 제외) |
| 판정 창·①②③ | §3 과 같다(흐름 측정일 20일 · 누적 > 0 · 상위 3일 제외 ≥ 0 · 최악일 악화 한도) |
| 최소 표본 | 필터가 **제외한** 포지션 **10건** 미만이면 INSUFFICIENT — 제외가 적으면 필터가 한 일이 없다 |
| 기록 전용 | `flow_trend`(09:00 이후 콜−풋 추세) — 판정하지 않는다(다중비교 방지) |

- 시뮬이 없다(실제 체결을 쓰고 빼기만 한다) — 러너보다 편향이 작다.
- ⚠ 신동 R2 는 흐름 수집 피크 스킵(09:00–09:02) 때문에 실제로는 09:02 이후에야 알 수 있다.
  09:01–09:02 미륵이 진입은 필터가 약간 후하게 본다(그 창의 진입은 드물다).
- PASS 여도 자동 적용하지 않는다 — 미륵이 진입 게이트 변경은 주간회의 안건이다.
