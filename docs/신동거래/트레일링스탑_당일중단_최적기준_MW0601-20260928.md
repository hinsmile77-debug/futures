## 1. 방법

| 항목 | 내용 |
|---|---|
| 트레일 | 진입가 대비 유리한 극값이 **발동(act) pt** 이상이 되면 손절 = 극값 − **간격(dist) pt**, 단조(뒤로 안 감). 1차·최종 목표는 유지(`keep`) 또는 최종 없이 트레일로만(`no2`) |
| 봉 내부 가정 | 한 봉 안에서는 **이전 봉까지의 트레일 손절**로 먼저 검사하고, 그 봉 극값은 다음 봉부터 반영(보수적). 트레일 청산은 시장가 1틱 슬리피지 |
| 격자 | act {2,3,4,5,6,8} × dist {1,1.5,2,3,4} × {keep, no2} = 60 + 현행 |
| 당일 중단 | (G) 당일 실현 누적 ≥ G 이면 신규 진입 중단 · (A,K) 고점 ≥ A 뒤 고점 − K 이하로 밀리면 중단 |
| 평가 | 74일 R3 가격 대리(px 0.5/1.0/1.5) — 순손익 · 후반기(H2 = 08-07–09-28) · 일누적 MDD · 부트스트랩 P(Δ≤0) + **흐름 4일 실측(R2+R3)** |
| 검증 | 하네스는 트레일을 끄면(act=999) 엔진 `run_trade` 와 원 단위까지 같고, X4NF 는 엔진 결과와 같다 |

흐름 4일 전체(R2 에도 트레일)로 재면 간격 1pt 는 더 나쁘다 — MAIN **+390만 → +130만(4/1) · +97만(3/1)**.
9/22 R3(29pt 추세)와 9/23 R2(20pt)가 1pt 트레일에 몇 pt 만에 잘린다.

**비유** — 간격 1pt 트레일은 「조금만 흔들려도 내리는 승객」이다. 박스권 날엔 손실 전에 내려 이득을 보지만,
추세일엔 목적지 직전까지 갈 버스에서 첫 정거장에 내린다. 간격 4pt 는 흔들림은 견디고 **되돌아 내려오는 버스에서만** 내린다.

→ **권고: R3 에만, 발동 4pt · 간격 4pt** (차선 4/3). 대리에서 현행 대비 +1,000만대, H2 가 3종 중 2종 흑자 전환,
MDD 절반 이하. 추세일(흐름 4일)은 거의 그대로(+128 vs +138만).

- 9/28 손실은 트레일로 막히지 않는다 — 손실 3건의 MFE 가 2.84 / 2.50 / 1.56pt 로 발동선(4pt)에 못 갔다.
  그날을 구한 것은 진입 쪽(F2·flip 금지)이었다.
- 수익률 환산(참고, px1.0 · 2계약 · 74거래일): 트레일 4/4 **+2,049만 = 일평균 +27.7만**, 현행 +450만 = +6.1만.
  목표자본 5천만 원 대비 일 +0.55% vs +0.12%. **대리 수치라 기대 성과가 아니다.**

## 5. 권고

1. **당일 수익중단은 도입하지 않는다.** 근거가 9/28 하루(흐름일)뿐이고 74일 대리에선 약하거나 악화다.
2. **R3 트레일 4/4 를 네 번째 섀도 후보로 검토** — X4NF 와 대체 관계이므로, 둘 중 하나만 올린다면
   이미 운용 중인 X4NF 를 유지하고 트레일 4/4 는 **같은 판정 창에 비교 기록만** 붙이는 편이 다중비교를 덜 늘린다.
3. 간격 1–1.5pt 트레일은 **어떤 형태로도 채택하지 않는다** — 추세일에서 R2·R3 러너를 잘라 신동의 핵심 수익원을 없앤다.
4. R2 에는 트레일을 걸지 않는다 — R2 는 추세일 러너가 수익의 대부분이다(9/23 +134만, 9/28 +101만).

## 6. 한계

- 트레일은 1분봉으로만 판정했다. 봉 내부 경로를 모르므로 보수 규칙(이전 봉 손절로 먼저 검사)을 썼지만,
  간격이 좁을수록 1분봉 해상도의 오차가 커진다 — 4pt 간격을 권고하는 이유 중 하나.
- R2 는 대리할 수 없어 당일 중단의 74일 평가는 R3 만의 누적이다. 실제 신동은 오전 R2 수익이 먼저 쌓이므로
  당일 중단 발동이 더 잦을 것이다(흐름 4일 결과가 그 방향).
- 흐름 4일은 규칙을 만든 3일 + 1일이다. 추세일 편향이 있어 「트레일이 러너를 자른다」는 효과가 과대할 수 있다.
