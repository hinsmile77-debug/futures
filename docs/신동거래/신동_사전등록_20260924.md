## 2. 규칙 규격(고정값)

### 2-1. 흐름 원천과 대상 상품

- 원천: `option_flow.db:option_investor_flow` — CpSvrNew7222, **개인** 누적 순매수 **금액(백만원)**.
  계약수는 쓰지 않는다(만기 근처의 싼 외가격 풋이 계약수를 부풀린다 — 9/23 실측).
- 콜−풋 = 개인 콜 금액 − 개인 풋 금액.
- **대상 상품 = 만기가 가장 가까운 위클리**, 달력으로 정한다(`strategy/shindong/calendar.py`).
  - 월요일 → 월위클리(그날 만기) · 화–목 → 목위클리 · 금 → 다음 주 월위클리
  - 🔴 **먼스리 만기주(둘째 목요일이 든 주)에는 목위클리가 상장되지 않으므로 먼스리로 대신한다.**
    예: 2026-10-07·10-08 → 먼스리 / 2026-11-10–11-12 → 먼스리
  - 휴장 이동(**확정**, 2026-09-24 사용자 확인):
    | 상품 | 만기일이 휴장이면 |
    |---|---|
    | 월요일 만기 위클리 | **다음 거래일로 순연** (예: 10/5 개천절 대체공휴일 → 10/6) |
    | 목요일 만기 위클리 | 직전 거래일로 당김 (9/24 추석 → 9/23, 실측 확인) |
    | 월물 옵션·선물(둘째 목요일) | 직전 거래일로 당김 |
  - 🔴 **2026-09-28(월)은 정상 거래일이다.** 설·추석 연휴의 대체공휴일은 일요일·다른 공휴일과
    겹칠 때만 생기고 토요일(9/26) 중복은 대상이 아니다. `config/krx_holidays.py` 에 대체공휴일로
    잘못 등록돼 있던 것을 삭제했다 → 9/28 대상은 **월위클리(당일 만기)**, 9/29 는 목위클리(10/1 만기).

### 2-2. R1 장전 방향

- 08:59 콜−풋 금액의 절댓값 ≥ **50** → 방향을 정한다(양수 = 하방, 음수 = 상방).
- 50 미만 또는 장전 흐름 미수집 → **보류**(개장 진입 없음, R3만 대기).

### 2-3. R2 개장 확정 진입

- 09:01–09:10 중 09:00 대비 **콜−풋이 방향대로 50 이상** 움직이고, 콜과 풋 각각의
  부호도 맞는(하방: 콜↑·풋↓ / 상방: 콜↓·풋↑) 첫 분에 그 분 종가로 진입한다.
- 손절: 09:00부터 진입 분까지 고점 +1.0(매도) / 저점 −1.0(매수).

### 2-4. R3 구조맥점 반전 진입

- 09:30–14:30, 포지션이 없을 때만.
- 구조맥점 = 08:50 목록(09:31부터 09:30 목록 합산).
  터치 = 봉이 맥점 기준 −1.0부터 +1.5까지의 범위에 닿고 종가가 되밀림.
- 터치 후 10분 안에 콜−풋이 반대 방향으로 **50 이상** 움직이면 그 분 종가로 진입한다.
- 손절: 맥점 너머 1.5pt, 터치 이후 극값 +0.5 가 더 멀면 그쪽.

### 2-5. 청산(2계약을 둘로 나눔)

- **1차**: 첫 거리맥점 또는 반대편 OR 끝(진입가에서 2pt 이상 떨어진 것 중 가까운 것) −0.5.
  1차 청산 즉시 손절을 **본전**으로 올린다.
- **최종**: 08:50 목록의 **가장 먼 구조맥점**(그 방향에 없으면 80% 거리맥점 끝) −0.5.
- **시간 청산**: 15:05 봉 종가.
- 흐름 정체만으로는 청산하지 않는다.

### 2-6. 손익 환산(가상)

- 미니선물 1pt = 50,000원, 수수료 CYBOS 편도 0.0098104%.
- 슬리피지: 시장가 1틱(0.02pt). 진입과 손절·시간 청산에 적용하고, 지정가 목표 청산에는 적용하지 않는다.
- 같은 봉에서 손절과 목표가 모두 닿으면 **손절로 본다**(보수적).

## 4. 채점 방식(결정 2)

`python scripts/shindong_scorecard.py` — 장후에 실행한다(읽기 전용).

1. **변형(MAIN / SHADOW_E2F2) × 규칙(R2 / R3)** 별로 거래 수, 승, 승률, 순손익, 거래당 손익.
2. **규칙가 vs 실현가능가.** 라이브 행은 신호를 처음 알아챈 시각(`detected_at`)의 최신
   종가(`detect_px`)로 진입했다고 보고 같은 청산가로 다시 잰다.
   - 🔴 R2는 **구조적으로 늦게 탐지된다.** 수급 수집이 09:00–09:02 서버 피크를 건너뛰기 때문에
     (`WEEKLY_OPTION_FLOW_PEAK_SKIP`) 09:00·09:01 흐름이 09:02 수집에서야 들어온다.
     규칙가는 09:01 종가인데 실제로 알 수 있는 것은 09:02 이후다. 두 값의 차이가 이 비용이다.
3. 일별 표(상품, 장전 콜−풋, 방향, R2 상태, 거래 수, 순손익).
4. 표본에서 빼는 것(건수는 따로 적는다 — 계측 4원칙 ③):
   - 채점 시작 전 행(9/21–9/23 백필은 **복기 전용**)
   - `RETRACTED`(재계산 중 원천 값이 바뀌어 사라진 신호)

## 5. 섀도 E2+F2(결정 4)

| 코드 | 내용 |
|---|---|
| E2 | 1차 청산 뒤 바로 본전으로 올리지 않고, 1차–최종 **중간 지점**에 닿을 때까지 원래 손절 유지 |
| F2 | R3를 **당일 흐름 방향**(09:00 이후 콜−풋 누적)과 같은 쪽으로만 허용 |

- 매분 MAIN과 같은 데이터로 함께 계산해 `variant='SHADOW_E2F2'`로 기록한다. 차트에는 그리지 않는다.
- 10거래일 뒤 MAIN 대비 순손익·최대 손실일을 비교한다. 이기더라도 **바로 채택하지 않는다.**
  55일 가격 대리 검증에서 E2+F2의 우열은 대리 기준에 따라 뒤집혔다(+384만 / −55만 / +108만).
  채택하려면 새 버전으로 개정하고 그 버전의 채점을 처음부터 다시 센다(§6).
