### 2-5. 청산(2계약을 둘로 나눔)

## 4. 채점 방식(결정 2)

`python scripts/shindong_scorecard.py` — 장후에 실행한다(읽기 전용).

1. **변형(MAIN / SHADOW_E2F2) × 규칙(R2 / R3)** 별로 거래 수, 승, 승률, 순손익, 거래당 손익.
2. **규칙가 vs 실현가능가.** 라이브 행은 신호를 처음 알아챈 시각(`detected_at`)의 최신
   종가(`detect_px`)로 진입했다고 보고 같은 청산가로 다시 잰다.
   - 🔴 R2는 **구조적으로 늦게 탐지된다.** 수급 수집이 09:00–09:02 서버 피크를 건너뛰기 때문에
     (`WEEKLY_OPTION_FLOW_PEAK_SKIP`) 09:00·09:01 흐름이 09:02 수집에서야 들어온다.
     규칙가는 09:01 종가인데 실제로 알 수 있는 것은 09:02 이후다. 두 값의 차이가 이 비용이다.
3. 일별 표(상품, 장전 콜−풋, 방향, R2 상태, 거래 수, 순손익).
4. 표본에서 빼는 것(건수는 따로 적는다 — 계측 4원칙 ③):
   - 채점 시작 전 행(9/21–9/23 백필은 **복기 전용**)
   - `RETRACTED`(재계산 중 원천 값이 바뀌어 사라진 신호)

|---|---|
