## 1. 무엇이 잘못됐나 — 2026-09-29 라이브 재현

MAIN R3 매수 4건의 1차 목표가 모두 **1091.50**이었다. 진입가와 비교하면 이렇다.

| 진입 | 진입가 | 1차 | 진입가 대비 | 결과 | 순손익 |
|---|---|---|---|---|---|
| 10:37 | 1091.22 | 1091.50 | +0.28 | 1차 → 본전 | −10,412 |
| 10:43 | 1091.90 | 1091.50 | **−0.40** | 1차 → 본전 | −44,422 |
| 10:59 | 1091.04 | 1091.50 | +0.46 | 1차 → 본전 | −1,409 |
| 11:19 | 1091.84 | 1091.50 | **−0.34** | 1차 → 본전 | −41,421 |

**매수인데 1차 익절가가 진입가보다 낮은** 거래가 2건이다. 4건 모두 이익을 낼 수 없는 구조였다(합계 −97,664원).
규격 §2-5는 1차를 「진입가에서 2pt 이상 떨어진 것 중 가까운 것 −0.5」로 정했으므로, 이 결과는
**규격이 의도한 동작이 아니다.** 결과가 나빠서 바꾸는 것이 아니라, 코드가 규격 문구를 어긴 것이다.

## 2. 원인 — `engine.targets` 의 두 구멍

```
far = [x for x in S(08:50) if side*(x-e) > 0]    # ① 「진입 방향에 있는가」만 본다 — 거리 0.08pt 도 통과
t2  = 가장 먼 것
t2  = t2 - side*0.5                              # ② 버퍼를 **검사 뒤에** 뺀다 → 진입가 뒤로 넘어감
if t2 < t1: t1, t2 = t2, t1                      # ③ 맞바꿈 — 최소거리 검사 없이 1차 자리로
```

9/29는 가격이 08:50 구조맥점 목록의 **맨 위(1092)** 에 붙어 있었다. 1092보다 위에는 구조맥점이 없으므로
「가장 먼 구조맥점」이 곧 진입가 바로 위의 1092였다. 그래서 오전 내내 이 경로를 탔다.
1차 후보(09:30 거리맥점 끝 1098.86)는 정상적으로 2pt 검사를 거쳤지만, ③의 맞바꿈이 그 검사를 무력화했다.

같은 결함이 섀도 3종에도 있다. `SHADOW_X4NF`는 `targets()`의 1차를 받아 「현행이 더 가까우면 현행」을 쓰므로
역전된 1091.50이 그대로 살아남았고, `SHADOW_TR44`와 `SHADOW_E2F2`도 같은 `targets()`를 쓴다.

## 3. 수정 — 최종 후보에도 1차와 같은 최소거리

```python
far = [x for x in S(08:50) if side*(x-e) >= T1_MIN_DIST]     # 2pt 이상만
t2  = 가장 먼 것, 없으면 80% 거리맥점 끝
if side*(t2-e) < T1_MIN_DIST: t2 = None                       # 80% 끝도 2pt 안이면 목표 없음
```

- **값은 하나도 바꾸지 않았다**(`T1_MIN_DIST=2.0`, `TP_BUF=0.5` 그대로). 바뀐 것은 최종 후보를 거르는 조건 하나다.
- 이유: 1차에 이미 있는 규칙(2pt)을 최종에도 똑같이 적용한다. 새 문턱을 만들지 않으므로 결과에 맞춘 조정이 아니다.
- 결함 경로 밖(최종 후보가 2pt 이상 떨어진 경우)에서는 v1과 **출력이 같다** — 무작위 3,000 사례 중 해당 사례 전부 일치(`test_639` D).
- v2 보장: 두 목표 모두 진입가 **너머** 1.5pt 이상이고, 1차가 최종보다 멀지 않다(`test_639` C, 무작위 3,000 사례).

9/29 매수 4건에 적용하면 이렇게 된다. 1092(2pt 안)는 빠지고, 80% 끝 1101.37을 쓴다.

| | 1차 | 최종 |
|---|---|---|
| v1 | 1091.50 (역전) | 1098.36 |
| **v2** | **1098.36** | **1100.87** |

### 8-2. 🔴 불리한 사실 — 결함이 결과적으로 손실을 막고 있었다

두 날 모두 **v2가 더 나쁘다.** 결함은 「진입가 바로 너머 맥점에서 진입 → 1차가 진입가에 붙음 → 사실상 즉시 본전 청산」으로
작동했다. 진입한 자리가 **구조맥점 목록의 끝(더 갈 맥점이 없는 자리)** 이었고, 거기서의 진입은 되돌림에 약했다.
v2는 이런 거래를 정상 목표(8–9pt 너머)로 끝까지 들고 가서 손절까지 맞는다.

- 9/29 MAIN 10:37 매수: v1 = 3분 만에 본전(−10,412) / v2 = 11:42 손절 1086.50(**−497,364**)
- 그 뒤 거래 순서도 바뀐다(보유가 길어져 10:43·10:59·11:19 진입이 사라짐).

⚠ **이것을 「v1이 옳았다」로 읽지 말 것.** 표본은 결함 경로 **5거래**(9/22 1건 · 9/29 4건)뿐이고, v1의 동작은
규격 문구(1차 ≥ 2pt)를 어긴 **우연**이다. 「맥점 끝 진입은 즉시 본전 청산」이 좋은 규칙이라면 그것은 **새 규칙**이며,
결과를 본 뒤 만드는 것이라 별도 사전등록(새 버전·재채점)을 거쳐야 한다(§0 과최적화 경계).

⚠ 반대로 「v2 채택」의 근거도 성과가 아니라 **규격 준수**뿐이다. 이 절은 결정을 뒤집자는 제안이 아니라,
v2 채점이 시작되기 전에 알려진 불리한 사실을 기록해 두는 것이다(사후에 「몰랐다」가 되지 않도록).
