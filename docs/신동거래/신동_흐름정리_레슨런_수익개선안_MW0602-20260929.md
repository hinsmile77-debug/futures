- **R2와 R3는 서로 막는다.** R2 거래가 청산될 때까지 R3는 대기한다(`busy`). 반대로 R3 하나가 들고 있는 동안에도 다음 R3는 없다.
- 거래는 매분 **하루치 전체를 다시 계산**하는 재생 방식이라, 원천 흐름 값이 나중에 바뀌면 이미 나온 신호가 사라진다(`RETRACTED`). 1-3에서 다룬다.

- 엔진 `run_trade(trail=(4,4))`와 MW0601의 `trail.make(4,4)`는 이 PC에서 **같은 값**을 낸다(−228만). 코드 차이가 아니라 **입력 데이터 차이**다. 두 PC는 1분봉과 장전 맥점을 각자 수집·산출한다. 월별 현행 값부터 다르다.
- 뜻: 트레일 성과는 **맥점·봉의 작은 차이에 민감하다.** 반면 X4NF는 두 PC 모두 현행 대비 +1,400~+2,100만 개선으로 **방향이 같다.**
- ⚠ 어느 PC 데이터가 맞는지는 이 문서에서 판정하지 않는다. TR44 섀도의 10거래일 비교 결과를 PC 간에 그대로 옮겨 인용하지 말 것.

## 5. 제안 — 사전등록을 깨지 않는 수익 개선 경로

우선순위 순이다. **어느 것도 MAIN 규격을 바꾸지 않는다.**

### 5-1. [1순위] 새 섀도 `SHADOW_X4NFA` — X4NF + 깨진 맥점 금지

| 항목 | 내용 |
|---|---|
| 규칙 | X4NF 그대로. 여기에 R3 진입 순간 `side × (진입가 − 터치 맥점) ≤ 0`이면 진입하지 않는 조건 한 줄을 더한다 |
| 근거 | 75일 대리 3종 모두 X4NF보다 개선(+484~+1,004만). 전·후반기 흑자. 깨진 맥점 진입은 거래당 부호가 반대. 사후 적합이 아니라 **반전 실패라는 논리로도 설명된다** |
| 반대 근거 | 흐름 5일에서는 X4NF보다 −72만 나빴다. P(Δ≤0) 0.034~0.14로 비유의이고, 다중비교 상태다 |
| 판정(사전등록 제안) | 채점 시작 **9/30**, 10거래일 뒤 MAIN·X4NF와 비교. 채택 후보 조건은 X4NF와 같다: 순손익 우위 **그리고** 최악일 개선 |
| 구현 크기 | `engine.run_day` R3 루프에 조건 한 줄 + `spec.VARIANTS`·`LATE_SHADOW_START` 등록 + 리포트·채점표 표시. `test_626` 재현값은 바뀌지 않는다 |
| 비용 | 섀도가 5개가 된다. 다중비교를 줄이려면 **TR44를 비교 기록에서 내리는 것**을 함께 검토할 것(4-3: 두 PC 결과가 정반대) |

### 5-2. [2순위] 규격을 바꾸지 않는 기록 항목 — 채점표 분리

엔진은 건드리지 않고, 이미 있는 컬럼(`side`·`entry_px`·`touch_level`)만으로 `scripts/shindong_scorecard.py`가 R3를 두 번 더 나눠 보여주게 한다.

1. **깨진 맥점 여부**: 5-1 섀도 없이도 MAIN 안에서 A의 효과를 매일 쌓을 수 있다.
2. **R1 정렬 여부**(방향 판정이 있는 날만): R3 방향 == R1 방향. 흐름 3일에서 같은 쪽 +12.4만 / 반대 쪽 −143.8만(9건)이었다. R1은 가격으로 대리할 수 없어 **표본은 앞으로만 쌓인다.** 조건으로 올리면 다중비교가 늘어나므로 **판정 없이 기록만** 한다.

### 5-3. [3순위] R3 중단 판정 이후를 준비 — 「R2 중심」 경제성

- 지금 추세(채점 2일 R3 13전 3승 −199만)가 이어지면, **10거래일 판정(10/13 전후)**에서 R3가 사전등록 기준으로 중단된다. 그러면 신동 = R2만 남는다.
- R2는 3전 3승 +285만이지만, MW0601 R2 단독 연구에 따르면 **R1 적중률 약 58%가 손익분기**다. R1 적중은 현재 3/3이고, 보류일(9/22·9/29)은 R2가 없다.
- 준비할 것: 채점표의 R1 적중률 표시(이미 있음)와 함께, 보류일 비율과 R2 확정률을 **판정 전에** 같은 표에 둔다. R3 중단 뒤 「그러면 R3 대신 무엇을」을 결과를 보고 고르지 않기 위해서다.
