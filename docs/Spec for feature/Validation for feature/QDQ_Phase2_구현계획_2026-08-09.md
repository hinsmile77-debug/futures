## 1. 이 Phase가 답해야 할 단 하나의 질문

> **`anchor_buy_share`가 0.50 근방인가, 0.63 근방인가?**

- **0.50 근방** → 발견 A(체결구분 파싱 결함) **라이브 확정**. Phase 3 착수 가능.
- **0.63 근방** → 매수 편향이 시장 실체이고 **내 진단이 틀렸다.** Phase 3 취소.

Phase 0·1은 이 판정을 내리기 위한 배선이었다. Phase 2는 그 배선에서 판정을 뽑아
매주 자동으로 재확인한다. 나머지 지표는 전부 이 판정의 신뢰도를 재는 보조다.

### 현재 상태 — 계측 미개시

```
raw_candles  anchor_buy IS NOT NULL : 0행
             buy_vol_flag IS NOT NULL: 0행
최신 봉      2026-08-07 15:09  (Phase 0 배포는 2026-08-09 일요일)
```

**따라서 이 리포트의 첫 임무는 "아직 못 잰다"를 정확히 말하는 것이다.**
0을 계산해 놓고 통과시키면 `toxicity_block_shadow`가 자기모순 조건으로 3개월간
0건인 채 방치된 402차 후속3과 같은 사고가 된다.

## 2. 설계

### 2-1. 🔴 `anchor_diff` — 크기 축을 둘로 나눈다

QDQ 보고서 §1.3의 경고: *"누적끼리 비교하면 오전에 생긴 오차가 오후에는 누적거래량으로
나눠지면서 작아 보인다."*

우리 스키마에서 `anchor_buy`는 **이미 봉 단위 증분**이다(Phase 0 `_read_trade_anchor`가
누적값의 차분을 저장). 즉 `anchor_diff: true`가 구조적으로 만족된다. 다만 **집계할 때**
같은 함정을 다시 만들 수 있다:

| 축 | 식 | 성질 |
|---|---|---|
| ①-순 | `\|Σ(자체 − 앵커)\| / Σvolume` | 봉끼리 **상쇄된다**. 오전 +100 / 오후 −100이면 0으로 보인다 |
| **①-절대** | `Σ\|자체 − 앵커\| / Σvolume` | 상쇄 없음. **이쪽이 진짜 지표다** |

둘 다 출력하고, **판정은 ①-절대로 한다.** 두 값이 크게 벌어지면 그 자체가
"오차가 방향을 바꿔가며 났다"는 정보다.

### 2-2. 대조는 두 쌍이다

| 쌍 | 의미 | 기대 |
|---|---|---|
| **legacy vs anchor** (`buy_vol` vs `anchor_buy`) | 지금 라이브가 얼마나 틀렸나 | 괴리 **큼** (발견 A 재현) |
| **shadow vs anchor** (`buy_vol_flag` vs `anchor_buy`) | Phase 3에서 쓸 수정안이 정답지와 맞나 | 괴리 **≈0** |

두 번째가 핵심이다. 이게 0에 수렴해야 Phase 3의 전환 대상(올바른 체결구분 파싱)이
서버 정답지와 동등함이 증명된다. 크면 체결구분 분류 자체의 한계를 뜻하고,
Phase 3은 앵커 직접 사용으로 설계를 바꿔야 한다.

> 매도 쪽은 따로 재지 않는다 — 항등식(§2-3)이 성립하면 `sell_diff = −buy_diff`가
> 수학적으로 강제된다. 대신 **항등식 자체를 별도 축으로 검증**한다.

### 2-3. 항등식 3종 (Q DQ 보고서 §2.3의 "부등식이 아니라 항등식")

| # | 식 | 위반 의미 |
|---|---|---|
| I1 | `anchor_buy + anchor_sell == volume` | 서버 정답지가 우리 거래량과 안 맞음 → 필드 의미 재확인 필요 (공식 xls에서는 정확히 성립) |
| I2 | `buy_vol_flag + sell_vol_flag == volume` | 잔차 = **미분류 틱 물량**. 양수 정상(디코딩 실패분), **음수면 이중 집계 버그** |
| I3 | `buy_vol + sell_vol == volume` | 라이브 경로에선 구조상 항상 성립 — 깨지면 수집기 회귀 |

### 2-4. 판정 규칙 (히어로)

```
계측 봉 < MIN_BARS(300)                      → ⏳ 계측 미개시/부족 — 판정 보류
I1 위반율 > 1%                                → ⚠ 앵커 신뢰 불가 — 필드 의미 재확인
anchor_share ∈ [0.45,0.55] & legacy_share ≥ 0.58 → ✅ 발견 A 확정 · Phase 3 착수 가능
anchor_share ≥ 0.58 (legacy와 동급)           → ❌ 진단 오류 · Phase 3 취소
그 외                                         → ⚠ 판정 애매 — 표본 확대
```

임계값은 **지금 정한 판단 기준**이며 캘리브레이션된 값이 아니다. QDQ 보고서 §6의
3단계(관측 2~4주 → p99 보정 → 운영)를 아직 안 거쳤다. 리포트 본문에 그 사실과
근거를 함께 찍어 "조용히 완화된 임계치"가 되지 않게 한다.

### 2-5. 게이팅 없음

종료코드는 **항상 0**(생성 실패만 1). 진입 차단·신호 억제 일절 없다.
CB②·CB③-P4·FP-CRITICAL이 "계측이 덜 익은 상태에서 차단부터 켰다가 상시 발동으로
껐다"는 같은 실패를 겪었다(CLAUDE.md §2). 네 번째를 만들지 않는다.
