## 0. 착수 전 확정한 사실 (구현 중 재확인 완료)

1. **`predictions` 스키마**: `ts, horizon, direction, confidence, actual, correct, up/down/flat_prob, sigma_at_t`
   — L4에 필요한 열 전부 존재 (94,109행).
2. **`raw_candles` 스키마**: `open, high, low, close, bid1, ask1, ...` — N5의 다음봉 시가 기준 타겟
   가능. `bid1/ask1`이 있어 mid 기준도 커버리지 확인 후 병행 가능.
3. **왕복비용 정본**은 `generate_validation_campaign_report.py:137 _roundtrip_cost_pt(avg_price)`
   `= 2×price×FUTURES_COMMISSION_RATE(0.000015) + 2×slippage_ticks_per_side(1.0)×TICK_SIZE(0.02)`.
   **0.133pt vs 0.0711pt 괴리의 원인 규명**: 0.0711은 이 정본 산식(미니선물 틱 0.02) 값이고,
   394차 문서의 0.133은 슬리피지를 **일반선물 틱 0.05 기준 2틱(0.10pt)** 으로 잡은 구 가정이다
   (TICK_SIZE는 235차에 미니 0.02로 교정됨 — 문서 가정이 교정 전 값을 씀).
   → **L2·N1은 정본 산식을 기본값**으로 쓰되, 0.133pt 고정 시나리오를 **병기 열**로 항상 출력한다
   (07-30·08-02 계획 문서가 0.133을 사전등록 문구로 쓰고 있으므로, 어느 쪽을 판정 기준으로
   삼을지는 주간회의 결정 사항 — 그때까지 둘 다 보이게 해서 조용한 기준 변경을 막는다).
4. **환경**: 주간 체인(`campaign_steps.py`)은 `sys.executable`(py310_64)로 스텝 실행.
   신설 스크립트는 py37_32 호환 문법 + numpy 전용(scipy.spearmanr MKL 크래시 회피 — 454차 선례).
5. `scripts/`는 네임스페이스 패키지로 import 가능 (`from scripts.campaign_report_paths import ...` 선례).

## P2 — N1: 비용 문턱 IC\*(h) 표 (`scripts/ic_cost_hurdle_table.py`)

- IC\*(h) = c / (E[z|top q] · σ_h). E[z|z>z_q] = φ(z_q)/q (표준정규 절단 평균, 수치 적분 불요).
- σ₁: 관찰창 일자별 "당일 1분 Δclose(pt) std"의 **중앙값**(이상치 견고). σ_h는
  ① √h 스케일링(σ₁√h) ② **실측**(비중복 h-간격 Δclose std) 둘 다 출력 — 일중 평균회귀로
  실측 σ_h < σ₁√h이면 √h 가정의 낙관 정도가 그대로 보인다.
- c: 정본 산식 + 0.133 병기(§0-3). q ∈ {5%, 10%, 20%}.
- 출력: stdout 표 + `data/ic_hurdle_latest.json`. **"advisory — 판정 효력 없음. 게이트형
  진입+ATR 청산 구조에는 근사"** 고정 문구 포함. [1] 채널 합격선(0.03/0.05)과의 대비 각주.
- 인자: `--days 120`.

## P4 — N2: IC 감쇠 곡선 전 격자 카탈로그 (`scripts/ic_decay_catalog.py`)

- 격자 **h ∈ {1,3,5,10,15,30}** (h=60 제외 — 15:10 강제청산·30m 퇴역 이력). 방법론은
  `core_feature_discovery`와 동일(일자단위 IC·Bonferroni·split-half — rankdata/corr/tstat/
  build_matrix/load **import 재사용**, 기존 3점 도구는 무수정).
- Bonferroni 가족 = 피처 수 × **6** — 이 채널 고유값으로 사전등록(`config/settings.py:
  IC_DECAY_CATALOG` 신설, inert advisory 설정 — 기존 3점 채널 판정과 불혼합).
- 피처별 산출: 부호 유지 IC 곡선, `peak_h`, 지수 피팅 `τ`(ln|IC| 최소자승, peak 이후·동부호
  구간)·`half_life=τ·ln2`·`R²`, **유형 분류** {단조감쇠 / 봉우리 / **증가형** / **부호반전**
  / 무정보}, 회전율 프록시(일중 lag-1 자기상관 ρ₁ → √(2(1−ρ₁))).
- 유형 판정(사전등록): 무정보 = 전 h Bonferroni 미달 / 부호반전 = |t|≥2인 두 h가 반대 부호 /
  단조감쇠 = peak가 h=1 / 증가형 = peak가 격자 끝(진짜 피크는 격자 밖 — 일 단위 공변동
  의심, L2 함정 경고와 함께 읽기) / 봉우리 = peak가 내부.
  *(증가형은 첫 실측 스모크에서 수급 계열이 전부 "봉우리"로 오분류되는 것을 보고 같은 세션
  내(어떤 판정 소비 전)에 추가한 5번째 유형 — 사후 기준 변경이 아니라 첫 관측 전 확정이다.)*
- **변동성 정규화 병행 열**: fwd_norm = Δclose / (당일 past-only EWMA σ₁ × √h). 원시·정규화
  IC의 부호가 갈리면 "시간대 의존" 플래그(기존 타겟 정의는 무변경 — 병행 계측만).
- 노이즈 5종(P3) 상시 포함 + 하한선.
- **부호반전형은 별도 섹션** "청산/역추세 후보"로 출력 — 진입 제안 아님, 챌린저 계층 입력.
- 출력: stdout + `data/ic_decay/ic_decay_catalog_YYYYMMDD.{json,md}`(런타임 산출물 — 커밋 금지).
- 주기: 월간(수동 → Phase C 구현 시 그 체인에 편입). 주간 체인에는 넣지 않는다.

## P6 — N5: bounce 1회성 검증 (`scripts/bounce_artifact_check.py`)

- 단기 h ∈ {1,3,5}에서 타겟 3벌 대조: ① close→close(현행) ② **open[t+1]→open[t+1+h]**
  (다음봉 시가 진입 — bounce 제거) ③ mid(bid1/ask1 커버리지 ≥80%일 때만).
- 대상 피처(기본): `cvd_divergence, cvd_delta_norm, cvd_slope, ofi_norm, vwap_position,
  microprice_bias` (CORE 실소비 + 마이크로 계열).
- 산출: 피처×h별 IC_close / IC_open / IC_mid + bounce 성분 추정(IC_close − IC_open).
- **효력**: CORE 교체 근거 아님(§3) — "단기 IC 해석 할인율" 문서화용. 결과는 DECISION_LOG 기록.
