- **재난 손절 검증(6일)**: 하드 손절 3/5/8/12pt 는 +153.7/+280.3/+834.4/+743.0(최악일 −97.7/−157.6/−99.0/−190.4)로 **전부 악화** — 손절 뒤 같은 신호로 재진입해 또 잃는다. 20pt(≈0.6×ATR14)는 6일 무변경(+875.1). 흐름 반전 청산도 악화(+736.2). 그래서 「넓은 재난 손절 + 발동 시 당일 중단」이다.
- **FLOWF 의 6일 사전 점검은 나쁘다**(9/22·9/23 — 외국인이 샀고 장은 내린 날). 구현계획 B0 대로 **K 를 바꾸지 않는다**(바꾸면 사후 선택). 76일 walk-forward 근거(+1,719~1,893만)와 6일 표본 안 값이 갈리는 것 자체가 기록할 사실이다.
