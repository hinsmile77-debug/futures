# 신동 MAIN 리모델링 제안 — v1(R2+R3) → v2, 섀도 체계 재편 (MW0602 · 2026-09-30)

- 요청: 현행 MAIN(`SD-2026-09-24-v1`, 6일 채점)을 6일 결과로 세운 더 합리적인 진입·청산 체계로 **교체**하고, 그에 맞춰 섀도 체계를 다시 짜자. 채점은 다시 해도 좋다. 손익을 조사해 제안하라.
- 성격: **제안.** 코드·규격 무변경. 손익은 같은 하네스·같은 비용(2계약 · CYBOS · 1틱)으로 다시 쟀다(`docs/신동거래/최적조건_탐색_20260930_MW0602/remodel_pnl.py`).
- 규약과의 관계: 사전등록 §6은 「규격 변경은 **새 버전 + 재채점**으로만」이다. 이 제안은 정확히 그 경로다 — v2를 새 `SPEC_VERSION`으로 사전등록하고 채점을 처음부터 하며, **v1은 섀도로 계속 기록**해 창을 끊지 않는다. 규약 위반이 아니다.

## 2. 제안 — v2 규격과 섀도 재편

### 2-1. MAIN v2 = `FLOWC` (규격 `SD-2026-10-01-v2` 안)

| 항목 | 규칙 |
|---|---|
| 원천 | 개인 위클리 콜·풋 **순금액**(현행 R1·R3와 같은 `option_investor_flow`, 상품 선택 `select_flow_product` 그대로) |
| 기준점 | 09:00 값(없으면 09:00 이후 첫 값 — 09:00 봉 결손일 대비) |
| 진입 | 콜−풋 누적 변화 **≥ +300 → 매도** / **≤ −300 → 매수**. 신호 봉 종가. 포지션 없을 때만 |
| 손절 | 없음 — 트레일이 대신(6일·76일 대리 모두 「손절 없음+트레일」이 「손절 3~5pt」보다 나았다. 09:34·14:35 같은 찌름을 견디기 위함) |
| 트레일 | 유리하게 **6pt** 가면 손절 = 극값 ∓ **4pt**(한 방향으로만, 그 봉 극값은 다음 봉부터) |
| 익절 | 진입가 ± **12pt** 지정가 |
| 횟수·시간 | 하루 **최대 3회** · 신규 진입 14:50까지 · **15:05 시간 청산** |
| 수량 | 2계약 일괄(1차·최종 분할 없음) |
| R1·R2·R3 | **없음.** R1 판정·R2 확정은 `shindong_day`에 계속 **기록**(섀도 V1·BRKC와 채점표 R1 적중률이 쓴다) |
| 보류일 | 거래한다(R1 무관) |
| 비용 | 현행과 동일 |

**왜 이 값들인가(사전등록에 적을 근거)** — K=300·트레일 6/4·익절 12·3회는 흐름 6일 격자의 최적이고 **둥근 값**이다(9/30 문서 §4). 최적 주변이 평탄한지(9/30 하루에서 K 100~300 중앙 +85, 트레일 (6,6)~(12,x) 중앙 +70~+110)를 확인했다. **결과를 보고 바꾸지 않는다** — 바꾸면 v3.

## 3. 대안 — 보수안 (권고하지 않지만 열어 둔다)

**v2 = `V1X4`(R2 + X4NF)** 로 가고 FLOWC·FLOWF·BRKC를 섀도로 두는 안.

| | 권고안(v2=FLOWC) | 보수안(v2=V1X4) |
|---|---|---|
| 6일 | +875 | +262 |
| 근거 길이 | 직접 6일 · 간접 76일 | 직접 76일 대리 |
| 흐름 체제가 바뀌면 | MAIN이 흔들린다(V1X4 섀도가 대안) | MAIN은 버티고 FLOWC 섀도가 기회 |
| 되돌림 | V1 대조군 | V1 대조군 |
| 후회 | 흐름 우위가 이어지면 보수안은 20일치 격차를 잃는다 | 흐름 우위가 6일짜리였다면 권고안은 20일치 손실을 본다 |

두 안 모두 섀도 집합은 같다 — 다른 것은 **차트에 그리는 것과 판정의 기준점**뿐이다. 신동은 주문이 없으므로 **경제적 비용은 없다.** 그래서 권고안이다: 기준점이 흐름 규칙이면 「흐름 체제가 유지되는가」를 매일 정면으로 보게 되고, 그것이 지금 가장 알아야 할 질문이다.
