## 3. F-4 프로필 폴백 설계 메모 (구현 전)

- 검색 오류(PAGE_ERROR, 또는 `rl.rem==0`) → 같은 탭을 `https://x.com/PeterLeejoa` 로 이동 → reset 뒤 검색 복귀.
- `content.js` 자격 규칙(`offSearch`)에 프로필을 **2급 원천**으로 추가하고 하트비트에 `source=profile` 을 싣는다.
  611차 가드(홈 타임라인 오염 방지)는 그대로 — 허용 목록에 프로필 URL 하나만 더한다.
- ⚠ 프로필 기본 탭은 **답글을 보여주지 않는다**. 피터가 지시를 자기 글의 답글로 단 적이 있으면 빠진다 →
  `_raw` 이력에서 답글형 지시 비율을 먼저 잴 것. 비율이 0이 아니면 `with_replies` 탭(UserTweetsAndReplies)을 쓴다
  (훅은 이미 그 엔드포인트도 잰다).
- 매니페스트 `content_scripts.matches` 에 `https://x.com/PeterLeejoa*` 추가가 필요하다.
