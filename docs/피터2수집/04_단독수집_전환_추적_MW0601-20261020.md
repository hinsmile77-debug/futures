# 04. 단독 수집 전환 — MW0602 수집기 중지 효과 추적 (MW0601 698차)

## 1. 결정 (2026-10-20 사용자)

> 새 X 계정을 만들지 않고, **MW0602 피터2 수집기를 10-20부터 끈다.** 10-20부터는 MW0601 단독 수집이다.
> 이후 변화를 추적하고 개선 여부를 확인한다.

03 판정절차 §4의 **②안**이다(①안 = 전용 계정은 채택하지 않음). 10-19 장후 697-2 결과가
「다른 소비자 있음」 가지로 나왔기 때문이다.

## 2. 근거 — 10-19 기준선 (MW0602가 함께 돌던 마지막 날)

`logs/peter2_receiver_20261019.log` 의 `RATE` 줄을 보면 우리 수집기는 80초마다 2번 요청한다
(`n=1`, `n=2` 연속 2줄). 그런데 그 사이에 남은 한도(rem)가 **5–6씩** 줄었다.

```
09:32:22 rem=48   ← 우리 요청 (n=2)
09:33:39 rem=46   ← 우리 요청 (n=1) — 그 사이 1회 외부 소진
09:33:40 rem=45
09:34:58 rem=41   ← 그 사이 3회 외부 소진
```

| 지표 (09:00–15:20) | 10-19 기준선 |
|---|---|
| 한도 창당 외부 소진(중앙값 / 최대) | **27 / 35회** (24개 창) |
| 429(한도 초과) | **23건** |
| 트윗 지연 p50 / p90 / max | 65 / **237.2** / 364초 |
| PAGE_ERROR · 오류 있는 분 | 248건 · 63/380분 |

우리 몫만 보면 15분 창당 약 22회로 한도 50회의 절반이 안 된다. **혼자라면 429가 나지 않는 양이다.**

## 3. 사전등록 판정 기준 (2026-10-20 07:50, 결과를 보기 전에 고정)

평가 창: 10-20부터 **수신기 로그가 있는 평일 5거래일**(휴장·미기동일은 건너뛰고 미측정으로 표시).

| # | 무엇 | 합격선 |
|---|---|---|
| ① | 단독 확인 — 외부 소진이 사라졌나 | 그날 정규장 한도 창(관측 ≥ 5줄)의 외부 소진 **중앙값 ≤ 3** |
| ② | 한도 초과 소멸 | 그날 정규장 429 **≤ 1건** |
| ③ | 지연 개선(주 판정) | 평가 창 통합 트윗 지연 **p90 ≤ 90초**, 통합 n ≥ 30 (615차 합격선 그대로) |

| 최종 판정 | 조건 | 다음 할 일 |
|---|---|---|
| **IMPROVED** | ① 4일 이상 PASS 且 ③ PASS | 종결. F-4(프로필 폴백) 하지 않는다. |
| **NOT_LIMIT** | ① 4일 이상 PASS 且 ③ FAIL | 한도는 풀렸는데 지연이 남음 → 03 §2 「혼자 소진」 가지(RELOAD_SEC 역산 → F-4) |
| **STILL_SHARED** | ① 4일 미만 | MW0602 중지가 반영 안 됐거나 다른 소비자(같은 계정으로 사람이 X 검색) → **사용자 확인** |
| INSUFFICIENT | 통합 트윗 n < 30 | 평가 창 연장(기준은 그대로) |

⚠ 결과를 본 뒤 합격선을 바꾸지 말 것(458차 D6 · §9-4). 상수는 `tests/test_698_peter2_sole_collect_tracker.py` 가 고정한다.

## 4. 추적 방법

```
python tools/peter2_live/sole_collect_tracker.py                 # 오늘까지 누적 표
python tools/peter2_live/sole_collect_tracker.py --upto 2026-10-26
```

- 장후 점검 증거 수집기(`collect_evidence.py --phase post`) §9-e에 매일 요약이 자동으로 실린다.
- 기준선(10-19)은 표에 함께 나오지만 판정에는 들어가지 않는다.

## 5. 가장 먼저 볼 신호

10-20 장중 `RATE` 줄에서 **우리 요청 2줄 사이 rem 감소가 1**이면 MW0602가 실제로 꺼진 것이다
(10-19에는 4–6). 첫날 오전 창 몇 개만 봐도 ①은 거의 결판난다. ③(지연)은 5거래일을 모아야 한다.
