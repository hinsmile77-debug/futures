### 4-3. 왜 승률 58.8%인데 적자인가 — 산술

```
승 10건  평균 +1.030pt  (중앙 +0.560)
패  7건  평균 −2.660pt
손익비 0.387  →  손익분기 승률 72.1%  vs  실제 58.8%
기대값 = 0.588×1.030 − 0.412×2.660 = −0.49pt/건   (실제 −8.32/17 = −0.49 ✓)
```

**설계 기하가 원인이다.** 로그에서 직접 확인한 값:

```
하드스톱      = ATR × 1.50            (ATR_STOP_MULT)
TP1(보호전환) = ATR × {1m 0.3, 3m 0.5, 5m 0.7} × hurst배수
보호 스톱     = ATR × 0.25            ← 호라이즌 무관 상수 (main.py:202)
```

즉 **보호전환에 걸린 "승리"의 가치는 0.25 ATR, "패배"는 1.50 ATR — 1:6이다.**
이 조합만으로는 손익분기 승률이 **85.7%**다.

그리고 `0.25`가 호라이즌을 모르기 때문에 **유지율이 호라이즌에 반비례한다**:

| 호라이즌 | TP1 | 보호 | TP1 대비 유지율 |
|---|---|---|---|
| 1m | 0.3×ATR | 0.25×ATR | 83% |
| 3m | 0.5×ATR | 0.25×ATR | 50% |
| 5m | 0.7×ATR | 0.25×ATR | **36%** |

오늘 실측 유지율은 33~50%로 정확히 이 예측과 일치한다(#10: 5m, +0.96 → +0.20 = 33%).

**의도된 설계가 아닐 가능성이 높다.** TP1은 374/387차에 호라이즌별로 분화됐는데
보호 lock은 339차의 상수 그대로 남았다.

### 7-3. 🔴 `stop_intrabar` 딥다이브 — 봉중 하드스톱만 계통적으로 유리하다

`exit_fill_slippage`(07-27~08-05, 68건)를 경로별로 가르면 이분법이 선명하다:

| 경로 | n | 합계pt | 평균 | 유리비율 | 부호검정 p |
|---|---|---|---|---|---|
| **봉중 하드스톱** (`stop_intrabar` + 태깅 전 `하드스톱`) | 13 | **−24.51** | −1.885 | **13/13** | **0.00024** |
| 틱 하드스톱 (`stop_tick` + `하드스톱(틱)`) | 42 | +2.12 | +0.050 | 17/42 | 0.280 |
| 목표 경로 (TP1/TP2/손절1차) | 13 | −0.38 | −0.029 | 7/13 | 1.000 |

*(음수 = 유리)* 봉중 vs 틱 Mann-Whitney **p<1e-6**.
**틱 경로는 대칭이고(정직), 봉중 경로만 13/13 전건 유리다.**

**메커니즘 확정** — `main.py:12278` 부근:

```python
_effective_stop = stop_price if _close_stop_hit else _prev_stop_price
exit_price = min(_effective_stop, bar_high)      # SHORT
price_hint = exit_price ;  hint_source = "stop_intrabar"
→ 시장가 주문 전송 → 그 사이 가격이 이동한 곳에서 체결
```

실례 (08-04 12:04):
```
12:03:52  진입 SHORT @ 976.50
12:04:26  TP1 부분청산 → 보호스톱 976.50(본전)으로 조임
12:04:52  봉 마감 점검: bar_high ≥ 976.50  → "스톱 히트"로 판정
          ⚠ 그 고가는 12:04:26 **이전**에 발생 — 스톱이 그 자리에 있기 전이다
12:04:53  시장가 체결 @ 973.12  → +3.38pt (= 유리 체결분과 정확히 일치)
```

보호스톱이 본전이라 정상 체결이면 **0.00pt**여야 한다. 기록된 이익은 전부
"유령이 발동한 순간 포지션이 얼마나 이익 중이었나"다. 423차가 진단한 **유령 하드스톱**이
맞고, 424차가 배포한 억제(`phantom_stop_shadow`)의 대상이 바로 이것이다.

### 7-4. ⚠ 그러나 "가짜 이익"은 아니다 — 자체 정정

**직전 조사 발표에서 "실현손익의 146%가 슬리피지", "qty=2 사다리 실질 +2.75pt"라고
했는데, 그것은 회계 분해를 반사실로 오독한 것이다. 정정한다.**

올바른 반사실은 "체결가가 hint였다면"이 아니라 **"유령이 발동하지 않았다면"** 이다.
억제되면 포지션은 계속 달려 다른 곳에서 청산된다. 1분봉 재생 결과:

| 진입 | 유령 청산 | 실현 | 억제 시 대체청산 | 대체손익 | 차이 |
|---|---|---|---|---|---|
| 08-04 11:27 | 11:29 | +4.02 | 보호스톱 | +0.85 | **−3.17** |
| 08-04 11:55 | 11:58 | +1.12 | 보호스톱 | −0.00 | **−1.12** |
| 08-04 12:03 | 12:04 | +3.38 | **TP2** | +3.79 | **+0.41** |
| 08-04 12:08 | 12:11 | +4.26 | **TP2** | +4.78 | **+0.52** |
| 합계 | | +12.78 | | +9.42 | **유령 순기여 +3.36** |

그리고 **08-05는 억제가 배포된 뒤**라 직접 관측된다 — 억제 5건에서
유령 발동 시 +6.36 vs 실제 **+6.74** → **억제가 오히려 +0.38pt 유리**.

→ 9개 이벤트 통산 유령 순기여 ≈ **+3.0pt**이지 +13.54pt(회계상 유리 체결분)가 아니다.
**"423/424차 억제가 흑자를 없앤다"는 우려는 근거가 없다.** 억제는 옳고, 손익 영향은
사실상 중립이다.
