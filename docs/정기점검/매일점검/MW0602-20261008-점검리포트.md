## 4. 고도화 방안

1. **FreezeSentinel의 "정상 종료 확인" 3플래그 중 최소 1개를 `main.py`의 정상 흐름이 더 일찍 쓰게 하는 방안 검토.** 현재는 `daily_close()` 완료 시점에만 `daily_close_done_<날짜>.txt`가 찍힌다. 오늘처럼 `daily_close()` 자체가 시작도 못 하는 경우를 대비해, 창이 닫히는 순간(`qt:lastWindowClosed`) 자체에도 "의도된 종료인지"를 가볍게 남기는 보조 플래그를 추가하면(예: 사용자가 직접 닫았는지 vs 크래시인지 구분) F-Z 판정의 정밀도가 올라갈 수 있다. **당일 관측 근거**: 오늘 3개 플래그 전부 미측정이라 CRITICAL과 "사람이 의도적으로 닫음"을 구분할 방법이 로그상 전혀 없었다.
