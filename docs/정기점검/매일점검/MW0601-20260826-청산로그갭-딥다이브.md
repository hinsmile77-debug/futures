## 1. 원인 — `[청산 완료]`는 「포지션」이 아니라 「마지막 **주문**」의 집계다

`main.py:_post_exit()` 이 찍는 값은 `result["pnl_krw"]` 이고, 그 `result` 는
`_ts_build_agg_exit_result(last_result, pending)` 가 만든다. 그 함수의 집계 범위는
**`pending` = 주문 하나**다(독스트링도 *"분할체결 집계값을 단일 체결 result로 합산"*).

즉 **한 주문의 분할체결**은 합쳐지지만 **다른 주문**은 합쳐지지 않는다.

### 그래서 같은 로그 줄이 날마다 다른 것을 뜻한다

| 사례 | 청산 구성 | `[청산 완료]` 값 | 실제 의미 |
|---|---|---:|---|
| 2026-08-25 포지션① | 하드스톱 **1주문** 2계약(2체결) | −24,108 | **포지션 총합** ✅ |
| 2026-08-25 포지션② | TP1 1주문 → 스톱 1주문 | +11,936 | 마지막 주문만 ❌ (총합 +56,872) |
| **2026-08-26** | TP1 1주문 → 스톱 1주문 | **−11,928** | 마지막 주문만 ❌ (총합 **+21,144**) |

⇒ **한 주문으로 닫힌 포지션에서는 우연히 맞고, TP1을 거친 포지션에서는 틀린다.**
계측 4원칙 ①(단위 명시)의 전형 — 같은 이름이 두 분모를 가진다(461차 `mdd_pct` 유형).

> 📌 어제 F-X가 고친 수집기 결손(`요약 1건 +56,872원`)의 **56,872가 바로 이 값**이다.
> 같은 뿌리인데 그때는 **수집기 쪽만** 고쳤고 **엔진의 로그 자체**는 그대로였다.

## 2. 🔴 더 심각한 것 — 승패 **분류**도 레그 단위다 (신규 발견)

`_post_exit()` 첫 줄:

```python
pnl = result["pnl_pts"]      # ← 마지막 **주문**의 pt
was_correct = pnl > 0
if was_correct:  circuit_breaker.record_win();        kelly.record(win=True,  ...)
else:            circuit_breaker.record_stop_loss(…); kelly.record(win=False, ...)
                 ensemble.record_trade_outcome(was_correct=False, …)
```

**오늘 이 포지션은 이겼는데(+21,144원) 세 시스템이 전부 패배로 학습했다.**

게다가 승패 기록 지점이 **3곳**(`main.py:10362 / 10447 / 10780`)이고 전부 레그 단위라,
오늘 한 포지션이 이렇게 기록됐다:

| 레그 | pt | 기록 |
|---|---:|---|
| TP1 부분청산 | +0.87 | `record_win()` + `kelly.record(win=True)` |
| 최종 스톱 | −0.03 | `record_stop_loss()` + `kelly.record(win=False)` + 앙상블 오답 |

⇒ **1포지션이 Kelly에 「1승 1패」로 들어간다.** 실제로는 **1승**이다.

### 왜 이게 지금까지 안 잡혔나

- **`daily_stats` 는 이미 고쳐져 있다** — 459차 F1이 승패를 레그→포지션 단위로 바꿨다.
  그래서 **일일 마감 통계는 맞고**, 그 옆에서 Kelly·CB·앙상블만 레그 단위로 남았다.
  통계가 맞으니 아무도 학습 계층을 의심하지 않았다.
- **489차 A-1은 CB②만 부분 완화했다** — 같은 `entry_ts` 의 계단식 손절을 1회로 접었다.
  그러나 **분류 자체**(이 포지션이 손절인가)는 손대지 않았다. 오늘 포지션은
  **이익 포지션인데 손절 1회로 카운트**된다.
- **F-AA(어제 배선)가 도구를 이미 만들어 뒀다** — `classify_exit_stage()` 가
  `INITIAL_STOP`(진짜 손절)과 `TRAIL_AFTER_TP1`(TP1 후 이익 확정 트레일)을 가른다.
  2026-08-24 실측 오염률 **66.7%**. 오늘 청산이 정확히 `TRAIL_AFTER_TP1` 이다.
  **분류할 수단은 생겼는데 소비처가 아직 안 쓴다.**
