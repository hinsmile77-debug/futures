- **기준 위반**: 절대원칙 직접 위반은 아니나, 안전장치(ERR-FATAL 핸들러)가 코드

  **잘못 작성된 로그 호출 하나 때문에 발동**했다.
- **영향**: 14:25~14:41 15분간 자동 진입이 전면 정지됐다. 이 구간에 실제 진입
  후보가 있었는지는 `ensemble_decisions`로 확인 가능하나(아래 참고), 이 창에서

##### 1-7. 같은 버그 패턴이 또 있음 — 미발동, 재발 가능 (ColdStart 분기)
