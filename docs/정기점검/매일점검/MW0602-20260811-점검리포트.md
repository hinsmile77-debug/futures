## 5. 개선 제안

### P1 🔴 `allow_new_entry` 선언·동작 불일치 해소 — 버그 수정 (통계 불요)

`_ZONE_PARAMS[*]["allow_new_entry"]`가 실제 진입 경로에서 읽히는지 코드 추적 후 택일:
- **(a) 집행한다** — 플래그를 진입 게이트에 배선. 단 11:50~13:00이 실제로 봉쇄되면
  하루 70분(18.2%)이 확정 사망하므로 P2와 함께 판단할 것.
- **(b) 선언을 동작에 맞춘다** — 플래그를 제거하고 `min_confidence`만 정책으로 남긴다.

어느 쪽이든 **지금처럼 "금지라고 쓰고 가끔 뚫리는" 상태는 유지 불가**다.
※ 절대원칙 §1은 345차 컷오프가 별도 집행 중이라 이 수정과 무관하게 안전하다.

### P2 🔴 자기유발 CB⑤ 차단 — S0 모델교체를 지연 판정에서 제외

`[Model] 재학습 완료 모델 교체 적용 (S0)`이 1.5~2.8초를 먹어 CB⑤ → Degraded 선제차단으로
이어지고, 오늘 **유효 진입후보 2건(13:58·14:58)을 소멸**시켰다.

권고: 모델 교체 소요시간을 `PipePerf` 지연 판정에서 **차감**하거나(가장 안전),
Degraded streak 계산에서 `trigger=MODEL_SWAP` 사이클을 제외한다.
CB⑤ 본래 목적(API·시장 지연 감지)은 그대로 보존된다.

### P3 🟠 mc-conf 괴리 — DynMC 후행성에 대칭 가드

현재 DynMC는 conf 분포 p65를 추종하는데, conf **스케일 자체가 이동**하면 항상 늦는다
(08-03 과소 → 08-11 과대). 이미 `[경보] mc-conf 괴리`가 사후 탐지는 하고 있으나
`mc는 자동 조정하지 않음`이다.

권고(**섀도 우선**): mc가 당일 conf 분포의 **p95를 초과**하면 "산술적 도달 불가"로 판정해
경보를 **당일 09:30 시점**에 올린다(현재는 15:40 EOD). 자동 조정은 하지 않는다 —
403차 지배 논증과 461차 P-B(편측 히스테리시스) 규율을 따른다.

### P4 🟠 사전등록 채널 3종 (`VALIDATION_CAMPAIGN`)

313차 규율상 §4-2의 기각된 축과 §4-1⑤는 **지금 배포하지 말고 채널로 등록**할 것.

| 제안 채널 | 가설 | `min_samples` |
|---|---|---|
| `raw_grade_cohort_watch` | raw_grade=C 코호트 EV < 0, X→A > 0 | 각 밴드 30 |
| `profit_geometry_lowvol_watch` | 실현이익/ATR 배수가 저변동성 국면(ATR<2.5pt)에서 붕괴 | 40 |
| `effective_weight_watch` | 앙상블 유효가중합 < 0.3 진입의 EV | 30 |

세 번째는 오늘 진입(유효가중 0.243, 방향 3m 단독)에서 나온 관찰이다. `weight_collapsed`
안전망은 가중합 0만 잡고 **0.24 같은 준붕괴는 통과**시킨다 — 459차 F2·461차 P-A와 같은
"판단 불가 ≠ 확신" 계열이다.

### P5 🟡 3m 모델 상수출력 반복

오늘 `ConstOut` 5회 중 3m이 3회. 3m은 EOD 교체도 보류(acc 0.4756→0.4138)됐고,
`cvd_monotone_ratio` 미가용으로 피처 1개가 빠진 상태다(105→12). 3m은 8/3 메모 기준
진입 비중이 가장 큰 호라이즌이므로 **다음 세션 우선 조사 대상**으로 등록.
