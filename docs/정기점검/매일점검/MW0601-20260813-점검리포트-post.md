## 3. 고도화 방안

### G-4. 퍼널 자기검증 — "퍼널 합계 ≠ 실측"이면 EOD가 스스로 경고한다

- **관측 근거**: 오늘 퍼널이 `JointGateBlock=6`을 찍었는데 로그·DB는 7건이었고, 전기간으로는
  진입 190건 중 25건(13.2%)이 누락돼 있었다. **이 불일치가 6주 넘게 아무 경보 없이 지나갔다.**
  1-1의 본질은 버그 하나가 아니라 **검산이 없다는 것**이다.
- **제안 내용**: `strategy/ops/daily_exporter.py` 퍼널 섹션 말미에 항등식 검산을 넣는다.
  - `flat + conf_fail + coherence + gate_blocked + candidate == total`
  - `entered == SELECT SUM(entry_executed) FROM ensemble_decisions WHERE 당일`
  - `퍼널 JointGateBlock 건수 == logs/*_TRADE.log 의 [JointGateBlock 차단] 건수`
  하나라도 어긋나면 `⚠ 퍼널 정합성 실패: {항목} 기대={a} 실측={b}` 한 줄을 리포트와
  `WARN` 로그에 남긴다.
- **기대 효과**: 측정 가능 — 다음 거래일부터 리포트에 정합성 줄이 반드시 1개 출력되고,
  값이 어긋나면 그날 즉시 잡힌다. 오늘 같은 6주 잠복이 불가능해진다.
- **비용·위험**: 낮음. 쿼리 2개 추가(EOD 시각이라 장중 DB 금지 규약 무관). 오탐 시
  리포트 노이즈가 늘 수 있으나 항등식이라 오탐 가능성 자체가 낮다.
- **선행 조건**: **F-5 선행 필수** — 지금 넣으면 매일 실패를 찍는다.
- **우선순위 제안**: 이번 주.

### G-5. "미측정" 1급 표현 — 스냅샷 스키마에 `*_measured` 도입

- **관측 근거**: 오늘 하루에만 미측정이 정상값으로 위장한 사례가 **2건**이다 —

  한 줄 안에 기간이 섞인 것. 계측 4원칙 ②·④가 **런타임 상태(`getattr` 폴백)** 를 겨냥해
  만들어졌는데, **DB 스키마 계층에는 아직 적용된 적이 없다.**

  `ALTER TABLE`로 추가(`ensemble_decisions` 6컬럼 추가 전례와 동일 패턴). 판정·표시 코드가

  **"DB 컬럼에 폴백값을 쓸 때 같은 행에 플래그가 있는가"** 로 확장한다(계측 4원칙 ④ 3번째 규약이

- **비용·위험**: 중간. 기존 96행은 `metrics_measured=NULL`(=미상)로 남으므로
  소급 판정에는 쓸 수 없다 — 그 한계를 주석에 명기할 것.

- **우선순위 제안**: 이번 주.
