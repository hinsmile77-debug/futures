## 3. 고도화 방안

### G-1. 하트비트를 `session_state`가 아니라 **별도 파일**로 분리 — 즉시

- **관측 근거**: 오늘 `data/session_state.json`의 mtime은 **16:08**(EOD 재학습이 쓴 것)이다.
  라이브 프로세스는 13:41에 멈췄는데 이 파일만 보면 정상으로 보인다.
  즉 **기존 상태파일은 생존 판정에 쓸 수 없다** — 여러 프로세스가 같은 파일을 쓴다.
- **제안**: `data/heartbeat_{PC}_{date}.txt` — 쓰는 주체를 라이브 프로세스로 **단일화**.
- **기대 효과**: 동결 감시의 오탐률을 로그 mtime 단독 판정 대비 낮춘다(로그는 조용한 구간에도 안 써질 수 있다).
- **비용·위험**: 낮음. 파일 1개 추가.
