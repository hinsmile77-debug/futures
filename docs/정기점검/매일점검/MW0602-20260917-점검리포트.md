#### 4-2. 313차 다섯 갈래 적용

| 갈래 | 적용 결과 |
|---|---|
| ① 일자단위 판정 | 관측 거래일 **1일뿐** — 오늘의 A/E 집계는 독립 관측치가 아니라 **단일 레짐 윈도우(10:05~11:10, 65분)의 연속 관측**이다. 결론이 아니라 가설 등록 수준으로만 취급 |

| ③ 이상치 분해(drop-worst) | CASE-05(-142,004원) 제외 시 당일 순손익 -50,076원 → **+91,928원**으로 부호 반전. 단 한 건이 오늘 전체 결과를 좌우함 — 평균만으로 "손절 미준수가 원인"이라 말할 수 없음 |

| ⑤ 부호 일관성 | 판단 불가(관측 1일뿐, 비교할 다른 기간·PC 데이터 없음) |
