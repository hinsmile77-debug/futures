## 2. 이상점 5건

### F-1 🔴 「상방 없음」의 사유가 어디에도 없다 — 계측 4원칙 ③ 위반

**증상**: 로그 `구조 상방 없음`, DB `struct_up=[]`, UI `▲ ——`. 셋 다
**「구조 후보 수집이 실패했다」와 구분되지 않는다.**

**실제**: 후보는 **10개 있었고 전원이 기준가 아래**였다.

```
구조 후보 전체 10개 (기준가 1088.26)
  1077  -11.26  매물대1077.0(379분/2세션)          ← 최고 후보
  1074  -14.26  매물대1073.5(306분/2세션)
  1068  -20.26  매물대1068.5(268분/3세션)
  1064  -24.26  매물대1063.5(153분/3세션) + 전일고1063.78
  1056  -32.26  매물대1055.5(114분/2세션) + 갭상변09-01저1056.94
  1053  -35.26  갭하변09-02고1052.62
  1051  -37.26  전일VWAP1051.5
  1048  -40.26  매물대1048.0(542분/4세션) + 4세션VWAP1049.5
  1042  -46.26  매물대1041.5(368분/3세션) + 전일저1042.42
  1037  -51.26  매물대1037.0(240분/3세션)
```

즉 **갭업으로 시가가 이력 6세션 후보 분포 위로 빠져나간 것**이며, 설계상 정상이다.
그런데 그 사실이 남지 않아 다음 점검이 헛 조사를 하게 된다.
457차 C6(*"7개 미가용이라 적어놓고 5개만 출력"*)과 **같은 유형**이다.

### F-2 🔴 당일 봉을 어디서 읽었는지 기록되지 않는다 — 계측 4원칙 ④ 위반

`ensure_stage`는 메모리 버퍼가 비면 **조용히** `raw_candles` PK 범위 조회로 폴백한다.
`bars` 개수만으로는 두 경로가 구분되지 않는다.

⚠ 이것이 위험한 이유는 어제 실제로 겪었다 — `candle["ts"]`가 datetime인 것을
문자열로 슬라이스해 `except: pass`가 삼키면 **버퍼가 항상 비고**, 화면·DB는 정상으로
보이면서 매일 DB 폴백으로만 돌게 된다. 그러면 *"장중에 DB를 읽지 않는다"* 는 이
모듈의 설계 전제가 **아무도 모르게** 무너진다.

### F-3 ⚠ 기준가가 후보 분포 밖인 날에 경고가 없다 — 설계 공백

가이드는 이 경우를 다루지 않는다(마흐디 §12 예시 09-04는 갭이 작았다).
갭업/갭다운이 크면 한쪽이 구조적으로 빈다 — **그것이 정상이라는 사실**을 남겨야 한다.

### F-4 ⚠ R̂ 산출 근거가 남지 않는다

오늘 `rhat_scale = 0.85`(하한). 갭이 0.83 ATR인 날에 **구간을 좁히는** 방향이라
직관과 반대인데, 회귀 입력이 저장되지 않아 회귀 탓인지 `med_r` 탓인지 가릴 수 없었다.

계측을 붙여 재산출한 결과가 이것이다:

```
rhat raw = 0.3898  →  clip → 0.8500  (floor_hit=True, n=60)
x[4] gap = +0.8334,  x[5] |gap| = +0.8334
```

**R̂ 회귀는 오늘 범위를 훈련 중앙값의 39%로 예측했다.** 하한 0.85가 없었다면 구간이
**61% 좁아졌을 것**이다 — 갭 3.25%인 날에. 즉 오늘은 **하한이 방어했다.**

> ⚠ **하루 표본으로 파라미터를 바꾸지 않는다(313차).** 이 관측은 가이드 §5 채택의
> 60일 누적 재판정 원료로만 쓴다. 지금 하한을 올리는 근거가 아니다.

### F-5 ⚠ 거리 모델 기준점 O 가 미측정 지연에 걸려 있다

거리 모델은 **08:45 봉의 `open` 하나에** 고·저 예측 전부를 건다.
오늘 실시간 구독은 `08:45:07` — **개장 후 7초**에 붙었다.

```
2026-09-07 08:45:07 [INFO] SYSTEM: [EarlyWarmup] Cybos RT 08:45 선행 구독 시작
```

그 7초 사이 체결을 놓쳐 O가 몇 pt 밀렸는지 **측정 수단이 없었다**.
533차가 같은 결함을 기록해 뒀고(`08:45 봉 O·V 오염`), **09-08 프로브가 답할 문제**다.
맥점 쪽에서는 최소한 **지연 초를 산출물에 남겨** 사후 재구성이 가능하게 해야 한다.
