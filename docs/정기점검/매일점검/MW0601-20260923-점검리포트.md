#### 1-1. `.git/index.lock` 스테일 잔존 — 저장소 커밋 불가 상태

- **증상**: 리포 루트에 0바이트 `.git/index.lock`이 남아 있어 이 저장소가 커밋을 받지 못하는 상태다.
- **근거**:
  ```
  $ python scripts/git_lock_guard.py --check
  futures                  STALE 스테일 확정 — 0바이트 · 0.3시간 · git 프로세스 0개 -> 이 저장소는 커밋 불가 상태다
  exit=2
  ```
  수집기 §2 락 자가점검: "이 수집 실행은 락을 만들지 않았다" — 이 세션이 만든 락이 아니라 이전 세션(어제 장후 12:35경 생성분으로 추정, `dev_memory/DECISION_LOG.md` 09-22 세션 헤더 참조)에서 넘어온 것.
- **기준 위반**: `references/invariants.md` §0 git 호출 규약 / 계측 4원칙 ③(탈락 가시화) — `git status`는 rc=0으로 이 상태를 조용히 통과시킨다.
- **영향**: 코드 변경 사항을 커밋할 수 없다. 단, STALE(스테일 확정)이지 HOLD(판정보류)가 아니므로 위험한 락은 아니다 — 회수만 하면 된다. 리눅스 샌드박스 세션은 마운트 경유 `unlink`가 거부돼 세션 안에서 회수 불가능하다.
- **영향(기술)**: `python scripts/git_lock_guard.py --reclaim`을 **Windows PC에서** 실행해야 회수된다. `--check`가 STALE(종료코드 2)을 확정했으므로 회수해도 안전하다(HOLD였다면 회수 금지).
- **신규 여부**: 기존 — 어제(09-22) 장후 리포트가 동일 락을 "STALE 지속" 상태로 사용자 조치 1번에 이미 올렸다(`dev_memory/DECISION_LOG.md` 2026-09-22 항목). 오늘도 회수되지 않은 채 이어지고 있다 → **지속(1-1 계승, 원 번호 없음 — 오늘 파일 신규 시작이라 1-1로 부여)**.

### F-4(병합 F-3). 재기동 원인 규명 — 예외 트레이스백 강제 기록

- **파일**: `main.py:20639`(`system.run()` 호출부 최상위), `main.py:20596`(`_fault_atexit()`)
- **변경 내용**: `system.run()` 호출을 `try/except Exception`으로 감싸 예외 발생 시 `crash_fault.log`에 전체 트레이스백을 강제 기록한다(현재는 예외가 나도 atexit 핸들러만 `[CLEAN EXIT]`를 남기고 원인 텍스트가 전혀 안 남는다). `[CLEAN EXIT]`를 `[CLEAN EXIT reason=<normal|exception|signal>]` 형태로 확장하는 안(기존 F-3·G-3 제안)과 결합.
- **회귀 위험**: 예외를 잡아서 로그만 남기고 그대로 재전파(re-raise)하도록 설계해야 한다 — 삼켜버리면 원래의 `[CLEAN EXIT]` 동작(atexit)이 스킵될 수 있다.
- **검증**: 재배포 후 다음 재기동(원인 불문) 발생 시 `crash_fault.log`에 트레이스백이 실제로 찍히는지 확인. 코드가 없는지 `grep -n "system.run()" main.py`로 먼저 확인 완료(함정① 점검 — 현재 감싸는 예외 핸들러 없음을 확인).
- **우선순위**: P0 — 오늘 사건의 근본 원인 규명 없이는 F-6도 임시방편에 그친다.

- **왜**: 감시 장치는 일부러 뒷정리를 건너뛰고 끄는 방식(`os._exit`)이라 "정상 종료" 표식이 원래 안 남는다. 점검 도구는 그 표식만 봤기 때문에 **의도된 종료를 원인 불명 크래시로 보고**했다. 오늘 장후 절의 가장 높은 등급(P0) 판단 근거 일부가 여기서 나왔다.

- **매매 영향 0**: 점검 도구 전용 파일만 바꿨다. 매매 프로그램은 이 파일을 쓰지 않는다(기존 테스트가 그것을 검사한다).
- **일부러 안 한 것**: 감시 장치 블록이 없는 무기록 종료(13:51)는 **여전히 「하드킬/무흔적」**으로 남긴다. 새 분류가 진짜 미상 종료를 삼키지 않도록 테스트로 고정했다.
