- **A-2** (재학습 성공 표시를 쓴 시점에 확인 로그) — 이미 있다. 재학습 프로그램이 `[P8] session_state … 기록 완료`를 남기고 있고, 오늘 장후 리포트도 바로 그 로그로 해소를 확인했다.

### 보류한 것 (사용자 결정이 필요하거나 손대면 안 되는 범위)

- **F-5** (증권사 연결부 메시지 처리 구간에 진단 로그) — 증권사 연결 코드는 주문이 오가는 길이라 자동 작업이 손대지 않는 범위다. 계획만 할 일 목록에 넘겼다.
- **F-7** (참고 분석 패널 스크립트가 장중에 무거운 조회를 하지 않게) — 리포트가 세 가지 방법 중 **사용자가 고르라고** 했다. 할 일 목록에 넘겼다.

### 사용자가 직접 할 일

1. **F-7 방법 고르기** — 장외로 옮김 / 무거운 스크립트만 장 마감 후로 / 점심시간에만 가볍게, 셋 중 하나. 걸리는 시간 1분. 안 하면: 장중 실패가 매일 열 번 안팎 반복된다(거래 영향은 없음).
2. **F-5 허용 여부** — 증권사 연결부에 진단 로그만 다는 것을 허락할지. 걸리는 시간 1분. 안 하면: 다음 장중 크래시도 "어디서"까지만 알고 "왜"는 모른다.
3. **잠금 파일 부스러기 2개 삭제** (`.git` 폴더 안 `index.lock.stale_…` 2개) — 장전 3번 그대로. 걸리는 시간 1분. 안 하면: 부스러기만 쌓인다(기능 장애 없음).
4. **점검 스킬 사본 갱신** — 장후 9번 그대로. 자동 작업은 앱 쪽 사본을 바꾸지 않는다.
