## 1. 무엇을 하나

723차 「외인 선물 마감 누계 미반영」 경고는 **문제가 있을 때만** 뜬다.
경고가 안 뜬 날은 「정상」인지 「검사를 안 한 것」인지 로그로 구분할 수 없어서 `V-1028-3`/`O-10`을 DB 쿼리로 판정해야 했다.

이제 **15:35 이후 snapshot을 돌릴 때마다** 결과와 무관하게 한 줄을 남긴다.

```
[ForeignCutCheck] 15:55:03 t_cut=마감 db_last=15:34 반영=OK
```

| 값 | 뜻 |
|---|---|
| `t_cut` | 외인 선물 경로를 어디까지 읽었나. `마감` = 자르지 않고 마감 누계까지 읽음(정규봉 적재 후의 정상 상태) |
| `db_last` | 그날 `raw_investor_futures`의 최신 적재 시각. `-` = 적재 0행 |
| `반영` | `OK` / `누락`(db_last > t_cut — 723차 경고와 같은 조건) / `미측정`(적재 0행 — OK로 위장하지 않는다, 계측 4원칙 ②) |

장중(15:35 전)에는 줄을 만들지 않는다. 장중에 완결 봉까지만 읽는 것은 의도된 동작이다.
