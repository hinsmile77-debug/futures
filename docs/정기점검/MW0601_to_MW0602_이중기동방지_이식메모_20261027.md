### 뮤텍스의 성질

| 성질 | 이유 |
|---|---|
| 이름이 작업 폴더별이다 | 다른 리포의 main.py 와 충돌하지 않는다 |
| `Local\` 네임스페이스다 | 비승격 프로세스는 `Global\` 생성 권한이 없을 수 있다. 런처·수동 기동은 모두 같은 대화형 세션이다 |
| `ERROR_ACCESS_DENIED`(5)도 「이미 있음」이다 | 승격 예약작업이 만든 뮤텍스를 비승격 수동 실행이 열면 이 오류가 난다 |
| 크래시 뒤 낡은 잠금이 없다 | 프로세스가 죽으면 OS 가 핸들을 닫는다. 락 파일과 다르다 |
| 판정 불가면 막지 않는다 | 기동을 막으면 그날 거래가 0 이 된다. 대신 WARN 으로 남긴다(계측 4원칙 ②) |

앱 안에는 「새 main.py 를 띄우고 자신은 종료」하는 재시작 경로가 없다. 재시작은 전부 런처 루프를 거치고, 프로세스 종료 뒤 10초를 기다린다.
