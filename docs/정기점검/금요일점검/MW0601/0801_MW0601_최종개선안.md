# 6. 이 개선안이 답하지 못하는 것

- **왜 3계약 이상에서만 지는가** — 사이저의 어느 입력(켈리·등급·conf·ATR)이 역예측적인지
  미분해. 고변동일 교란 가능성이 남아 있고 `entry_gate_json` 사이징 입력 재구성이 필요하다.
  **P1-2는 현상을 감시할 뿐 원인을 고치지 않는다** — `MAX_CONTRACTS` 인하가 원인 치료인지
  증상 억제인지는 여전히 모른다.
- **§2-3의 qty=1 부호 일치가 우연이 아닌지** — MW0601 n=34, MW0602 n≈42로 둘 다 얇다.
  313차 기준 "부호 일치 확인"까지이지 효과 크기 확정이 아니다.
- **방향예측이 랜덤과 무차별인 이유가 피처인지 레이블인지** — 고정 임계 레이블
  (`USE_FIXED_LABEL_THRESHOLD=True`)에서 실제 분포가 치우친 것과 분리하지 못했다.
- **07-14 이후 60건 +59.7만원** — 표본이 얇아 흑자 전환을 확정으로 읽으면 안 된다.
