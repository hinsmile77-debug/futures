## 1. 사용자 5항목에 대한 의견과 보완

### 항목 1. 진입품질 고도화 방안 — ⚠ 부분 동의, 방향 수정 제안

**"임계 조이기"로 읽으면 증거가 반대다.**
- 가격 기반 4지표 전부 t<2, conf는 승·패 동률(34.7 vs 34.8%), GradeEVGuard는
  "대상 오조준"으로 이미 부결(0801). 지금 아는 어떤 축으로 조여도 FAST를 못 거르고
  TP1 도달 43건(+490만원)만 같이 깎는다.
- 표본 기아 리스크: 검증 캠페인 전 채널이 min_samples 대기 중이다. CB②를 9999로
  풀어둔 이유(표본 확보 우선)와 정면 충돌한다.

**대신 "진입 집행 품질"로 재정의할 것을 제안한다.**

유일하게 유의한 발견이 그 축을 가리킨다 — 신호봉 종가 대비 실제 체결가가 **방향기준
평균 +0.173pt 불리**(61.3%, t=+2.45). 규모는 작지 않다:

```
1계약당 0.173pt × 50,000원 = 8,650원
기간 84계약 전량 회수 가정  ≈ 726,600원
같은 기간 실제 순손익        =  +53,548원   ← 체결비용이 손익의 13배
```

오늘 실측 스프레드는 p50 **7틱(0.14pt)** / p90 12틱이다. 시장가는 이 스프레드를
전액 지불한다(매수=ask1, 매도=bid1).

처방이 **이미 구현돼 있다** — `LIMIT_ENTRY_FIRST_ENABLED`(260704 감사 P1,
`settings.py:1157`). 매수는 `bid1+1틱`, 매도는 `ask1−1틱` 지정가로 먼저 시도한다
(`main.py:8937`).

> ⚠ **타임아웃 동작 정정**: 12초 미체결 시 **취소만 하고 시장가로 전환하지 않는다**
> (`main.py:8994` — *"시장가 전환 없음, 2026-07-05 사용자 지시: 가정이 깨져도
> 안전하도록 포지션을 억지로 열지 않는다"*). 부분체결분은 유지하고 잔량만 취소한다.
> 이 문서 초안이 "시장가 폴백"으로 잘못 적었던 것을 정정한다.

감사 §5 활성화 순서 **1순위**인데 "Cybos CpTd6831(지정가)/CpTd6833(취소) TR이 이번에
처음 구현돼 실브로커 미검증"을 이유로 **OFF인 채 4주째**다(NEXT_TODO ① 등록·미실행).

#### ⚠ 그러나 "켜면 이득"이 아니다 — 지정가 고유의 함정 2개

**① 체결률 하락 → 표본 기아 악화.** 12초 미체결이면 진입을 포기하므로 거래 수가
줄어든다. 지금은 전 채널이 표본 부족으로 판정 불가 상태다([25] n=14·1일,
[23] OOS 1일). CB②를 9999로 풀어둔 이유(표본 확보 우선)와 **정면 충돌한다.**

**② 지정가 자체의 역선택.** 매수 지정가를 걸면 — 가격이 **올라가면**(예측이 맞는
방향) 미체결이고, **내려오면**(예측과 반대) 체결된다. 즉 *맞을 때는 못 타고 틀릴 때만
태워질* 수 있다. 학술적으로 알려진 문제이며, 급행 풀스톱(진입 직후 즉시 역행)과
방향이 맞물릴 위험이 있다.
> 뒤집으면 장점일 수도 있다 — "가격이 이미 달아난 진입"이 자동으로 걸러지므로.
> 그러나 이는 **가설이며 검증된 바 없다.**

#### → 따라서 항목 1의 실질 내용은 "켜서 4가지를 재본다"이다

"켜면 이득"이 아니라 **계측을 붙여 켠다**. 사전등록할 4개 지표:

```
(a) 체결률            — 12초 내 체결 비율 (전량/부분/미체결)
(b) 미체결 counterfactual — 그때 시장가로 갔다면의 hyp_pnl (기존 채널 패턴 재사용)
(c) 체결 vs 미체결의 이후 FAST 비율 — 함정 ②가 독인지 약인지 판별하는 핵심 지표
(d) 순개선 = 절약한 스프레드 − 놓친 기회
```

**중단 기준도 관측 전에 고정한다**: (a)가 60% 미만이거나 (d)가 2주 연속 음수면
즉시 OFF 복귀. 표본 기아 상황이므로 "애매하면 유지"가 아니라 **"애매하면 끈다"**.

→ **신규 차단 게이트는 항목 2의 결과 전까지 금지.** 지정가는 항목 2와 독립적으로
진행 가능하나, 위 4지표 계측 배선이 선행 조건이다.

### 항목 2. 결정적 인자 발굴 그물 — ✅ 전적 동의, 설계를 2단으로 분리해야 한다

핵심 보완: **발굴(discovery)과 확증(confirmation)을 물리적으로 분리**한다.
오늘 세션에서 같은 유형의 과잉해석이 3번 나왔다(모집단·거래일·호라이즌 확인 전
결론 — DECISION_LOG 421차 후속5 교훈). 한 표본에서 그물을 치고 그 표본으로 판정까지
내리면 그 실수가 제도화된다.

**그물의 폭** (전부 이미 저장돼 있는 데이터 — 라이브 코드 무접촉):

| 축 | 소스 | 예 |
|---|---|---|
| 미시구조 피처 97종 | `raw_features` (진입 분 + 직전 분 델타) | toxicity 성분 5종, queue_*, ofi, cvd, mlofi, spread |
| 게이트 상태 | `ensemble_decisions.entry_gate_json` | 어떤 게이트가 임계 근처였나 |
| 체크리스트 항목 | TRADE.log 파싱 ([16] 선례 재사용) | cvd/ofi/chas 조합 |
| 컨텍스트 | trades + regime_history | 시간대, 호라이즌, hurst, 방향×직전흐름, 일중 레인지 분위 |
| 신호 신선도 | 신호봉 종가↔체결가 | 이미 +0.173pt 유의 확인 |

**통계 규율 (사전등록)**:
- 포지션 단위, **일자 블록 군집 검정** 필수 — FAST의 75%가 3일에 몰려 있어 일자
  무시 시 유사반복으로 p가 거짓으로 작아진다.
- 다중비교: BH FDR 10% (발굴 단계는 그물이므로 관대하게).
- 발굴 통과 후보 중 **top-K ≤ 5개만** 방향·효과크기와 함께 사전등록 → 확증 단계로.
- 확증은 **등록일 이후 신규 데이터만**으로, 후보당 단측 α=0.05, 일자 군집 유지.

### 항목 3. 일정기간 데이터 수집 / findings — ✅ 동의, 기간을 현실화

- 누적 속도 실측: 포지션 ~9건/주, FAST ~2건/주 (단 최근 2주 가속).
- 검정력: 기저 FAST율 25%에서 "플래그 구간 FAST율 2배" 수준의 판별자를 잡으려면
  확증창에 포지션 **80~100건 ≈ 4주+** 필요. 그보다 약한 판별자는 더 걸린다.
- **종료기한을 두지 않는다** — 캠페인 standing 규약(CLAUDE.md) 그대로, 채널이
  min_samples 도달 시점에 개별 판정. 별도 캘린더 신설 금지 — **금요일 EOD 리포트에
  [32] 채널로 편입**해 매주 자동 렌더.
- findings는 리포트 상세절에 후보별 (발굴 효과크기 vs 확증 누적 효과크기, 일자 수,
  PC 병기) 표로 고정 — 사람이 매주 다시 계산하지 않는다.

### 항목 4. verdict — ✅ 동의, 기준을 지금(관측 전) 고정

후보 판별자 D별 (사전등록 초안 — 승인 시 settings에 등재):

```
CONFIRM: 확증창에서 (a) 발굴과 같은 부호 + (b) 일자군집 단측 p<0.05
         + (c) 확증창 FAST ≥ 10건·거래일 ≥ 8일 + (d) 플래그 구간 FAST율 ≥ 기저 2배
REJECT : 부호 반전, 또는 표본 충족 후 효과 하한 미달
CONTINUE: 그 외 (표본 부족)
```

**채널 전체의 부정적 verdict도 사전등록한다** — top-K 전원이 REJECT로 끝나면
"진입 시점 판별 불가 **확정**"이 공식 결론이 되고, 자원을 청산기하·집행 축으로
재배치하는 결정이 구속력을 갖는다. (부정적 결과가 기록되지 않으면 다음 세션이
같은 그물을 다시 친다 — CLAUDE.md "판정≠결정" 사고의 거울상.)

두 PC: 421차 후속2 판독 규칙 (1)~(4)를 그대로 준용한다. 단 MW0602는 dev(V8)라
피처 집합이 다를 수 있으므로 "요구"가 아니라 "병기"로 한다.

## 4. 리스크와 한계 (정직 고지)

1. **판별자가 존재하지 않을 수 있다.** 4개 가격 지표·InstabilityGate·동일 체크리스트
   쌍의 증거는 "분 단위 정보로는 못 가른다" 쪽을 가리킨다. 그물의 가치는 그 경우에도
   "포기를 확정"해 자원 재배치를 구속력 있게 만드는 데 있다.
2. **FAST 라벨은 결과 기반이다** — ≤150초는 [15]의 기존 정의를 재사용하지만 150초
   경계 민감도는 발굴 단계에서 ±60초 스윕으로 함께 본다(경계 튜닝은 확증에 반입 금지).
3. **일자 군집이 강해 실효 표본이 명목 n보다 작다** — 검정력 추정(4주+)이 낙관일 수 있다.
4. **MW0602 병행 불가 가능성** — V8 피처 집합 차이. 단일 PC 표본 명시 규칙으로 대응.
5. 오늘(08-03)은 3.24% 극단 휩소일이다 — FAST 6건 포함 오늘 데이터가 발굴 표본의
   30%를 차지하므로, 일자 블록 통계가 아니면 오늘 하루에 과적합된 그물이 나온다.
6. **지정가 집행은 순이득이 보장되지 않는다** — 체결률 하락(표본 기아 악화)과
   지정가 역선택(맞을 때 미체결·틀릴 때 체결)이라는 반대 방향 힘이 있다. §1 항목 1의
   4지표·중단기준이 그 때문이며, **"검증"이지 "개선"이 아니다.** 초안이 이를
   "항목 1의 실질 내용"으로 단정했던 것을 완화했다(2026-08-03 사용자 지적).
7. 0.173pt 불리체결 중 **스프레드 성분과 지연 드리프트 성분이 분리돼 있지 않다.**
   지정가는 전자만 다룬다 — 후자(신호 생성 ~55초 지연)는 남는다. 따라서 726,600원
   전량 회수는 상한이며 실제 회수분은 그보다 작다.
