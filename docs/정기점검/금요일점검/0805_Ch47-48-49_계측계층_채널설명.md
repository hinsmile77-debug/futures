## 3. [47] `sim_fidelity_gate` — 계측기를 계측한다

### 3-1. 무엇을 재나

정본 재생기([23-B]의 `current` 변형)가 **같은 모집단의 실제 실현손익**을
재현하는지 **포지션 단위로 조인**해 잰다.

```
repro_bias_R = median( (sim_pt − actual_pt) / R )    R = 그 진입의 하드스톱 거리
sign_match   = sign(Σ sim) == sign(Σ actual)
```

- **중앙값을 쓴다** — 372차 원칙. 평균은 고변동일 소수 건에 끌려간다.
- **R로 정규화한다** — pt 그대로 더하면 ATR이 큰 날이 지표를 지배한다.

### 3-2. 왜 [23-B]가 정본인가

- 그 채널만 `rows_ts`(entry_ts 평행 리스트)를 내보내 **포지션 단위 조인**이 된다.
- 모집단이 "전 진입"이라 가장 넓고, 위 ①②③ 가정을 **전부** 포함한다.
- 다른 채널은 같은 세 가정을 공유하므로 정본이 실패하면 그들도 실패한다는
  **간접 추론**이며, 리포트가 그 사실을 함께 찍는다.

### 3-3. 판정 (사전등록, 관측 전 고정)

```
PASS         : |repro_bias_R| <= 0.10  AND  총합 부호 일치 → 하위 채널 정상 출력
SUSPEND      : 그 외 → 하위 채널 verdict를 SUSPENDED로 대체
INSUFFICIENT : n<40 또는 거래일<8 → **게이트를 열어 둔다**(근거 없이 막지 않는다, 313차)
```

정지 대상: `quantile_tp_shadow`[3-B] / `tp1_geometry_shadow`[23-B] /
`tp1_protect_offset_shadow`[25]+[25-B] / `hurst_threshold_shadow`[46]

### 3-4. 정지의 성질 — 삭제가 아니다

```python
ch["verdict_raw"]   = ch["verdict"]        # 원 판정 보존
ch["verdict"]       = "SUSPENDED"
ch["suspended_by"]  = "sim_fidelity_gate"
# per_variant·n·delta_vs_current 등 수치는 **전부 그대로**
```

리포트 표기: `⏸ SUSPENDED(계측 무효)` — **FAIL로도 PASS로도 읽으면 안 된다.**

### 3-5. 🔑 해제는 자동이다 — 이것이 이 채널의 존재 이유

재생기에 TP3·4단계 트레일링을 편입해 재현이 회복되면 **게이트가 PASS로 바뀌고
하위 채널이 스스로 깨어난다.** 사람이 기억할 필요가 없다.

> 절대원칙 §2의 **CB② · CB③-P4 · FP-CRITICAL**이 전부 *"재검토하기로 했는데 안 함"*
> 패턴이었다(CB②는 2026-07-05부터, FP-CRITICAL은 07-08부터 예외 상태). 이 게이트는
> 그 패턴에 대한 **구조적 해법**이다 — 조건이 충족되면 코드가 알아서 되돌린다.

### 3-6. ⚠ 사전등록 정직성 고지

이 채널의 첫 관측치는 신설 **전에** 이미 측정됐다(432차 후속2). 따라서 최초
SUSPEND는 사전등록된 검증이 아니라 **이미 본 결과의 코드화**다 — [25]의
`breakeven` 변형과 같은 취급. **사전등록 가치는 앞으로의 회복 판정에 있다.**

## 4. [48] `bar_stop_path_watch` — 봉중 하드스톱 경로

### 4-1. 무엇을 재나

`exit_fill_slippage`를 **청산 경로별로 갈라** 슬리피지의 **부호 대칭성**을 본다.
정상적인 집행이라면 유리/불리가 반반이어야 한다.

### 4-2. 메커니즘 — 두 겹이다

`main.py:12278` 부근:

```python
_effective_stop = stop_price if _close_stop_hit else _prev_stop_price
exit_price = min(_effective_stop, bar_high)       # SHORT
price_hint = exit_price ; hint_source = "stop_intrabar"   → 시장가 주문
```

**(a) 계측** — `price_hint`가 봉 고저가에서 유도한 **허구의 스톱가**다. 주문은
시장가로 나가므로 손익은 hint와 무관한데, **슬리피지 지표만 오염**된다.

**(b) 발동조건** — 유령 하드스톱은 *"그 봉의 극값이 스톱 조임보다 **먼저** 발생"*
할 때만 생기고, 스톱 조임은 **TP1 도달이 전제**다 → **이익 중인 포지션에서만
발동**한다. 그래서 유리 편향이 선택효과가 아니라 **결정론적**으로 나온다.

실례 (08-04 12:04):

```
12:03:52  진입 SHORT @ 976.50
12:04:26  TP1 부분청산 → 보호스톱 976.50(본전)으로 조임
12:04:52  봉 마감 점검: bar_high ≥ 976.50 → "스톱 히트" 판정
          ⚠ 그 고가는 12:04:26 이전에 발생 — 스톱이 그 자리에 있기 전이다
12:04:53  시장가 973.12 체결 → +3.38pt (= 유리 체결분과 소수점까지 일치)
```

보호스톱이 본전이라 정상 체결이면 **0.00pt**여야 한다. 기록된 이익은 전부
"유령이 발동한 순간 포지션이 얼마나 이익 중이었나"다.

### 4-3. 경로 분류 — `stop_close`는 BAR와 분리한다

| 경로 | hint_source | hint의 성질 |
|---|---|---|
| **봉중 하드스톱** | `stop_intrabar` | ❌ 허구 — 봉 고저가에서 유도, 체결 시점엔 없던 가격 |
| 종가 하드스톱 | `stop_close` | ✅ 유효 — 현재가가 실제로 스톱을 넘었다 |
| 틱 하드스톱 (**대조군**) | `stop_tick` | ✅ 유효 — 틱이 스톱을 넘었다 |
| 목표 | (none) 등 | TP1/TP2 목표가 |

> ⚠ `hint_source` 태깅은 **423차부터**다. 이전 행은 NULL이라 `reason`으로
> 재분류하는데, `하드스톱`(비틱)은 `stop_close`/`stop_intrabar` **둘 다일 수 있어
> 구분 불가**다. 보수적으로 BAR에 넣고 **재분류 건수를 노출**한다.

### 4-4. 판정 (사전등록, 관측 전 고정)

```
PASS         : 봉중 경로 유리비율이 [0.35, 0.65] 안 (틱 경로처럼 대칭)
FAIL         : 밴드 밖 **그리고** 부호검정 p < 0.01
               → 체결가 산정이 시장을 반영하지 않는다 = (a) 계측 결함 잔존
INSUFFICIENT : 봉중 n<25 또는 거래일<8
```

### 4-5. 🔴 `price_hint`를 지금 고치지 않는 이유 (재론 시 근거 필요)

*"봉중 hint가 허구니 전송 시점 현재가로 바꾸자"* 가 자연스러운 처방으로 보이지만
**435차는 하지 않기로 결정했다.** 세 가지 이유다:

1. **§9 위반이 된다** — 이 채널이 사전등록으로 재려는 바로 그 지표를, 관측 직후
   정의만 바꿔 PASS로 만드는 꼴이다.
   > [25] 클램프와 **다르다** — 그건 *체결 불가능한 가격*을 계상하던 **물리적 오류**
   > 였고, 이건 *유효한 정의 선택*의 문제다.
2. **손익이 안 바뀐다** — 주문은 `_send_broker_exit_order()`의 **시장가**이고
   (`main.py:9209`) hint는 브로커에 전달되지 않는다. 고쳐도 체결은 그대로다.
3. **순수 계측값이 아니다** — Chejan 콜백 유실 시 **평균가 폴백**으로도 쓰인다
   (`main.py:2823` `_flush_pending_exit_agg`). 드물지만 **라이브 복구 경로**라
   "계측 전용이니 안전하다"고 단정할 수 없다.

→ **진짜 처방은 424차 억제(발동 차단)이고 이미 배포됐다.** 이 채널은 그 억제가
실제로 듣는지를 **부호 대칭성 회복**으로 검증한다. 억제 후에도 편향이 남으면
그때 hint 정의를 손대고, 그 변경은 [25] 클램프처럼 **전/후 수치를 함께 기록**해야 한다.

### 4-6. ⚠ 손익 영향은 작다 — 이 채널은 경로 건전성을 본다

1분봉 반사실 재생 결과 유령의 **순기여는 9건 통산 ≈+3.0pt**뿐이다:

| | 실현 | 억제 시 | 유령 순기여 |
|---|---|---|---|
| 08-04 유령 4건 | +12.78 | +9.42 | **+3.36** |
| 08-05 억제 5건 (직접 관측) | +6.74 | 유령 발동 시 +6.36 | **−0.38** |

→ **"424차 억제가 흑자를 없앤다"는 우려는 반증됐다.** 억제는 옳고 손익은 중립이다.
(회계상 유리 체결분 +13.54pt를 순이익으로 읽으면 **4배 과장**된다 — 432차 후속2의
자체 정정 참조: *회계 분해는 반사실이 아니다*.)

### 4-7. ⚠ 사전등록 정직성 고지

첫 관측치(봉중 13/13, p=0.00024)는 신설 **전에** 이미 봤다. 재확인용이며,
**사전등록 가치는 424차 억제 배포 후의 회복 판정**에 있다.

## 5. [49] `payoff_geometry_watch` — 문제 자체의 상시 계측

### 5-1. 왜 신설했나 — 아무도 이걸 안 보고 있었다

**"현행 기하가 애초에 이길 수 있는 구조인가"** 를 묻는 채널이 하나도 없었다:

| 채널 | 보는 것 |
|---|---|
| [24] | TP1 보호전환 **반납**만 |
| [25] | 보호 **offset**만 |
| [23-B] | **대안** 기하만 |
| **[49]** | **현행 기하가 이길 수 있는 구조인가** ← 공백이었다 |

설정 직독(시뮬 무관):

```
하드스톱        = ATR × 1.50
보호스톱(qty=1) = ATR × 0.25       ← 호라이즌 무관 상수
→ 보호전환에 걸린 승리 0.25 : 패배 1.50 = 1:6 → 손익분기 승률 85.7%
```

TP1은 374/387차에 호라이즌별로 분화됐는데(0.3/0.5/0.7) **보호 lock은 339차 상수
그대로** 남아, TP1 대비 유지율이 **호라이즌에 반비례**한다:

| 호라이즌 | TP1 | 보호 lock | 유지율 |
|---|---|---|---|
| 1m | 0.3×ATR | 0.25×ATR | 83% |
| 3m | 0.5×ATR | 0.25×ATR | 50% |
| 5m | 0.7×ATR | 0.25×ATR | **36%** |

### 5-2. 이중지표를 쓰는 이유 — 갈림 자체가 정보다

| 기준 | 성질 |
|---|---|
| **원화(pt)** | 실제 돈. 고변동일의 큰 이익이 그대로 반영된다 |
| **위험조정(R)** | 각 진입의 하드스톱 거리로 정규화. 변동성 체제 차이를 제거한다 |

둘이 크게 갈리면 **"결과가 소수 고변동일에 집중"** 이라는 뜻이고, 리포트가
`dual_metric_divergence_pp`(기본 3.0%p) 초과 시 경고한다.

### 5-3. ⚠ 포지션 단위로 집계한다 — 417차 교훈

`trades` 한 행은 **청산 레그**다(TP1 부분청산 / 잔량이 별도 행). 레그로 세면
이익 포지션이 여러 작은 행으로 쪼개져 승률이 뜨고 손익비가 왜곡된다.
반드시 `GROUP BY entry_ts`로 병합할 것.

> **이 채널이 신설되자마자 잡은 것**: 432차/432차 후속2가 쓴 **로그 파서**가
> `[체결진입]`을 다음 `[체결청산]` 하나와만 짝지어 **다중레그 포지션 10건의
> 2번째 레그(+12.60pt)를 통째로 누락**하고 있었다. 아래 5-4의 정정 표 참조.

### 5-4. 판정 (사전등록, 관측 전 고정)

```
PASS         : edge_gap = 실제승률 − 손익분기승률 > 0 이 **두 기준 모두**에서 성립
FAIL         : 어느 한 기준이라도 edge_gap <= 0 → 기하 재설계 검토(주간회의 수동)
INSUFFICIENT : 포지션<40 또는 거래일<10
```

⚠ **자동 적용 없음(§9).** 이 채널의 목적은 조치가 아니라 **문제의 존재를 계속
보이게 하는 것**이다.

   재확인용이며, 가치는 **회복 판정**에 있다([25]의 `breakeven`과 같은 취급).

## 8. 해제·재론 조건

### [47] 해제 — 이것이 남은 **진짜 작업**이다

```
재생기에 TP3 + 4단계 트레일링 편입
```

- **PASS**(대칭 회복)면 424차 억제가 듣는 것이다 → 추가 조치 불요.

  다시 검토하고, 변경 시 **전/후 수치를 함께 기록**할 것.

### [49] 재론

  단 **[47]이 PASS로 돌아온 뒤에야** 기하 A/B 채널의 대안을 근거로 쓸 수 있다.
