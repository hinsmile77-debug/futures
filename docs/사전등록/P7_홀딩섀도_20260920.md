## 0. 왜 이걸 등록하는가

미륵이는 **보유 중앙 3분**에 나가고, **이긴 거래에서 갈 수 있는 거리(MFE)의 13%만** 먹는다
(이긴 228건: 실현 +444.2p / 그 건들의 MFE +3,501.1p).

피터리 역설계 과정에서 나온 유일한 생존 후보다. ⚠ **피터리에게서 가져온 규칙이 아니라,
피터리를 보다가 미륵이 자신의 약점을 발견한 것**이다. 피터리 규칙 이식은 전부 실패했다
(진입가 산출 7종 · 손절·목표 기하 3종 · BM 게이트 — 모두 무작위 수준 이하).

## 1. 규칙 (변경 금지)

```
적용 대상   방향 = SHORT
            ∧ 미륵이 실제 손익 > 0            (진 거래는 손대지 않는다)
            ∧ 08:50 구조모델 레벨 중 진행 방향에 다음 값이 있음

잔량 비율   50%
잔량 스톱   진입가(본전)                        → 최악 0p. **추가 위험 없음**
잔량 목표   다음 구조레벨                        → 임의 배수(W×k) 금지
시간청산    15:05
⛔ 롱 제외   실측에서 상승일 −2.1p · 하락일 −4.7p 로 양 국면 모두 음수
```

### 왜 「다음 구조레벨」인가
v2 카운터팩추얼에서 목표를 `손절폭 × 2.75`(피터리 상수)로 두면 무작위 72백분위로 죽었고,
**레벨 간 거리**로 바꾸자 98백분위가 됐다. 같은 교훈이 여기서도 나왔다 — 거리레벨 목표는
합계가 크지만 흑자일이 떨어지고(56%), **구조레벨 목표만 합계와 흑자일을 동시에 올린다**(65%).

> **목표는 임의 배수가 아니라 시장 구조에서 가져온다.**

## 3. 합격선

```
① 표본 밖 기간에서 일 단위 블록 부트스트랩 95% CI 하한 > 0
② 상승일 부분집합의 **점추정이 음수가 아닐 것**          ← 아래 ⚠ 참조
③ 흑자일 비율이 기준선 대비 떨어지지 않을 것
④ 잔량 결말 중 BREAKEVEN 비율이 80%를 넘지 않을 것        (넘으면 목표가 너무 멀다)
표본  표본 밖 최소 120거래일
```

### ⚠ 합격선 ②를 수정한 이력 — 중요
**초판은 「상승일 부분집합에서도 CI 하한 > 0」이었다. 그것은 달성 불가능한 기준이었다.**

검정력 계산: 상승일 일평균 개선 **+0.103 p**, 일별 SD **1.936**
→ CI 하한이 0을 넘으려면 **1,358 상승일 ≈ 2,772 거래일 ≈ 11.6년** 필요.

그래서 ②를 **「점추정이 음수가 아닐 것」**으로 낮췄다. 이 규칙의 값어치는
**국면을 맞히는 데 있지 않고**(그건 우리가 못 한다), **어느 국면에서도 손해가 아니라는 데** 있다.

| 구분 | 일평균 개선 | 필요 표본 |
|---|---|---|
| 숏 전체 | +0.549 p | **67일** (현재 58일 — 9일 남음) |
| 숏·하락일 | +0.985 p | 27일 → **이미 충족** |
| 숏·상승일 | +0.103 p | **1,358일 ≈ 11.6년** |

### 🔴 `P7_SHADOW_EOD.bat` 은 순수 ASCII 로 유지한다

초판에 한글 주석을 넣었다가 **실행이 깨졌다**. 출력에 `OW_EOD.bat`·`HONIOENCODING`
같은 **줄 중간 조각**이 찍혔다.

> **cmd.exe 는 배치 파일의 위치를 바이트 오프셋으로 기억한다.**
> 파일 안의 `CHCP 65001` 이 실행 도중 코드페이지를 바꾸면, 멀티바이트 문자가 있는
> 지점부터 오프셋이 어긋나 **줄 중간부터 다시 읽는다.**

- 산문은 **이 문서에** 쓰고 `.bat` 에는 쓰지 않는다.
- 파이썬 쪽 한글 출력은 `CHCP 65001` + `PYTHONIOENCODING=utf-8` 이 처리한다 —
  `.bat` 자체가 ASCII 면 오프셋이 밀릴 일이 없다.
- 관련 규칙(603차): **`.bat` 은 BOM 을 넣지 않는다**(cmd 가 BOM 을 첫 명령의 일부로 읽는다).
  BOM 이 필요한 것은 `.ps1` 쪽이다.

* 장중(08:45~15:35)에는 `guard_intraday` 가 막는다 — 2026-08-10 CB⑤ 자가유발 재발 방지.
* 원본 DB(`raw_data.db`·`trades.db`·`premarket_levels.db`)는 **`mode=ro`** 로만 연다.
* 쓰기는 `data/db/p7_shadow.db` **한 곳뿐**이다. 기존 스키마를 건드리지 않는다.
