### 조사에서 드러난 구조적 사실 3가지

1. **신동 v3 MAIN·섀도 5종은 사다리에 없다.** `tools/maekjeom_ladder/ladder_data.py` 는 `shindong.db` 를 열지 않는다.
   MAIN 은 대시보드 복기 차트·장후 PDF 에만 있다. AI 가 「기본」을 보며 학습할 수 없는 구조였다.
2. **「기본」이란 이름이 다른 것을 가리켰다.** 추이표의 「규칙 기본」은 `scripts/foreign_flow_pit_review.py` 의 점수식(신동2 기본)이지
   신동 v3 MAIN(HYBR60)이 아니다. 지금까지의 대조군 수치는 사용자가 뜻한 「실제거래/v3 MAIN」과 무관했다.
3. **단위가 달랐다.** MAIN 은 2계약·원(10/19 +1,916,683원 ≈ +19.2pt/계약 · 10/20 +1,919,458원 ≈ +19.2pt/계약).
   AI 는 1계약 단독시뮬 pt(10/19 +4.8 · 10/20 −5.2).

10/20 의 실패가 설계 공백을 가리켰다: AI 는 「외인 동향」 틀로 **매수**, MAIN 은 **개인 위클리 콜−풋 역추종(FLOWC)** 으로 **매도** +19pt.
AI 의 snapshot 에는 개인 콜−풋 항목 자체가 없었다 — **기본이 보는 것을 AI 가 못 보고 있었다.**

## 2. 사용자 결정 (원문 보존)

### 2-1. 역할·목적 (2026-10-20)

- `main.py` 는 신동2 AI 를 참조하지 않는다 — 사다리 패널 표시만 — **유지**.
- 목적: KOSPI200 미니선물에서 가장 수익률이 좋은 진입·청산 타점. 「예측 → 실행 → 평가·반성 → 레슨런 → 개선된 예측」 사이클을 매일·회차마다 — **유지**.
- 역할 둘 **유지**: 해설자 · 자가학습 장치.
- **개선 1건**: 대조군을 「기본·P·P2·P3」에서 **기본 = 실제거래/v3 MAIN**, **섀도 = V22 · V22S · HYBL · FLOWR60 · BRKC** 로 바꾼다.
- 하지 않는 것 유지: 주문 없음(§6) · 사전등록 상수 불변 · 기록 시각 벽시계 · 사후 수정 없음.
- 4-1. 방향·진입·청산·손절·확률의 근거는 AI 가 시장국면·외국인 동향으로 예측→실행→평가·반성→레슨런→개선 예측을
  **기본(v3 MAIN)을 가지고 평가**하고, 실전 라이브 시행착오 학습으로 **기본을 개선하는 방향**으로 레지스트리를 업그레이드하며
  개선 효과를 검증해 **기본을 능가할 능력**을 키운다.
- 4-2. 섀도에 대해서도 같은 사이클을 돌려 기본이 놓친 것·더 좋은 설정을 레슨런으로 잡아 개선 예측에 반영한다.
- **존재의 목적**: 라이브 시장 상황을 **중학생도 이해할 수 있게** 설명해 사용자의 미륵이 운영 고도화를 돕고, 다방면 데이터의 추이·비교분석·실험기록과
  4항의 라이브 평가로 최적 타점을 잡아 최고 수익률을 내는 **스마트한 기계**.

### 2-2. 처신 (2026-10-20 후속)

> **「MAIN·섀도의 행위는 『상대의 수』로 읽는다」** — 신동AI 의 처신을 한마디로 표현한 문장.
> 신동V3 의 신동AI 는 보조가 아니라 **치열하게 싸우는 경쟁자**다. 때로는 더 나은 지표를 개발하거나 웹을 통해 기관·외국인·헤지펀드의
> 수를 읽는 지표·전략을 수집·분석해 장착하고, 신동V3 를 능가하기 위한 수단으로 쓰도록 코드를 고려한다.

## 4. 바로잡은 설계 — 「기본의 눈」은 베끼는 눈이 되면 안 된다

세션 중간에 제안했던 「snapshot 에 MAIN 신호원을 보여 주자」(P3)는 그대로 두면 AI 가 MAIN 에 동의하는 쪽으로 수렴해 **복사본**이
될 위험이 있었다. 그래서 셋을 더했다 — ① 독립성 지표(동의율) 사전등록 ② 레슨 위에 「AI 전략 S-n」 층 ③ MAIN·섀도 행위는 「상대의 수」.
사용자가 ③을 **처신의 정의**로 채택했다(§2-2).
