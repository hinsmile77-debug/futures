## 결정·주의

- **기권(abstain)은 기록값이다** — 기계 판정으로 대체하지 않고 동의율 분모에서 뺀다(사전등록 §5). 구현 중 한 번 틀렸다가 테스트에서 잡혔다.
- `judge_window` 가 BEATS 여도 반대일 코호트가 AI 우위가 아니면 `why` 에 「동의일 덕일 수 있다」 경고를 붙인다.
- 배포 전 `eval.json`(10/07~10/19)은 평가 본체를 건드리지 않고 `rival` 키만 보강했다(`rival_backfilled_at`). 그 날들의 동의/반대는 전부 `(기계)` 표기다.
- 🔴 **사다리 서버 재기동 필요** — `server.py` 는 기동 시 `ladder_data` 를 올려 두므로 재기동 전에는 `/api/day` 에 `rival` 키가 없다
  (실측: 재기동 전 `'rival' in d == False`). `MAEKJEOM_LADDER.bat` 재실행.
- 기존 테스트 72건 + 신설 11건 = **84건 통과** (`python -m pytest -q tests/test_640_rival_scoreboard.py tests/test_614_* tests/test_656_* tests/test_662c_* tests/test_672_* tests/test_683_*`).
