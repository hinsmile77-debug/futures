## 핵심 발견 3가지

### 1. 처방 P1(트리플 배리어 라벨) 가설이 실측으로 확인됐다

기존 라벨(고정시간 방향분류)은 3m~30m 호라이즌에서 **FLAT 비율이 62~68%**다. 같은 30일 데이터에 ATR 연동 트리플 배리어(손절 1.5×ATR / 익절 3.0×ATR)를 적용하면 FLAT은 **0.04~0.6%**로 사실상 사라진다.

```
호라이즌   기존 라벨 FLAT%    트리플배리어 FLAT%   두 라벨 일치율
1m         33.7%              0.6%                 66.9%
3m         62.0%              0.4%                 38.4%
5m         62.2%              0.2%                 37.9%
10m        62.3%              0.1%                 37.7%
15m        64.1%              0.04%                35.8%
30m        67.7%              0%                    31.9%
```

**해석**: 6월 내내 30분 정확도가 랜덤급(33%대)이었던 현상은 "모델이 못 배웠다"가 아니라 **"학습 라벨의 62~68%가 FLAT이라 GBM이 방향성 신호를 거의 못 봤다"**일 가능성이 크다. 호라이즌이 길어질수록 일치율이 급락(1m 67%→30m 32%)하는 것도 "장기 호라이즌일수록 기존 라벨링 방식의 왜곡이 심하다"는 v9 설계안의 진단과 정확히 일치한다.

### 2. 진짜 병목 게이트는 Hurst가 아니라 qty_ok·mode_filter_ok였다 (예상 밖 발견)

18개 게이트 마지널 통과율을 실측하니 최저 2개는 다음과 같았다:

| 게이트 | 통과율 | `entry_block_reason`(운영 대시보드 차단사유 문구)에 등장하는가 |
|---|---|---|
| `qty_ok` | **9.6%** | ❌ 없음 |
| `mode_filter_ok` | **11.4%** | ⭕ 있음 (638건) |
| `hurst_ok` | 50.6% | ⭕ 있음 (1,272건) |

v9 설계안 §13은 Hurst·ATR·시가이격 등을 다중 게이트 병목의 주범으로 지목했는데, 실측 1위 병목(`qty_ok`, 90.4% 차단)은 그보다 훨씬 심하고, **운영 로그의 사람이 읽는 차단사유 문자열에는 아예 나타나지 않는다** — 즉 지금까지 대시보드로는 이 병목이 안 보였다는 뜻이다. 30일 등급 분포도 `{X: 5,848건, C: 1,912건}`으로 **A/B등급이 단 한 건도 없었다.**

부가로, 18겹 게이트의 실측 결합 통과율(1.32%)이 "완전 독립"을 가정한 이론값(0.37%)보다 오히려 3.6배 높게 나왔다 — 게이트들이 서로 양의 상관관계를 갖고 있다는 뜻으로, §13의 "AND 직렬 붕괴" 서사는 방향은 맞되 정량적 병목의 정체는 재조사가 필요하다.

### 3. 레짐 사후 라벨링 — 표본 부족으로 이번 창은 결론 보류, 데이터 이상치 하나 발견

30일 중 22일이 유효 데이터였고 그중 21일이 '추세장' 지배, 1일만 '횡보장'로 분류돼 TREND/RANGE PnL 비교를 하기엔 RANGE 표본이 1건뿐이라 이번 창에서는 통계적 결론을 낼 수 없다.

⚠️ **별도로 짚어야 할 것**: 여러 날 일중 레인지가 6~13%로 이례적으로 크게 나왔다(06-23: 13.03%, 07-01: 6.45%, 07-03: 10.83% 등). 거래소 서킷브레이커 발동일과 겹치는 것일 수도 있지만, 과거 21차/228차에서 있었던 "종목코드 불일치·봉차트 이종가격 혼재" 버그가 재발한 것일 가능성도 배제할 수 없다 — 원본 데이터 스팟체크를 권장한다(`NEXT_TODO.md` 290차에 등록).
