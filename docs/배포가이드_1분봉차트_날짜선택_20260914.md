## 1. 무엇이 바뀌었나

| 단계 | 내용 |
|---|---|
| **A** | 날짜 인자화 + `_live_mode` 플래그 + 달력 팝업 |
| **B** | 레이어별 수집 상태 배지 (봉·레짐·방향·거래·GP) |
| **C** | 마감구간(`session_bars` 15:09~15:34) 병합 + 경계 표시 |

### A — 날짜 선택

- `reload_today(session_date=None)` · `_start_reload_thread(session_date=None)` 로 인자화.
  하위 조회 4종(`fetch_today_trades` · `fetch_regime_today` · `fetch_direction_today` ·
  `_load_gp_trades`)은 **이미 날짜 인자를 받고 있었다** — 시그니처 변경 0건.
- 날짜칸 + **「달력 ▾」 버튼** + 「오늘」 버튼. 봉이 있는 날은 밝게·굵게, 없는 날은 흐리게.
  없는 날을 고르면 재적재하지 않고 되돌린 뒤 사유를 띄운다.
- 🔴 **`_live_mode` 가드 9곳** — 진입점 8개(`update_tick` · `on_candle_closed` ·
  `set_regime_at` · `set_direction_at` · `record_entry` · `record_exit` ·
  `sync_active_position` · `clear_active_position`) + `maybe_roll_session`.
  이게 없으면 과거 차트 뒤에 오늘 봉이 조용히 이어붙고, `maybe_roll_session` 이
  **다음 봉에 오늘로 강제 복귀**시킨다.
- 날짜 목록 조회는 **배경 스레드**(`_sig_dates_ready`). 실측 262일 DISTINCT 310ms —
  메인 스레드에서 돌리면 장중에 그만큼 화면이 멈춘다.

### B — 레이어 배지

「미측정」과 「0건」은 다르다. `_gp_status_text` 가 GP 한 층에 하던 구분을 5개 층으로 넓혔다.

| 문구 | 뜻 |
|---|---|
| `n건` / `384+27` | 측정값 (뒤 숫자는 마감구간) |
| `0건` | 원천이 돌았고 그날 실제로 0 (무포지션일) |
| `0건?` | 0 은 맞지만 가동 여부를 못 읽어 사유 미확정 |
| `미수집` | 그날 그 원천이 없었다 — **0건이 아니다** |
| `보관밖` | 레짐 EOD purge(30일) 이전 — 설계상 없다 |
| `기록없음` / `원천없음` / `미배선` / `미조회` | 테이블 빈값 / DB 못 읽음 / GP 미등록 / 조회 전 |

- 커버리지는 **날짜 집합**으로 읽는다(경계 min/max 로는 구간 안의 구멍을 못 잡는다).
- 거래·GP 가 0행일 때는 `direction`(ensemble_decisions)을 **증인**으로 써
  무포지션일과 미수집을 가른다. 증인을 못 읽으면 `0건?`.
- 배지에 마우스를 올리면 전체 판정표가 툴팁으로 뜬다.

### C — 마감구간

- `raw_candles` 가 15:08 에서 끝나는 건 **설계다**(`config/settings.py:441`, 533차).
  소비처 46파일의 "최근 N행" 창을 밀지 않으려고 15:09 이후를 `session_bars` 로 뺐다.
- `_merge_session_tail()` 이 **raw 의 마지막 ts 이후** 행만 붙인다.
  겹치는 구간은 손대지 않는다(실측: 겹치는 REGULAR 봉은 raw 와 완전히 동일).
- 경계에 세로 점선 + 옅은 배경 + 「수집 절단 → 마감구간 N봉 · 종가단일가 M」.
  15:45 `CLOSE_FILL` 은 **종가단일가**라 연속거래 봉과 성격이 다르다 — 갈라 그린다.
- 이건 계획서 §4 Phase 4 표의 「대시보드 차트 · 15:45까지 표시(표시 전용) · **게이트 없음**」 항목이다.

## 6. 검증 방식에 대한 기록

이 변경은 **오프스크린 PyQt5 렌더**(`QT_QPA_PLATFORM=offscreen`)로 실제 위젯을 띄워
검증했다. 그 과정에서 **속성 검사로는 안 잡히는 결함 3건**이 나왔다.

1. `QDateEdit::drop-down` 을 스타일시트로 덮자 화살표가 사라졌다 —
   `calendarPopup()` 은 `True`, `calendarWidget()` 도 정상. **API 는 멀쩡하고 픽셀만 비었다.**
2. `gp_rule_challenger_ids` 는 dict 인데 인덱스로 읽어 GP 층이 통째로 죽었다.
   같은 파일 안 `_load_gp_trades` 가 올바른 접근을 하고 있었다.
3. 무포지션일을 「미수집」으로 오판 — 날짜 집합만으로는 "왜 없는지"를 못 가른다.

**상호작용 요소는 열어서 찍어야 한다.** 속성만 보면 통과한다.
