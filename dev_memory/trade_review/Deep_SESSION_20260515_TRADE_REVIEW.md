## 5. 개선 제안

### 🔧 즉시 적용 가능한 개선

1. **1m 선행 신호 반전 시 조기청산 (Early Exit)**
   - `features/technical/cvd.py`와 결합: 1m horizon이 반대 방향으로 100% 확률 전환되고 CVD가 상쇄되지 않으면 → 즉시 손절/익절 축소
   - 구현 위치: `strategy/exit_manager.py` 또는 `safety/circuit_breaker.py`

2. **TP3/전량청산 미체결 → 취소 후 재시도**
   - 3초 내 미체결 잔여물 존재 시 → 주문 취소 → 지정가 1틱 불리하게 재주문
   - 낙관적 오픈(Optimistic OPEN)이 반대 방향으로 잡히는 것 방지

3. **Sizer-Executor 일관성 검증 로그**
   - Sizer 제안값 vs 실제 체결량을 DEBUG 로그에 추가: `[SizerMatch] suggested=10 filled=2 gap=8`
   - `config/constants.py`에 `MIN_FILL_RATIO` 추가 → 30% 미만 시 알람

### 💡 기발한 아이디어

4. **마이크로 호가잔량 기반 "진입 타이밍 최적화" (Micro-LOFI / Toxicity 필터)**
   - MICRO 로그에 이미 `mlofi_tick`, `toxicity`, `queue_signal`이 실시간 수집 중
   - **LOFI가 지속적으로 음수(-)일 때 SHORT 진입, 양수(+)일 때 LONG 진입을 허용** → 역방향 진입을 사전에 필터링
   - `toxicity > 0.5` (50%)일 때만 기존 신호에 진입 허용 (adverse selection 방지)
   - 09:49 진입 전 `toxicity` 확인: `tox_ma=0.1015`였고 `mlofi_norm=0.021`로 양수 → SHORT 진입에 불리한 미세구조였음

5. **"3연속 하드스톱 → 오후 거래 금지" 자동 킬스위치**
   - `safety/kill_switch.py`: 하루 3회 하드스톱 발생 시 → 잔여 시간 모든 신규 진입 차단, 기존 포지션만 관리
   - 5월 15일은 2회로 멈췄지만, 만약 3회였다면 오후 손실 방지 효과

6. **"Hurst Exponent 실측 → 레짐 분류기 고도화"**
   - `hurst=0.500` 고정 대신 실제 계산 구현. `hurst > 0.5` 지속 시 추세 국면으로 분류 → 추세추종 전략 가중치 증가. `hurst < 0.5` 지속 시 평균회귀 국면 → 스캘핑 위주
   - `features/technical/hurst.py` 복구 필요

7. **Checklist Weighted Scoring → 가중치 차등화**
   - 현재는 `sig=✓ conf=✓ vwap=✓ ...` 7/9로 단순 카운트
   - **코어 3피처(CVD, VWAP, OFI)는 각 2점, 나머지는 1점** → 14점 만점 중 최소 10점 이상일 때만 진입
   - 09:49 진입은 CVD=✗(2점 손실) → 실패 예견 가능했음

### 📋 조사 과제 (즉시 수정 말고 탐구)
