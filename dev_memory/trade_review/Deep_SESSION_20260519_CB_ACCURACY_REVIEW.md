## 4. 트레이더 관점 개선안

### 제안 1. "Scout -> Press" 2단 변속 진입

- 규칙:
  - `z-score 경고 존재` 또는 `CORE 피처 1개라도 탈락` 시
  - 신규 진입은 기본 계약의 **20~30%만 스카우트 포지션** 허용
  - 같은 방향 검증 3회 이상 통과 후에만 본사이즈 추가

효과:

- 장초반 이상 분포에서 대형 오판을 막는다.
- 맞을 때는 눌러 담고, 틀릴 때는 수업료만 내게 된다.

### 제안 2. "Accuracy Ignition Lock"

- 규칙:
  - 30m 전용 검증 샘플이 20개가 아니라 **30개 이상**
  - 최근 5바 동안 `극단 z-score` 0회
  - 최근 5바 동안 CORE 탈락 1회 이하
  - 이 조건 전에는 CB③은 측정만 하고 자동진입은 축소 모드

효과:

- 장초반 버퍼 오염 때문에 좋은 날을 너무 빨리 죽이는 문제를 줄인다.
- 반대로 나쁜 날에는 소형 포지션만 허용하므로 실제 손실도 작아진다.

### 제안 3. "한쪽 방향 과몰입 차단기"

- 규칙:
  - NEUTRAL 레짐에서 최근 12개 시그널 중 10개 이상이 같은 방향이면
  - 다음 시그널 confidence를 강제로 10~15% 차감
  - 또는 반대 체결압력/OFI가 안 받쳐주면 자동진입 금지

효과:

- 오늘처럼 LONG만 계속 외치는 편향장을 잘라낸다.

### 제안 4. "CORE Health Score"를 진입보다 먼저 사용

- 규칙:
  - `3_vwap`, `5_ofi`, `4_cvd` 상태를 0~100 점수화
  - 70점 미만이면 A/B 등급이 나와도 진입 금지
  - 70~85점이면 절반 사이즈
  - 85점 이상일 때만 정상 사이즈

효과:

- 예측 결과보다 피처 건강도를 먼저 믿는 구조가 된다.
- 선물은 특히 “왜 맞는지 모를 때 쉬는 것”이 수익률을 지킨다.

### 제안 5. "1% 트레이더식 오전 손실 예산"

- 규칙:
  - 09:00~10:00은 일일 허용 리스크의 **25%만 사용**
  - 30m 정확도 45% 미만이면 남은 오전 리스크를 절반으로 삭감
  - 35% 미만 경고 1회면 즉시 `no add / no pyramid`

효과:

- 시스템이 틀릴 자유는 주되, 계좌가 크게 다칠 자유는 주지 않는다.

### 제안 6. "중간 신뢰도 과신 탐지 — Overconfidence Blind Spot 제거"

- 현상:
  - CB③의 `_high_conf_wrong_streak`은 `confidence >= 0.85`만 추적
  - 오늘은 30m 신뢰도 60~80% 구간에서 전부 오답이었는데, 이 영역은 완전히 무방비
- 개선:
  - **Mid-Conf Blind Spot Tracker** 추가
  - `confidence >= 0.60` AND `confidence < 0.85` AND `incorrect` → `_mid_conf_wrong_streak += 1`
  - 7회 연속이면 **strict 모드 강제 진입** (임계값 50%로 상향)
- 효과:
  - 오늘처럼 "꽤 확신하지만 완전히 틀린" 패턴을 조기에 탐지
  - 09:40 시점(acc30m 36.4%)에서 미리 경고 가능했을 것

### 제안 7. "역방향 헤지 모드" — 모델이 한쪽만 찍을 때 자동 역베팅

- 트리거:
  - 최근 10분간 앙상블 동일 방향 6회 이상 연속 출력
  - AND `acc30m < 30%`
  - AND NEUTRAL/횡보 레짐
- 동작:
  - 메인 포지션과 반대 방향 **1계약 헤지 포지션** 자동 진입
  - 헤지는 별도 트레일링 스탑(고점/저점 대비 3pt)으로 관리
  - 메인 시그널 방향이 바뀌거나 acc30m 40% 이상 회복 시 헤지 청산
- 근거:
  - 오늘 09:20(고점 1157.36)~10:00(저점 1138.38) **19pt 하락**
  - 숏 1계약 = 19pt × 50,000원 = **950,000원 이익**
  - "모델이 미친 척하는 날"을 역이용하는 방어적 수익화 전략
- 리스크:
  - 헤지 1계약으로 제한, 메인 포지션과 상쇄되지는 않음 (메인은 진입 블록 상태)

### 제안 8. "재시작 루프 브레이커" — 연속 재시작 시 자동 축소

- 현상:
  - 오늘 3회 연속 재시작(08:45 → 10:06 → 10:13) 모두 동일 실패 반복
  - 재시작할수록 long bucket 정확도는 0.0%로 악화
- 개선:
  - 1일 내 CB③ HALT가 2회 이상 발생하면:
    - 3회차 진입 사이즈 **50% 축소**
    - 4회차부터는 **완전 관망 모드** (시그널 출력은 계속, 진입만 차단)
    - 다음 거래일 09:00에 리셋
  - 동시에 `raw_data.db`에 학습 데이터 **최근 2주 비중 2배**로 가중치 재조정 스케줄링
- 효과:
  - "죽음의 재시작 루프"에서 계좌 보호
  - 학습 데이터 왜곡이 의심될 때 강제 대응

### 제안 9. 가장 기발한 방안: "장초반 Shadow Session"

- 개념:
  - 09:00~09:40은 실제 주문 대신 **가상체결 shadow trading**으로만 채점
  - shadow 세션에서 30m 정확도, CORE health, z-score 안정성이 기준 통과하면
  - 09:40 이후 실주문 세션으로 전환

왜 유효한가:

- 미니선물은 시초 30~40분이 가장 왜곡되기 쉽다.
- 오늘처럼 20개 중 4개 정답이면, 차라리 그 20개를 수업료 없는 그림자 세션으로 써버리는 편이 낫다.
- “오전 첫 40분은 시장을 치는 시간이 아니라 시장의 상태를 심문하는 시간”으로 바꾸는 전략이다.

3. **Mid-Conf Blind Spot Tracker 추가 (제안 6)** — 구현 1시간, 효과 즉시
4. NEUTRAL 레짐의 방향 편향 카운터 추가
5. **역방향 헤지 모드 (제안 7)** — 09:20~09:50 같은 구간 수익화
6. Sizer에 `CORE health`와 `CB accuracy` 패널티 직접 연결
7. **재시작 루프 브레이커 (제안 8)** — 연속 CB③ HALT 방지
8. Shadow Session 또는 Scout 모드 중 하나를 우선 실험

## 6. 최종 판단

- 오늘 CB③ 정지는 **오작동이 아니라, 오히려 계좌를 살린 정상 정지**에 가깝다.
- 문제는 CB가 아니라, 그 전에 이미 나타난:
  - 입력 분포 이상
  - CORE 피처 붕괴
  - 방향 편향
  - 장초반 과신 구조
  이 네 가지다.
- 따라서 개선의 초점은 “정지를 늦추는 것”보다 “정지 전에 더 작게, 더 똑똑하게 들어가게 만드는 것”에 둬야 한다.
