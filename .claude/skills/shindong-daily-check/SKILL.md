## 4. 장중 확인 항목 — 장후에 판정한다

장중 정식 점검이 배포 첫날뿐이므로, 「장중에 확인할 것」은 **등록할 때 태그를 붙이고 장후에 판정한다.**

| 태그 | 뜻 | 판정 |
|---|---|---|
| `[로그]` | 그날 로그에 특정 줄이 나오는지(대부분) | **장후** — 근거 로그 1줄과 함께 닫는다 |
| `[경보]` | 장중에 즉시 대응해야 하는 상태 | 사람이 아니라 **자동 경보**(긴급 알림 메일)로 감시. 장후엔 경보 발생 여부만 기록 |
| `[화면]` | 대시보드 표시 | 장후 offscreen 스모크 또는 사용자 확인으로 넘긴다 |

장후 `0p-C` 의 「장중 확인 항목」 소절 규칙:
- 각 항목: **오늘 판정**(✅/❌ + 근거 1줄) · **표본 없음**(조건이 안 생김 — 나이 +1) 중 하나.
- **3거래일 연속 표본 없음 → ⬆️ 「구조적 미발생 의심」으로 격상** — 계속 기다리지 말고 왜 안 생기는지를 묻는다.
- 태그 없는 「장중」 항목을 새로 만들지 않는다. 기존 것은 보는 김에 태그를 붙인다(수집기 §6 이 개수를 센다).
